- 사정·진단·중재 진술문은 **시트 원문**. "연결·게이트·감별"은 **AI 초안 → 검증 전 사용 금지.**

## 🔒 공통 — 의식/낙상 (모든 환자 마지막)

### 의식 사정 — GCS 분기
```
[ GCS 15 · 명료함 ] → "의식 명료함" (한 줄로 끝)
[ 명료하지 않음 ]   → ↓ 펼침
   🧮 GCS (E/V/M 보고 탭 → 자동 합산)
       → "Glasgow Coma Scale : __" (값입력형 원문) · "의식수준 저하됨"
   🧭 지남력 (각각 클릭)
       시간 [있음][없음] → "시간에 대한 지남력 있음·없음"
       장소 [있음][없음] → "장소에 대한 지남력 있음·없음"
       사람 [있음][없음] → "사람에 대한 지남력 있음·없음"
```

### 매핑
| 사정(A&E) | 진단(D) | 중재(P&E) | 검토 |
|---|---|---|---|
| 의식 명료함 / (저하 시) Glasgow Coma Scale : __ · 의식수준 저하됨 · 시간·장소·사람 지남력 각각 있음·없음 · 보호자(상주/없음) | 낙상위험 🔒 | 지남력 평가함 / 낙상방지 교육함 / 침대 난간을 올려줌 | |

> ⚠️ GCS E/V/M 세부 점수 라벨(자발/소리/통증… 명령수행/국소/회피…)은 **표준 GCS** — 칩스 확인 권장.

## 검증 필요 (칩스)
1. 사정→진단→중재 연결의 임상 타당성 (특히 진단 매핑)
2. **"(확인 필요)" 진술문**을 시트에서 정확한 원문으로 채우기:
   - 어지럼·코피·인후통·홍반/발적·혈뇨·저혈당 증상·중재(수분·흡인예방·패드카운트·안정)
3. 진단 진술문 확정: 안과(감각지각)·피부(피부통합성)·배뇨장애·혈당·과민반응 관련 — 시트에 정확히 무엇이 있는지
