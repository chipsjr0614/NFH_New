| # | 무엇 | 왜 |

| 1 | **`외상-두부`에 `조직관류저하:뇌`가 맞나** | 경증 두부외상에도 이 진단을 붙이는 게 과한지 |
| 2 | **`소아-황달`에 `비효율적수유`가 맞나** | 황달 자체 진단이 마스터에 없어 수유로 잡았다 |
| 3 | **`아나필락시스`를 두 진단으로 나눈 것** | `알레르기반응` + `기도개방유지불능`. 하나로 할지 |
| 4 | **`부인과` 경로 이름** | 「임신 아님」이라 묶었는데 적절한지 |
| 5 | **임신 20주 이상에 태아심음(FHR)이 없다** | 마스터엔 `fetal heart rate 증가함/감소함`이 있다. 넣을지 |
| 6 | **외상에 수상 기전(교통사고·낙상)이 없다** | 마스터에 정형 진술문이 없어 📌비고로 간다 |
| 7 | **`화상` 범위·깊이가 없다** | TBSA·2도/3도는 마스터에 없다. 📌비고로 |

## 못 만든 것 — 마스터에 진술문이 없다

| 항목 | 상황 |
|---|---|
| **이통** | `이통`·`귀 통증`·`외이`·`중이` 어느 표현으로도 없다 |
| **절단** | `절단부위를 관찰하도록 격려함`(교육형) 하나뿐 |
| **코·귀·눈 외상** | 부위별 외상 진술문이 없다 |
| **열상** | `회음 열상`만 있다 |
