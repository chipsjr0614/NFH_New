## 1. 한 줄 비전

> **KTAS처럼 환자를 보면서 따라 클릭하면 → 사정이 빠짐없이 되고 → 그게 곧 정형 간호기록이 되는 도구.**

- **대상:** 간호기록·사정 개념이 약한 신규부터 빠른 경력까지.
- **기기:** 아이패드·**갤럭시 탭**을 들고 환자 곁에서. **단일 HTML·오프라인**(병원 내부망 OK).
- **목적:** 사정 → 정형 간호기록 자동 생성 → 기록지(EMR)에 복사.
- **철학:** **"탭 = 기록"** (묻고 탭한 것이 곧 진술문, 이중 작업 없음).

## 3. ★ 진술문 분류 규칙 (사정 vs 중재)

진술문의 **어미로 A&E / P&E 자동 분류**:

| 분류 | 어미 | 예 |
|------|------|----|
| **사정 A&E** (상태) | ~중임 · ~됨 · ~있음 · ~없음 · ~유지함 · ~되고 있음 | Foley catheter 유지 중임 · gas out 안됨 · 복부 통증 있음 |
| **중재/평가 P&E** (행위) | ~관찰함 · ~측정함 · ~교육함 · ~알림 · ~시켜줌 · ~적용함 | 배액양상 관찰함 · 활력징후 측정함 · 낙상방지 교육함 |

> ⚠️ "배액양상 관찰함", "주위 피부 상태 관찰함" 등 **"관찰함"은 중재(P&E)** 로 분류해야 함. (도관 칩 등 전체 적용)

   · 👁 관찰형(동공-신경 주호소 시만 / 피부색)  💡 사정법 안내

   ↓

## 5. 🛡️ 2종 안전 게이트

### 시작 게이트 (절차 확인, 기록 미포함)
- 🧼 손위생 / 🗣️ "성함이 어떻게 되세요?"(개방형) / 🏷️ 팔찌(이름+등록번호)
- **3개 체크 + 이름·등록번호(8자리) 입력**해야 시작
- (시트에 "손위생 시행함" 진술문 없음 → 절차 확인용, 기록 안 함)

### 위험 중재 게이트 (안내형)
- 위험 징후 자동 감지 시 팝업. **클릭 강제 아님**(확인 권고), "확인했습니다" 누르면 진행.
- 항목: 📟모니터 / 📞의사 보고 / 🩺활력징후 / 🩸**혈당(BST) 확인** / 🕑**이전에도 이런 증상 있었는지 사정**
- 체크한 것만 기록(분류 규칙 적용: "EKG monitor 중임"=A&E, "담당 의사에게 알림·활력징후 측정함"=P&E)
- 자동 트리거: 쇼크·의식저하(GCS<15)·ACS의심·아나필락시스·청색증·뇌졸중(FAST+)·Seizure·자해

## 6. ① 도관 확인 (15종, 시트 원문)

버튼=약어, 기록=정식 명칭. 도관 선택 시 **배액·출혈 차팅** 펼침("유지 중임" 자동 선택).

| 약어 | 정식 명칭 | 배액·출혈 차팅(예) |
|---|---|---|
| Foley | Foley catheter | 유지 중임 · 통해 소변 배출되고 있음 · 소변 leakage 없음/있음 |
| L-tube | Levin tube | 유지 중임 · 통해 배액됨 · patency 유지됨 |
| PTBD | Percutaneous Transhepatic Biliary Drainage | 삽입부위 출혈 없음/있음 · oozing |
| PTGBD | Percutaneous Transhepatic Gallbladder Drainage | 자연배액 유지함 · 삽입부위 출혈 |
| PCD | Percutaneous Drainage | 유지 중임 · 자연배액 유지함 · 출혈 |
| CVC | 중심정맥관 | 유지 중임 · 삽입부위 출혈 · 막힘 |
| A-line | arterial line | 유지 중임 · site 출혈/oozing |
| 흉관 | 흉관 | 유지 중임 · 자연배액 중임 · 삽입부위 출혈 |
| hemovac | hemovac | 유지 중임 · leakage · oozing · 막힘 |
| 장루 | 장루 | 통해 배액되는 것 있음/없음 · 출혈 |
| Tracheostomy | 기관절개관 | 유지 중임 · 주위 출혈 없음/있음 |
| PEG | gastrostomy tube | 삽입부위 출혈 · discharge |
| PCN | Percutaneous Nephrostomy tube | 유지 중임 · 삽입부위 oozing |
| Hickman | Hickman catheter | 삽입부위 문제 없음 · 막힘 |
| EVD | External Ventricular Drainage | 삽입부위 oozing · 통증 |

> ⚠️ "배액양상 관찰함"·"주위 피부 상태 관찰함"은 **중재(P&E)** 로 분류 (3장 규칙).
> 📌 **미결정 — 도관 UI:** 15종이 세로로 길어 **2열 그리드** 또는 **접기(+도관 추가)** 로 개선 예정.

## 7. 주호소 + 증상 사정

### 주호소 (계통별, 복수 선택)
⭐자주(복통·흉통·호흡곤란·발열·외상·두통) + 🧠신경 · 🫀심장 · 🤢소화기 · 🩸출혈 · 🔥감염 · 👁️안과 · 👂이비인후 · 🩹피부 · 🩺비뇨 · 🍬대사 · 🧠정신 + 🔍검색

### 사정 입력 (3종)
| 방식 | 설명 |
|------|------|
| 🧍 **바디맵** | 몸 그림 탭 → 부위 진술문 (예: 하복부 통증 있음) |
| 😀 **얼굴 통증척도** | 표정 0~10 (NRS, 비고) + 양상·발병 |
| 일반/관찰 토글 | 동반증상(있음=🔴), 동공·피부 |

### 동반증상 라벨·순서 (복통 예)
- 오심·구토 [없음][있음] → 오심, 구토 없음/있음
- 대변 [봄][못 봄] → 대변 봄 / 대변 못 봄
- gas out [됨][안됨] → **gas out 됨 / gas out 안됨** (※ "있음/없음" 아님)
- 설사 [없음][있음] → 설사 없음/있음

### 놓침방지 게이트 · 감별 힌트
- ⚠️ 임신(확인만·기록X)·혈변·식은땀·열감 등 한 번은 확인
- 🔀 조합 시 의심 힌트(ileus·충수염·ACS 등) → **의사 보고용**(진단 아님)

## 9. 🧠 신경 평가 (FAST) — 💡 사정법 안내 포함

| 항목 | 💡 사정 방법(화면 안내) | 진술문 |
|------|----------------------|--------|
| 얼굴 | "이~ 웃어보세요/눈 꽉 감기" 대칭? | 안면 비대칭임 · 안면신경마비 있음/없음 |
| 팔 들기 | "양팔 들고 10초" 떨어짐? | 국부 마비 있음/없음 · 근력 감소함 |
| **grasp** | "제 손가락 양손으로 꽉 쥐세요" | grasp power 강함/약함 · grasp power 평가함 |
| 말 | "성함·날짜 말해보세요" | 말을 어눌하게 함 |
| **감각저하** | "눈 감고 양쪽 똑같이 느껴지나요?" | 감각저하 있음/없음 · 감각이상 있음/없음 |
| 동공 | "펜라이트로 빛 비춰" | 동공이 확대됨/수축됨 · 빛 반사 prompt함 |
| 시야·균형 | 손가락 개수 / 걸어보기 | 시력장애·균형장애 있음/없음 |

→ FAST 양성 → 뇌졸중 의심·의사 보고 / 진단 조직관류저하:뇌

## 10. 🔒 의식 (GCS 분기) + 낙상 교육

### 의식 GCS 분기
```
[GCS 15·명료] → "의식 명료함"
[명료하지 않음] → GCS(E/V/M 보고 탭) → "Glasgow Coma Scale : __" · "의식수준 저하됨"
                + 지남력(각각): 시간/장소/사람에 대한 지남력 있음·없음
```

### 낙상 교육 (낙상위험 → 클릭 체크리스트)
진단 **낙상위험** 자동 → 교육 중재를 📢말하며 체크(P&E):
| 📢 말할 문장 | 기록(시트 원문) |
|---|---|
| "내려오실 때 간호사 불러주세요" | 낙상방지 교육함 |
| "침대 난간 올려드릴게요" | 침대 난간을 올려줌 |
| "보호자분 같이 계셔 주세요" | 보호자와 같이 있게 함 |
| "보호자분 동반해 주세요" | 보호자 동반하도록 설명함 |
