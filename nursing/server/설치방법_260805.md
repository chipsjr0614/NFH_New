# 맥미니 내부망 서버 — 설치 (2026-08-05)

간호사 폰(아이폰·갤럭시)에서 **앱 설치 없이** 간호기록을 쓰게 하는 방법.
맥미니에 파일을 띄워두고, 폰에서는 주소만 치면 된다.

```
맥미니 (병원 내부망 · 켜둔 상태)
   └─ 간호기록 파일 제공  :8000
            ↓
간호사 폰  →  http://맥미니주소:8000  →  [홈 화면에 추가]  →  아이콘 생김
```

> 인터넷 연결이 필요 없다. 병원 내부망 안에서만 오간다.

---

## 1. 먼저 — 맥미니 IP 확인

맥미니 터미널에서:

```bash
ipconfig getifaddr en0 || ipconfig getifaddr en1
```

예: `192.168.0.35` — 이 숫자가 간호사들이 칠 주소가 된다.

### ⚠️ IP가 바뀌지 않게 고정하기

DHCP로 받으면 재부팅 때 주소가 바뀔 수 있다. 둘 중 하나로 고정한다.

- **시스템 설정 → 네트워크 → 세부사항 → TCP/IP → 「DHCP 사용(수동 주소)」** 로 IP 고정
- 또는 전산실에 **DHCP 예약**을 요청 (맥 주소 알려주면 됨)

---

## 2. 켜보기 (수동)

```bash
cd ~/Library/Mobile\ Documents/com~apple~CloudDocs/AI/NFH_New/nursing/server
./serve.sh
```

주소가 화면에 나온다. 터미널을 닫으면 서버도 꺼진다.

**폰에서 접속 테스트** — 같은 병원 Wi-Fi에서 `http://맥미니IP:8000`

---

## 3. 자동 시작 설정 (재부팅해도 켜짐)

맥미니 터미널에서 아래를 그대로 실행한다.

```bash
cat > ~/Library/LaunchAgents/com.nfh.chart.plist << 'PLIST'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.nfh.chart</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/bin/python3</string>
    <string>-m</string><string>http.server</string>
    <string>8000</string>
    <string>--bind</string><string>0.0.0.0</string>
  </array>
  <key>WorkingDirectory</key>
  <string>REPLACE_ME</string>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>StandardOutPath</key><string>/tmp/nfh_chart.log</string>
  <key>StandardErrorPath</key><string>/tmp/nfh_chart.err</string>
</dict></plist>
PLIST

# 실제 폴더 경로를 넣는다
APP="$HOME/Library/Mobile Documents/com~apple~CloudDocs/AI/NFH_New/nursing/app"
/usr/bin/sed -i '' "s|REPLACE_ME|$APP|" ~/Library/LaunchAgents/com.nfh.chart.plist

# 등록
launchctl unload ~/Library/LaunchAgents/com.nfh.chart.plist 2>/dev/null
launchctl load ~/Library/LaunchAgents/com.nfh.chart.plist
launchctl list | grep nfh
```

마지막 줄에 `com.nfh.chart` 가 보이면 성공이다.

### 확인

```bash
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:8000/
```
`200` 이면 정상.

### 끄기 / 다시 켜기

```bash
launchctl unload ~/Library/LaunchAgents/com.nfh.chart.plist   # 끄기
launchctl load   ~/Library/LaunchAgents/com.nfh.chart.plist   # 켜기
```

## 4. 맥미니가 잠들지 않게

잠들면 서버도 멈춘다.

**시스템 설정 → 디스플레이 → 고급 → 「디스플레이가 꺼져 있을 때 자동으로 잠자기 방지」 켜기**

또는 터미널에서:
```bash
sudo pmset -a sleep 0 disksleep 0
```

---

## 5. 방화벽

**시스템 설정 → 네트워크 → 방화벽**

켜져 있으면 → 옵션 → `python3` 의 들어오는 연결 **허용**.
잘 모르겠으면 잠시 꺼서 접속되는지 확인하고 다시 켜면 된다.

---

## 6. 간호사에게 알려줄 것

> **주소** `http://192.168.0.35:8000` ← 실제 IP로 바꿔서 안내
>
> **아이폰** Safari로 접속 → 아래 공유 **⬆️** → 「홈 화면에 추가」
> **갤럭시** Chrome으로 접속 → 오른쪽 위 **⋮** → 「홈 화면에 추가」
>
> 홈 화면에 🩺 아이콘이 생기고, 누르면 앱처럼 전체화면으로 열린다.

QR코드를 만들어 병동에 붙여두면 더 편하다. (검색: "QR코드 생성" → 위 주소 입력)

## 7. 파일을 고쳤을 때

맥미니의 `nursing/app/` 폴더 파일만 바꾸면 **간호사 폰에서 새로고침하면 바로 반영**된다.
서버를 다시 켤 필요 없다.

V6를 다시 빌드했다면:
```bash
cd ~/Library/Mobile\ Documents/com~apple~CloudDocs/AI/NFH_New/3_서비스/NFH간호기록/data
python3 build_v6.py
```

## 8. ⚠️ 알아둘 것

| | |
|---|---|
| **환자 정보** | 입력한 기록은 **폰 안에만** 저장된다(localStorage). 맥미니로 전송되지 않는다 |
| **전산실 통보** | 병원 정책에 따라 내부망에 서버를 띄우는 것을 알려야 할 수 있다. 미리 문의를 권한다 |
| **맥미니 꺼짐** | 맥미니가 꺼지거나 네트워크가 끊기면 간호사 폰에서도 안 열린다 |
| **HTTPS 아님** | 내부망 전용이라 http로 충분하다. 다만 브라우저가 「안전하지 않음」이라고 표시할 수 있다 |
