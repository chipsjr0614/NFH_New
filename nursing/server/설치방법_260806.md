# 내부망 https 서버 — 설치 (2026-08-06)

`설치방법_260805.md`(http 판)를 대체한다. **https로 바꾸면 이것들이 된다.**

| | http (전) | https (지금) |
|---|---|---|
| **맥이 꺼져도 앱이 열림** | ❌ | ✅ 폰에 저장됨 |
| **Wi-Fi 끊겨도 열림** | ❌ | ✅ |
| 복사 | 우회로 동작 | 바로 동작 |
| 저장된 기록 | Safari가 지울 수 있음 | 더 오래 남음 |
| 주소창 | 「안전하지 않음」 | 자물쇠 |

> 병원 내부망은 인터넷이 막혀 있어 Let's Encrypt 같은 무료 인증서를 못 쓴다.
> **자체 서명 인증서**를 만들고 폰마다 한 번 설치한다.

---

## 맥에서 — 두 줄

```bash
cd ~/Library/Mobile\ Documents/com~apple~CloudDocs/AI/NFH_New/nursing/server
./mkcert.sh          # 인증서 만들기 (한 번)
python3 serve.py     # 서버 켜기
```

IP가 자동으로 안 잡히면 직접 주면 된다 — `./mkcert.sh 192.168.0.35`

켜지면 주소 두 개가 나온다.

```
폰 설정   http://10.32.61.237:8000
간호기록  https://10.32.61.237:8443
```

---

## 폰에서 — 한 번만, 3~5분

**`http://맥IP:8000`** 으로 먼저 들어간다. 안내 화면이 그대로 알려준다.

1. **① 인증서 받기** 를 누르고 「허용」
2. **설정 → 프로파일 다운로드됨** → 설치 → 암호 → 설치
3. **설정 → 일반 → 정보 → 인증서 신뢰 설정** → `NFH 간호기록 내부망 CA` **켜기**
   → ★ 이 단계를 빼먹으면 https가 안 열린다. 제일 많이 놓치는 곳이다.
4. **② 간호기록 열기 (https)**
5. 공유 **⬆️** → **홈 화면에 추가**

> **주소를 헷갈리지 말 것.**
> 설정용은 `http://…:8000`, 실제 앱은 `https://…:8443`.
> http로 앱을 열면 복사와 오프라인이 안 된다.

## 매년 한 번 — 인증서 갱신

**iOS는 398일 넘는 서버 인증서를 거부한다.** 그래서 397일로 만든다.

```bash
./mkcert.sh          # 다시 돌리면 서버 인증서만 새로 만든다
```

**CA는 그대로 두므로 폰은 아무것도 안 해도 된다.** 서버만 다시 켜면 끝이다.

만료일 확인:
```bash
openssl x509 -in certs/server.crt -noout -dates
```

---

## IP가 바뀌면

인증서에 IP가 박혀 있어 **IP가 바뀌면 인증서를 다시 만들어야 한다.**

```bash
./mkcert.sh 새IP
```

→ 그러니 **IP를 고정해 두는 게 좋다.**
시스템 설정 → 네트워크 → 세부사항 → TCP/IP → 「DHCP 사용(수동 주소)」
또는 전산실에 DHCP 예약 요청.

## 파일을 고쳤을 때

`nursing/app/` 안의 파일만 바꾸면 된다. **폰에서 새로고침하면 바로 반영된다.**

오프라인 캐시는 **「네트워크 먼저」** 방식이라, 서버가 살아 있으면 늘 새 파일을 쓴다.
서버가 죽었을 때만 저장해 둔 것을 꺼낸다. 고친 게 폰에 안 내려갈 걱정은 없다.

V7을 다시 빌드했다면:
```bash
cd ~/Library/Mobile\ Documents/com~apple~CloudDocs/AI/NFH_New/3_서비스/NFH간호기록/data
python3 build_v6.py
```

## 안 될 때

| 증상 | 확인 |
|---|---|
| https가 「안전하지 않음」 | **3번(인증서 신뢰 설정)을 안 켰다.** 제일 흔하다 |
| 폰에서 아예 안 열림 | 같은 Wi-Fi인가 · 방화벽 · IP가 바뀌었나 |
| 인증서 설치가 안 됨 | Safari로 열었나 (Chrome·Documents 앱에서는 안 된다) |
| 복사가 안 됨 | 주소가 **https**인가 (http면 안 된다) |
| 맥에서도 안 열림 | `launchctl list \| grep nfh` · `/tmp/nfh_chart.err` |

## 알아둘 것

| | |
|---|---|
| **환자 정보** | 폰 안에만 저장된다(localStorage). 맥으로 전송되지 않는다 |
| **지난 환자 10명** | 폰에 남는다. 다른 폰에서는 안 보인다 |
| **인증서 개인키** | `certs/ca.key`·`server.key` 는 맥에만 둔다. 폰에 보내는 것은 `ca.crt` 뿐 |
| **전산실 통보** | 병원 정책에 따라 내부망 서버를 알려야 할 수 있다 |

> `certs/` 폴더는 `.gitignore`에 넣어 두었다. 개인키가 저장소에 올라가면 안 된다.
