## 🛑 읽고 시작하기

- **사정·진단·중재 진술문은 전부 진술문 시트 원문**입니다(지어내기 없음). 표기 그대로.
- **"연결(어느 사정→어느 진단→어느 중재)"과 "감별 힌트"는 AI 초안**입니다 → **검증 전 사용 금지.**
- 🔀 **감별 힌트(ileus·충수염 의심 등)는 진단이 아니라 "간호사가 의심하고 의사에게 보고"하는 보조**입니다. (진단은 의사 영역)
- 검토법: 맞으면 그대로 / 틀리면 메모란 수정 / 빼면 ❌ / 빠진 진술문 추가

## 1. 😣 복통

### 사정(A&E) — 진술문 원문 (분기·가지치기)
**① 부위:** 상복부 통증 있음 / 하복부 통증 있음 / (우·좌하복부) / 복부 통증 있음 / 복부 불편감 있음
**② 동반:** 오심 있음·없음 / 구토함·구토 없음 / 설사 있음·없음 / 대변 봄·대변 못 봄 / gas out 있음·없음
**③ 통증 사정(가지치기):** 부위·양상·강도(NRS)·발병·지속 → 📌비고

### ⚠️ 놓침방지 게이트
| 확인 항목 | 진술문(원문 후보) | 검토 |
|---|---|---|
| 가임기 여성 임신 가능성·LMP | (임신 관련 진술문 확인 필요) | |
| 토혈·혈변·흑색변 | 혈변 있음·없음 / (토혈 진술문 확인) | |
| 식은땀·창백·어지럼(쇼크) | (진술문 확인 필요) | |
| 열감·오한(감염) | 열감 있음 / chilling 있음 | |

### 🔀 감별 힌트 (의심 → 의사 보고, 진단 아님)
| 사정 조합 | 의심 | 검토 |
|---|---|---|
| 오심·구토 + 대변 못 봄 + gas out 없음 (+복부팽만) | 🔴 ileus(장폐색) 의심 | |
| 우하복부 + 발열 (+반발통) | 🔴 충수염 의심 | |
| 옆구리 + 혈뇨 | 신산통(비뇨기) 의심 | |
| 설사 + 발열 | 내과(장염) 의심 | |
| 가임기 + 하복부 + 질출혈 | 산과 의심 | |

### → 간호진단(D) / 중재(P&E)
| 진단(D) | 중재·평가(P&E) + 📢설명 | 검토 |
|---|---|---|
| 급성통증 | 통증을 인정해줌 / 통증을 조절해줌 / 통증을 재평가함 / 통증을 관찰하기로 함 · 📢"많이 아프세요?" | |
| 오심 | 금식하도록 교육함 / 활력징후 측정함 | |
