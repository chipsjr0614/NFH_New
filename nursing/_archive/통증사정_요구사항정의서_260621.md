# 통증 사정 요구사항 정의서

**작성:** 2026-06-21 · **대상:** NFH 응급실 간호기록 통증 모듈 · **작업 목업:** `nursing/통증사정_목업_260621.html`

> **데이터 무결성(절대 규칙):** A&E·D·P&E 정형 진술문은 **마스터 원문(`Nr.statement_1023_Final.xlsx`)만** 사용. 마스터에 없는데 칩스(수간호사)가 쓰기로 **확정한 표현**은 `[칩스확정]`으로 표기(추후 마스터 정식반영 대상). 강도·양상·부위세부·SMC세부 등은 정형 진술문이 아니라 **비고**로 기록.

---

## 1. 공통 구조 · 규칙

| 규칙 | 내용 |
|------|------|
| **부위 복수선택** | 한 환자가 여러 부위 통증 동시 선택 가능. 부위마다 사정 카드. |
| **사정 순서** | 부위 특이 사정 항목을 **먼저**, **"통증 있음/없음"은 항상 맨 마지막**. 통증 '있음' 시 6종이 그 뒤에 펼쳐짐. |
| **통증 진술문 통일** | 부위별 표현(`흉부 통증 있음`·`두통 있음`·`복부 통증 있음`) **안 씀**. 부위 불문 **`통증 있음`/`통증 없음`(마스터✅) 하나로 통일**. 부위는 비고·카드 헤더(`[통증·머리]`)로만. |
| **진단(D) 규칙** | 간단히 1개 위주. 통증 **있음 → `급성통증`**. 통증 **없음 → 주 문제의 진단**(예: 출혈 관련). 진단명 남발 금지. |
| **평가(P&E)** | `통증을 인정해줌` / `통증 양상을 확인함` / `통증을 관찰하기로 함`(마스터✅, 말할문장 📢 → 체크 시 기록). |

---

## 2. 통증 '있음' 시 6종 입력 (전부 비고)

마스터에 정형 진술문 **없음** → 모두 **비고** 메타데이터.

| # | 항목 | 입력 |
|---|------|------|
| 1 | **부위** | 직접 입력 (가슴·배는 클릭형 — 아래 부위별 표 참조) |
| 2 | **사정도구** | NRS / FPRS / FLACC / NIPS / CNPS (단일선택, 각 설명 표시). ⚠️ CNPS 약자 의미 = 칩스 검증 필요 |
| 3 | **강도** | 0~10 클릭형(✓) |
| 4 | **빈도** | 발작적으로 갑자기 / 지속적 / 표현 못함 / 기타 |
| 5 | **양상** | 뻐근한 / 날카로운 / 둔한 / 욱신욱신·쑤시는 / 타는 듯한 / 저리는 듯한 / 칼로 베인 듯한 / 표현 못함 / 기타 (복수) |
| 6 | **기간** | 직접 입력 (측정 불가 = `-1`) |

## 3. 부위별 사정 (8개)

각 부위 = [특이 사정 항목] → **통증(맨 마지막)** → (있으면) 6종. 진술문은 마스터 원문.

| 부위 | 사정 항목 (A&E 정형 진술문) | 비고 |
|------|------|------|
| 🧠 **머리(두통)** | `dizziness 있음/없음` · `동공크기 : Rt _ / Lt _` · `빛 반사 확인결과 (prompt/sluggish/hippus) 함` · `감각이상 있음/없음` · `grasp power 강함/약함` | — |
| 🫀 **가슴(흉부)** | `호흡곤란 있음/없음` · `dizziness 있음/없음` | **부위 클릭형**: anterior chest / epigastric site / mediastinal site / substernal site / 가슴부위 |
| 🫃 **배(복부)** | `오심, 구토 있음/없음` · `복부 불편감 있음/없음` · `대변 봄/못봄` · `설사 있음/없음` · `gas out 있음/없음` | **부위 클릭형**: LLQ / LUQ / RLQ / RUQ / periumbilical area / 전체 |
| 🧣 **목(경부)** | `경부 강직 있음/없음` | 강직 정도(mild/moderate/severe/tolerable) = 비고 `[칩스확정]`(마스터 없음) |
| 🔙 **허리(요추)** | `허리에서 다리로의 방사통 호소함` / `방사통 없음` · **SMC**(아래 4번) · `배뇨장애 있음/없음`(🚨cauda equina) | — |
| 💪 **팔** / 🦵 **다리(사지)** | **SMC**(아래 4번) | — |
| 🍑 **엉덩이** | 보행: `부축없이 혼자 보행 가능함` / `부축하면 보행 가능함` / `걷지 못함` · `허리에서 다리로의 방사통 호소함`/`방사통 없음` | 보행 단계 = 칩스 최종 확정 대기 |

## 4. SMC (신경혈관 사정) — 허리·사지

- **A&E 정형 한 줄**: `sensory, motor, circulation intact 함` (마스터✅, check). 누르면 **바로 그 아래** S·M·C 세부가 펼쳐짐.
- **세부 (비고)**: Sensory / Motor / Circulation 각각 **양호함 / 약함 / 없음 / 평가불가** 클릭. → `[칩스확정]` (마스터 무시, 칩스 지시).
- 평가불가 시 종합 `sensory, motor, circulation 확인할 수 없음`(마스터✅) 사용 가능.

## 5. 「골절/외상」 독립 모듈

골절·상처·출혈 등 외상 관련을 **부위와 별개로 한 모듈에서 모두** 사정 (출혈을 따로 빼지 않음).

| 항목 | 진술문 |
|------|------|
| 골절 | `골절 있음` · `골절부위 부종/edema 있음` · `골절부위 tingling sense 있음` (마스터✅) |
| 상처 | `찰과상 있음/없음` · `피부 손상 있음/없음` (마스터✅ — "상처 있음/없음" 일반표현은 마스터에 없어 이걸로 대체) |
| 출혈 | `출혈 있음` 등 (정본 출혈 세트/마스터 연계) |
| 신경혈관 | SMC (4번과 동일) |
| 통증 | **맨 마지막** → 있으면 `급성통증`, 없으면 출혈 등 해당 진단 |

## 6. 차팅(미리보기) 출력 형식

비고는 **맨 아래 한 덩어리로 몰지 않고, 각 진술문 바로 다음 줄**에 분산한다.
- SMC 세부 비고 → `sensory, motor, circulation intact 함` 바로 다음 줄
- 통증 비고(6종) → `통증 있음` 바로 다음 줄

**예시 (허리):**
```
[통증 · 허리]
A&E · 허리에서 다리로의 방사통 호소함
A&E · sensory, motor, circulation intact 함
📌 비고: Sensory 약함 / Motor 양호함 / Circulation 양호함
A&E · 배뇨장애 없음
A&E · 통증 있음
📌 비고: 사정도구 NRS / 통증강도 6점
D · 급성통증
P&E · 통증을 인정해줌
```

색상: A&E 파랑 / D 빨강 / P&E 노랑 / 📌비고 회색. 양성(있음/이상) 빨강 강조.

## 7. 미해결 · 확인 필요 (칩스)

- [ ] 사정도구 5종 — 환자 유형 따라 단일선택인지 / CNPS 약자 정확한 의미
- [ ] 경부 강직 **정도**(mild/moderate/severe/tolerable) 진술문 확정
- [ ] SMC 세부(`Sensory 양호함/약함/없음/평가불가`) 마스터 정식 반영
- [ ] 엉덩이 **보행** 단계(혼자/부축/못 걸음) + 파행 추가 여부 확정
- [ ] 골절/외상 — "통증 없음"일 때 **출혈 진단명** 확정 (정본 출혈 세트 연계)
- [ ] 빈도·양상 일부 표현의 마스터 반영(현재 전부 비고)
