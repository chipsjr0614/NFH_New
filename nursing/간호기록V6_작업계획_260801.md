### 1-3. ★ 핵심 발견 — 엑셀에 질문 트리가 있는데 V4가 안 씀

`3_서비스/NFH간호기록/data/간호기록_원본_260623.xlsx` (칩스 편집본)

```
[1.주호소트리]  질문1 → 선택1 → 질문2 → 선택2 → 대분류/소분류
                주증상 15종 · 분기 경로 34개
[2.사정세트]    소분류마다 A&E / D / P&E 세트 (354행: A&E 197 · D 50 · P&E 106)
[3.환자설명] [4.도관] [5.낙상교육]
```

**분기 예시** — 이것이 곧 "응급실에서 효율적으로 질문하기":

```
🩸 출혈 (눈에 보임)
  └ "출혈 종류?"      → 객혈 (기침으로 피 뱉음)
      └ "흉통 동반?"  → 흉통 있음  →  A&E 7 · D 2 · P&E 5
                      → 흉통 없음  →  A&E 7 · D 1 · P&E 2
```

임상적으로 갈리는 분기:
- 호흡곤란 → 가래 적음 / 가래 많음(폐렴) / 천명음(천식·croup) / 심부전+흉통유무
- 심근경색 의심 → 통증 있음(A&E 10) / 통증 없음(A&E 5)
- Seizure → **지금 하는 중** / **이미 멈추고 내원**

**V4는 이 트리를 전혀 쓰지 않음.** 주호소 18개 평면 버튼 + 사정 항목 나열 방식이라,
신규 간호사가 "뭘 물어야 할지"를 여전히 스스로 알아야 하는 구조.
