## 0. 대원칙

간호기록 마스터 문장을 효율적으로 쓰게 만들어,
**신입·전보자·경력자 누구든 같은 룰로 간호기록을 완성**하도록 한다.
**빠르면서, 놓치지 않고, 완벽한** 간호기록이 목표다.

```
간호사가 환자에게 질문한다  →  답을 누른다  →  간호기록이 완성된다
```

## 3. 간호기록 작성 룰

### 3-1. 진술문 규칙

**진술문은 마스터 원문만 쓴다. 한 글자도 바꾸지 않는다.**

마스터에 없으면 네 가지로만 처리한다. **지어내지 않는다.**

| 처리 | 실제 사례 |
|---|---|
| **대체** | `따뜻한 환경 제공함` → `담요를 덮어줌`<br>`심전도에서 불규칙한 리듬 관찰됨` → `불규칙 맥박 촉지됨`<br>`gas out 있음/없음` → `gas out 됨/안됨` |
| **제거** | `혈압약 투여` — 대체 중재 3개로 충분 |
| **★ 유지** | `음독 함 ★` · `감각지각장애:시각 ★` · `빛 반사 확인결과 prompt 함 ★` |
| **보류** | `금식 하도록 교육함` — 마스터엔 `2시간/6시간 금식…`만. 칩스 확인 대기 |

**자동 교정은 두 가지뿐**
- 띄어쓰기 — `비효율적 호흡양상` → `비효율적호흡양상`
- 대소문자 — `Wheezing 있음` → `wheezing 있음`

마스터에 원문이 **확실히 있을 때만** 고친다. 그 외는 손대지 않고 보고만 한다.

**형식 판정**

**★ 토글 버튼 글씨는 진술문에서 뽑는다 (2026-08-02 수정)**

> 「있음/없음」을 화면에 고정으로 박아두면 안 된다.

엑셀에 **음성이 먼저 적힌 줄**이 22개 있었다 (`오심, 구토 없음/오심, 구토 있음`).
앱은 첫 번째 진술문을 「있음」에 붙이므로, **「있음」을 눌렀는데 `오심, 구토 없음`이 기록됐다.**
오심·구토만 15개 경로에 걸려 있었다.

고친 방식은 **엑셀을 건드리지 않고**, 버튼 글씨를 진술문에서 직접 뽑는 것이다.
간호사가 **누른 글씨가 곧 기록**이므로 순서가 어떻든 뒤집히지 않는다.

```
진술문  오심, 구토 없음 / 오심, 구토 있음
화면    [ 없음 ] [ 있음 ]          ← 글씨를 진술문에서 뽑았다
```

앞의 공통 부분만 떼고 꼬리를 쓰되, 조각이 나거나 조사로 시작하면 원문을 그대로 쓴다.
`obey command 가능하지 않음/가능함` → 꼬리가 `함` 한 글자라 원문 두 개를 그대로 보여준다.

남은 것은 **진단 추천**이다. 추천은 아직 첫 진술문을 근거로 삼으므로,
극성이 뒤집힌 4건은 `_확인필요.txt`의 `[토글 극성 확인]`에 올려 칩스 판단을 기다린다.

| 형식 | 조건 | 예 |
|---|---|---|
| 토글 | 음성형이 마스터에 있음 | `열감 있음 / 열감 없음` |
| 체크 | 양성만 있음 | `경련 있음` (없을 때 기록 안 함) |
| 선택 | 3지 이상 | `prompt / sluggish / hippus` |
| 값입력 | 콜론으로 끝남 | `동공크기 :` · `INR :` |

**값은 진술문이 아니다**
`NRS 7점` · `substernal` · `쥐어짜는` 같은 값은 마스터에 없다 → **📌비고**로.
대신 **「쟀다」는 사실은 마스터 원문 P&E**로 남긴다 — `통증 강도 측정함` · `통증부위를 사정함` · `통증 양상을 확인함`.

**진단명은 마스터 7875~8079행 205개에서만.** 그 밖의 문구가 D칸에 있으면 오류다.

> ⚠️ 마스터엔 **끝 공백이 붙은 항목이 8개** 있다 (`출혈위험␣` `고칼륨혈증␣` `seizures␣` 등).
> 대조는 반드시 **공백 무시**로 해야 한다.

### 3-2. 질문 규칙

- **긍정형으로.** `"흉통은 없으신가요?"` ❌ → `"가슴이 아프세요?"` ✅
- **환자가 이해하기 쉽게.** 차팅 문구를 그대로 읽지 않는다
- **간호사가 설명하기 쉽게.** 화면을 그대로 읽으면 문진이 되도록
- **한 질문에 한 가지만.** `"토했나요? 몇 번이나?"` ❌ → 횟수는 📌비고로
- **질문은 마스터 제약을 받지 않는다.** 대상별로 달라도 된다

```
📋 호흡곤란 있음   ← 기록은 하나
   ├ 💬 성인: "숨이 차거나 답답하신가요?"
   └ 💬 소아: "아이가 숨쉬기 힘들어 보이나요?"
```

### 3-3. 기록 구조

**진단마다 [사정 → 진단 → 중재·평가]가 한 묶음.**

```
［출혈］
  A&E  dizziness 있음 · 객혈 있음 · 기침 있음
  D    출혈
  P&E  출혈 증상이 있는지 확인함 · 출혈양상 확인함
［급성통증］                      ← 통증 진단은 항상 마지막
  A&E  흉부 통증 있음
  D    급성통증
  P&E  통증을 인정해줌 · 통증 양상을 확인함 · 통증을 관찰하기로 함
［의식 · 낙상］                   ← 모든 환자에게 항상
  A&E  의식 명료함 · 보호자 환자 옆에 상주하고 있음
  D    낙상위험
  P&E  낙상방지 교육함 · 침대 난간을 올려줌
```

**★ 통증 룰 (HIS 루틴)**

> **어떤 통증이든 통증이 들어가면 간호진단은 항상 `급성통증`을 따로 낸다.**

- 통증 사정이 있는 **모든 경로(21개)에 `급성통증` 진단이 있다** — 2026-08-02 기준 누락 0
- 통증 진단 블록은 **경로 안에서 항상 마지막**
- 사정 내용을 다 넣은 뒤, **마지막에 통증을 묻고** 급성통증으로 잇는다
- 진단이 2개 이상이면 각각 [사정–진단–평가]로 나뉘고, 통증이 맨 뒤

### 3-4. 진단 규칙

- **추천 기준** — 그 진단만의 **고유 사정**이 양성일 때만 추천. 여러 진단이 함께 쓰는 항목(`dizziness` 등) 하나로는 추천되지 않는다
- **기본값** — 추천된 것만 켜짐. 간호사가 직접 켜고 끄면 그 선택이 우선
- **공통 처리** — 어느 진단 근거인지 애매하면 `공통`으로 두어 양쪽에 표시 (정보 누락 방지)

### 3-5. 미응답 규칙

**「안 물어봄」과 「물어보고 없음」은 다른 기록이다.**

| 상태 | 기록 |
|---|---|
| 미응답 | 아무것도 안 남음 |
| 있음 | `열감 있음` |
| 없음 | `열감 없음` |

화면에서 미응답은 **점선 테두리 + 「미응답」 표시**, 상단에 남은 개수를 띄운다.

### 3-6. 엑셀 작성법

**엑셀이 정본이다. 앱은 그걸 그릴 뿐이다.**

| 시트 | 내용 | 주의 |
|---|---|---|
| `1.주호소트리` | 주증상 → 분기질문 → 소분류 | 소분류가 `2.사정세트`와 정확히 일치 |
| `2.사정세트` | A&E · D · P&E + 진단연결 | **D칸엔 진단명만** |
| `3.환자설명` | 진단별 📢 문구 → 연동 P&E | 진단명 표기 일치 |
| `4.도관` | 순서 · 도관 · 정식명칭 · 진술문 | 순서 1~10이 기본 노출 |
| `5.낙상교육` | 말할 문구 ↔ 기록 진술문 | **분리해서 적을 것** |
| `6.마무리질문` | 마무리 질문 | |
| `7.통증공통` | 통증 위젯 전부 — 진통제 문항 · 측정 P&E · 부위/도구/양상/빈도/기간/SMC | 21개 경로에 **한 번만** 적는다 |

**`7.통증공통`을 따로 둔 이유**
통증은 21개 경로에 걸쳐 있다. 진통제 문항을 `2.사정세트`에 적으면 **똑같은 줄을 21번** 써야 하고,
한 곳만 고쳐도 어긋난다. 여기 한 번 적으면 빌드가 `급성통증` 진단이 있는 경로 전부에 붙인다.

| 과정 | 뜻 |
|---|---|
| `A&E` | 경로 질문으로 붙는다. `그룹`이 비어야 붙고, `투여후`면 접힘 블록에만 나온다 |

### 4-3. 그 밖의 규칙

- 글씨 크기 **12 · 14 · 16 · 19** 네 단계만
- 버튼 최소 높이 **48px** (장갑 착용 고려)
- 단계별 화면 분리 + 상단 진행 표시
- 클릭할 때 **스크롤 위치 유지** (단계 이동 시에만 맨 위로)

### 4-4. 시작 게이트

**네 가지 모두 필수. 우회로 없음.**

1. 환자 이름
2. 등록번호 (숫자 8자리)
3. 환자 확인 — 손위생 · 성함 · 팔찌 (한 번에 체크)
4. 맞이 교육 안내 — 귀금속 · 환의 · 금식

> 신원 확인이 안 되는 환자는 소생실로 가므로 이 앱을 쓸 상황이 아니다.
> 예외를 만들면 바쁠 때 그 길로 새기 마련이라 예외를 두지 않는다.
> **맞이 교육은 안내만 하고 간호기록에 남기지 않는다.**

### 4-5. 동공 크기

- **실물 동공자로 재고, 앱은 기록만** 한다. 화면을 자로 쓰지 않는다
- **1mm 단위 버튼 8개** (1~8mm), Rt · Lt 각각
- 참고표는 **접어둔다** — 펼치면 크기별 눈 그림과 임상 의미
- 화면 그림은 **실제 크기가 아님**을 명시
- 급할 때는 상태 버튼 — `동공이 확대됨` `동공이 수축됨` `동공크기가 pinpoint임` `동공이 고정되어 있음`

## 5. 통증 사정 (구현 완료 · 2026-08-02)

**통증은 중요하므로 빠뜨리지 않고 전부 묻는다.** 탭이 늘어나는 것은 감수한다.
`급성통증` 진단이 있는 **21개 경로**에 자동으로 뜬다.

| # | 항목 | 내용 |
|---|---|---|
| ① | 언제부터 | 구간 선택 — 오늘·며칠 전 / 1개월 미만 / 1~3개월 / **3개월 이상** / 모름 |
| ② | 부위 | 8곳 (복수) · 가슴 4 · 배 6은 자세한 위치까지 |
| ③ | 사정도구 | NRS · FPRS · FLACC · NIPS · CNPS |
| ④ | 강도 | NRS 0~10 / 도구가 FPRS면 **얼굴 6단계로 화면이 바뀐다** |
| ⑤ | 양상 | 8종 (복수) |
| ⑥ | 빈도 | 발작적 · 지속적 · 표현 못함 · 기타 |
| ⑦ | 부위별 추가질문 | **엑셀 경로 A&E가 이미 담당** — 위젯에서 중복하지 않는다 |
| ⑧ | SMC | 감각 · 운동 · 순환 — 여는 조건은 아래 |

**기간을 자유 입력이 아니라 구간 선택으로 한 이유** — 「2주 전쯤」 같은 말을 글로 받으면
만성 판정을 글자에서 캐내야 하고 빗나간다. 구간을 누르면 판정이 어긋나지 않는다.
**만성 기준 3개월**은 IASP / ICD-11 국제 표준을 따른다.

### 5-1. 무엇이 기록되는가

값은 마스터에 없으므로 **진술문이 아니다.** 대신 **「쟀다」는 사실만** 마스터 원문 P&E로 남긴다.

| 간호사가 한 일 | 기록 |
|---|---|
| 부위를 골랐다 | P&E `통증부위를 사정함` |
| 강도를 넣었다 | P&E `통증 강도 측정함` |
| 양상을 골랐다 | P&E `통증 양상을 확인함` |
| 기간이 3개월 이상 | A&E `만성 통증 있음` + 진단이 **`만성통증`으로 바뀐다** |
| 값 전부 | 📌비고 한 줄 |

```
［급성통증］
  A&E  진통제 원함
  D    급성통증
  P&E  통증부위를 사정함 · 통증 강도 측정함 · 통증 양상을 확인함
  📌   비고: 통증 — 기간 오늘·며칠 전 / 부위 가슴(substernal site)
              / 사정도구 NRS / 통증강도 7점 / 양상 날카로운 / 빈도 지속적
```

### 5-2. 진통제 (2026-08-02 확정)

> **아파도 참는 환자가 많아 반드시 묻는다.**

마스터를 다 뒤졌지만 **「의사에게 보고함」류 진술문은 없다.** 남길 수 있는 것은 결과뿐이라,
「의사가 줄지 물어보기」가 아니라 **「투여했는지」**로 적는다.

| 시점 | 문항 | 진술문 |
|---|---|---|
| 초기 사정 | "진통제를 맞고 싶으세요?" | `진통제 원함` / `진통제를 원하지 않음` |
| **투여 후** | 💊 진통제를 투여했나요? | `처방에 의해 진통제를 투여함` |
| 〃 | "통증이 좀 나아지셨어요?" | `진통제 투여 후 통증 감소됨` / `진통제 투여하였으나 통증 지속됨` |
| 〃 | "메스껍거나 어지러우세요?" | `진통제 투여 후 부작용 있음 / 없음` |
| 〃 | 투여 후 강도 재측정 | P&E `진통제 투여 후 통증 강도 측정함` |

**투여 후 4문항은 접어둔다.** 환자 도착 직후엔 아직 하지 않은 일이라,
펼쳐두면 계속 「미응답」으로 남아 눈을 어지럽힌다. 투여한 뒤 다시 열어 기록한다.

### 5-3. SMC — 허리·팔·다리 + 골절·외상 (2026-08-02 확정)

여는 조건은 **두 가지**다.

1. 고른 **부위가 허리 · 팔 · 다리**일 때 (엑셀 `7.통증공통`의 `그룹=SMC`)
2. 경로 진단에 **`말초신경혈관기능장애위험`**이 있을 때 → 골절·외상은 부위와 무관하게 열린다

정상이면 마스터 원문 `sensory, motor, circulation intact 함` 한 번으로 끝낸다.
감각·운동·순환을 4단계(양호함·약함·없음·평가불가)로 나눈 등급은 **마스터에 없어 📌비고**로 간다.

### 7-1-b. 토글 극성 — 진단 추천 근거

기록은 3-1의 수정으로 안전해졌다. 남은 것은 **진단 추천이 어느 쪽을 근거로 삼는가**이다.
아래 4건은 첫 진술문이 음성이라 확인이 필요하다. `_확인필요.txt`에도 같은 내용이 있다.

| 질문 | 현재 추천 근거 | 반대쪽 | 경로 |
|---|---|---|---:|
| "오심이나 구토가 있으세요?" | `오심, 구토 없음` | `오심, 구토 있음` | 15 |
| "따라 해보실 수 있으세요?" | `obey command 가능하지 않음` | `obey command 가능함` | 3 |
| "여기가 어디인지 아시겠어요?" | `사람에 대한 지남력 없음` | `사람에 대한 지남력 있음` | 1 |

기계로는 못 가린다. `오심, 구토 있음`은 이상소견이지만 `지남력 없음`도 이상소견이라,
「있음이 이상」이라는 규칙이 통하지 않는다. **어느 쪽이 진단 근거인지 임상 판단이 필요하다.**
