## 3. 간호기록 작성 룰

### 3-1. 진술문 규칙

**진술문은 마스터 원문만 쓴다. 한 글자도 바꾸지 않는다.**

마스터에 없으면 네 가지로만 처리한다. **지어내지 않는다.**

| 처리 | 실제 사례 |
|---|---|
| **대체** | `따뜻한 환경 제공함` → `담요를 덮어줌`<br>`심전도에서 불규칙한 리듬 관찰됨` → `불규칙 맥박 촉지됨`<br>`gas out 있음/없음` → `gas out 됨/안됨` |
| **제거** | `혈압약 투여` — 대체 중재 3개로 충분 |
| **★ 유지** | `음독 함 ★` · `감각지각장애:시각 ★` · `빛 반사 확인결과 prompt 함 ★` |
| **보류** | `금식 하도록 교육함` — 마스터엔 `2시간/6시간 금식…`만. 칩스 확인 대기 |

**자동 교정은 두 가지뿐**
- 띄어쓰기 — `비효율적 호흡양상` → `비효율적호흡양상`
- 대소문자 — `Wheezing 있음` → `wheezing 있음`

마스터에 원문이 **확실히 있을 때만** 고친다. 그 외는 손대지 않고 보고만 한다.

**형식 판정**

**★ 토글 버튼 글씨는 진술문에서 뽑는다 (2026-08-02 수정)**

> 「있음/없음」을 화면에 고정으로 박아두면 안 된다.

엑셀에 **음성이 먼저 적힌 줄**이 22개 있었다 (`오심, 구토 없음/오심, 구토 있음`).
앱은 첫 번째 진술문을 「있음」에 붙이므로, **「있음」을 눌렀는데 `오심, 구토 없음`이 기록됐다.**
오심·구토만 15개 경로에 걸려 있었다.

고친 방식은 **엑셀을 건드리지 않고**, 버튼 글씨를 진술문에서 직접 뽑는 것이다.
간호사가 **누른 글씨가 곧 기록**이므로 순서가 어떻든 뒤집히지 않는다.

```
진술문  오심, 구토 없음 / 오심, 구토 있음
화면    [ 없음 ] [ 있음 ]          ← 글씨를 진술문에서 뽑았다
```

앞의 공통 부분만 떼고 꼬리를 쓰되, 조각이 나거나 조사로 시작하면 원문을 그대로 쓴다.
`obey command 가능하지 않음/가능함` → 꼬리가 `함` 한 글자라 원문 두 개를 그대로 보여준다.

**★ 어느 답이 「추천」을 띄우는가 — `9.추천근거` (2026-08-02 확정)**

기록과 별개로, 앱은 **어느 답이 이상소견인지** 알아야 「추천」 배지를 띄운다.
그런데 **「있음이면 이상」이라는 규칙은 만들 수 없다.**

| 질문 | 있음 | 없음 | 이상한 쪽 |
|---|---|---|---|
| "오심이나 구토가 있으세요?" | 토했다 | 안 토했다 | **있음** |
| "여기가 어디인지 아시겠어요?" | 지남력 있다 | 지남력 없다 | **없음** |

구토는 **증상**이라 있는 게 이상이고, 지남력은 **능력**이라 없는 게 이상이다.
글자는 둘 다 `있음/없음`이라 기계가 못 가린다. 그래서 **엑셀 `9.추천근거`에
이상소견 진술문을 적어두고** 빌드가 그것을 기준으로 삼는다.

확정된 4건 — 나머지는 첫 진술문이 이상소견이라 그대로 둔다.

| 이상소견으로 지정 | 이유 |
|---|---|
| `오심, 구토 있음` | 15경로. 엑셀엔 「없음」이 먼저 적혀 있었다 |
| `grasp power 약함` | 두통 경로는 「강함」이 먼저라 정상일 때 추천이 떴다 |
| `obey command 가능하지 않음` | 의식·낙상 경로 |
| `사람에 대한 지남력 없음` | (이미 첫 번째라 결과는 그대로) |

빌드가 `_확인필요.txt`에 **토글 전체 감사 목록**을 뽑는다.
훑어보다 「이건 반대인데」 싶은 줄이 있으면 `9.추천근거`에 진술문을 적으면 된다.

| 형식 | 조건 | 예 |
|---|---|---|
| 토글 | 음성형이 마스터에 있음 | `열감 있음 / 열감 없음` |
| 체크 | 양성만 있음 | `경련 있음` (없을 때 기록 안 함) |
| 선택 | 3지 이상 | `prompt / sluggish / hippus` |
| 값입력 | 콜론으로 끝남 | `동공크기 :` · `INR :` |

**값은 진술문이 아니다**
`NRS 7점` · `substernal` · `쥐어짜는` 같은 값은 마스터에 없다 → **📌비고**로.
대신 **「쟀다」는 사실은 마스터 원문 P&E**로 남긴다 — `통증 강도 측정함` · `통증부위를 사정함` · `통증 양상을 확인함`.

**진단명은 마스터 7875~8079행 205개에서만.** 그 밖의 문구가 D칸에 있으면 오류다.

> ⚠️ 마스터엔 **끝 공백이 붙은 항목이 8개** 있다 (`출혈위험␣` `고칼륨혈증␣` `seizures␣` 등).
> 대조는 반드시 **공백 무시**로 해야 한다.

### 3-2. 질문 규칙

- **긍정형으로.** `"흉통은 없으신가요?"` ❌ → `"가슴이 아프세요?"` ✅
- **환자가 이해하기 쉽게.** 차팅 문구를 그대로 읽지 않는다
- **간호사가 설명하기 쉽게.** 화면을 그대로 읽으면 문진이 되도록
- **한 질문에 한 가지만.** `"토했나요? 몇 번이나?"` ❌ → 횟수는 📌비고로
- **질문은 마스터 제약을 받지 않는다.** 대상별로 달라도 된다

```
📋 호흡곤란 있음   ← 기록은 하나
   ├ 💬 성인: "숨이 차거나 답답하신가요?"
   └ 💬 소아: "아이가 숨쉬기 힘들어 보이나요?"
```

- 통증 사정이 있는 **모든 경로(21개)에 `급성통증` 진단이 있다** — 2026-08-02 기준 누락 0

- 사정 내용을 다 넣은 뒤, **마지막에 통증을 묻고** 급성통증으로 잇는다

### 3-3-c. 같은 줄은 한 번만 · 의식은 한 곳에서만 (2026-08-02)

**★ 같은 진술문은 기록 전체에서 한 번만 찍는다.**

`공통`으로 둔 사정은 진단마다 복사된다. EMR에 `dizziness 있음`이 두 번 나오면
**두 번 사정한 것으로 읽힌다.** 먼저 나온 자리에 남기고 뒤는 접는다.
접고 나서 남는 줄이 없으면 **블록 제목도 찍지 않는다.**

| | 전 | 후 |
|---|---:|---:|
| 한 환자 기록에 같은 줄이 두 번 이상 | **14경로** | **0** |
| 빈 블록 | 1 | **0** |

**★ 의식은 🧠 블록으로 옮겼다.**

전에는 마지막 「의식·낙상」 화면이 **모든 환자에게** GCS·지남력을 물었다.
그런데 `의식섬망`·`의식 및 낙상위험 평가` 경로가 같은 것을 이미 묻는다.
둘이 다르게 답하면 한 기록에 `사람에 대한 지남력 없음`과 `있음`이 **함께 남았다.**

```
전   🔒 의식 · 보호자 · 낙상    GCS · 지남력 · 보호자 · 낙상교육
후   🧠 의식 · 신경학적 평가    GCS · 지남력 · 신경학 5항목   ← 접힘, 필요할 때만
     🔒 보호자 · 낙상          보호자 · 낙상교육             ← 두 번만 누르면 끝
```

의식 사정 능력은 그대로다. **자리만 옮겨 중복을 없앴다.**

**★ `의식 및 낙상위험 평가` 경로를 지웠다 (2026-08-02)**

이 경로는 **주호소 트리에 항목이 없어 애초에 고를 수 없었다.** 죽은 데이터였다.
하는 일도 고정 블록과 거의 같았다 — 의식 · 보호자 · 낙상교육.

| 그 경로에 있던 것 | 지금 어디에 |
|---|---|
| 의식 명료함 · 지남력 3종 | 🧠 블록 |
| `의식수준 :` | 🧠 블록 (`8.신경학공통`으로 옮김) |
| obey command | 🧠 블록 (이미 있었음) |
| 보호자 2종 | 🔒 보호자·낙상 (고정) |
| 낙상교육 P&E 5종 | `5.낙상교육` → 고정 블록 |

**잃은 것은 없다.** 경로 51 → 50, 질문 144 → 138,
`질문문구없음` 경고 8건 → **1건**(7건이 이 경로의 「확인하세요」였다).

지남력이 셋 다 없으면 마스터의 합본 한 줄 `시간, 사람, 장소에 대한 지남력 없음`을 쓴다.

### 3-3-b. 평가 규칙 — 자동과 수동 (2026-08-02 구현)

**간호기록을 많이 입력할 시간이 없다.** 사정은 제대로 하되 평가를 하나씩 누르는 부담은 줄인다.

P&E를 성격으로 나눈다.

| 성격 | 판정 | 화면 | 예 |
|---|---|---|---|
| **자동** | 그 사정을 했으면 **반드시 참** | `자동` 배지 · 켜져 있음 | `출혈양상 확인함` · `체온 측정함` |
| **수동** | 실제로 해야 참 | 눌러야 켜짐 | `처방에 의해 D50W 을 투여함` · `담요를 덮어줌` |

`출혈양상 확인함`은 출혈 사정을 한 순간 이미 한 것이다. 또 누르게 할 이유가 없다.
**자동이라도 간호사가 끄면 그 선택이 우선한다.** 안 물어본 진단에는 붙지 않는다.

```
［출혈］
  말하고 누르세요
    📢 "출혈이 더 있는지 살펴보겠습니다"   → 출혈 증상이 있는지 확인함
  사정했으니 자동으로 기록됩니다 — 아니면 끄세요
    [자동] 📢 "출혈 양상을 확인하겠습니다"  → 출혈양상 확인함
```

| | 지금 |
|---|---:|
| 눌러야 하는 평가 (전 경로) | 210 → **119** (43% 감소) |
| 경로당 평균 | 4.1 → **2.3** |
| 아예 안 눌러도 되는 경로 | **6개** |

목록은 엑셀 **`11.평가자동`** (자동 21종). 애매한 5종은 수동으로 두었고 시트 아래에 이유와 함께 적어두었다 — 자동으로 돌리려면 위로 옮기면 된다.

### 3-4. 진단 규칙

- **추천 기준** — 그 진단만의 **고유 사정**이 양성일 때만 추천. 여러 진단이 함께 쓰는 항목(`dizziness` 등) 하나로는 추천되지 않는다
- **기본값** — 추천된 것만 켜짐. 간호사가 직접 켜고 끄면 그 선택이 우선
- **공통 처리** — 어느 진단 근거인지 애매하면 `공통`으로 두어 양쪽에 표시 (정보 누락 방지)

**★ 「공통」은 1~2개짜리 장치다 (2026-08-02)**

`진단연결`을 비워두면 그 사정이 **모든 진단에 복사**된다. 애매한 한두 개를 위한 규칙인데,
V4 B영역을 엑셀로 옮길 때(8/1) **A&E의 진단연결을 통째로 안 채워서** 전부 공통이 되어 있었다.
P&E는 채워져 있었으니 이관 누락이다.

그 결과 어지럼 환자 EMR에 `dizziness 있음`이 **두 번** 찍혔다.
읽는 사람은 두 번 사정한 줄 안다.

| 경로 | A&E 줄 (전 → 후) | 비고 |
|---|---|---|
| 정신과 | 15 → **5** | 자살3 / 공격1 / 공황1 로 1:1 |
| 의식섬망 | 20 → **10** | 신경학 7 → 뇌 · 금단 3 → 알코올금단증 |
| 안과 | 18 → **6** | **`신체손상위험` 진단을 뺐다** |
| 어지럼 | 18 → **11** | `dizziness`·`오심 구토`는 **공통 유지** |
| 골절외상 | 10 → **5** | edema·tingling → 말초신경혈관기능장애위험 |
| 혈압 | 10 → **6** | 혈압값만 공통 |
| 소화기 | 8 → **4** | |
| 피부 | 6 → **3** | `urticaria`는 **손상**으로 |
| **합계** | **105 → 50** | **52% 감소** |

진단 추천도 같이 정확해졌다 — `혈압 상승됨`은 고혈압만, `변비 있음`은 변비만 추천한다.
전에는 자살 충동 하나만 답해도 폭력위험·불안까지 추천됐다.

**안과에서 `신체손상위험`을 뺀 이유** — 세 진단 중 그것만 근거가 될 사정이 없었다.
시력 저하로 넘어질 위험은 **모든 환자에게 붙는 `낙상위험`이 이미 담당**한다.
딸려 있던 P&E 2개(`안대 적용함` · `안전간호를 제공함`)는 `감각지각장애 : 시각`에
같은 것이 있어 **손실이 없다.**

### 3-5. 미응답 규칙

**「안 물어봄」과 「물어보고 없음」은 다른 기록이다.**

**★ 「물어봤는데 기록이 없음」도 안 된다 (2026-08-02 추가)**

간호사가 진단을 끄면 그 진단에 매달린 사정이 **통째로 사라지고 있었다.**
SMC 세 항목을 다 재고 진단을 끄면 남는 줄이 **0개**였다. 통증도 같은 구조라
`급성통증`을 끄면 NRS·부위·양상·기간이 전부 증발했다.

갈 곳을 잃은 답은 **`［사정 — 진단 미선택］`** 블록으로 거둔다. 진단(D)은 붙이지 않는다.

```
［사정 — 진단 미선택］
  A&E  골절 있음 · 골절부위 tingling sense 있음
  P&E  통증부위를 사정함 · 통증 강도 측정함
  📌   비고: SMC — Sensory 없음 / Motor 약함 / Circulation 양호함
```

진단을 켜면 예전처럼 진단 블록 안으로 들어가고 이 블록은 생기지 않는다.
잘못 답한 것은 **같은 버튼을 다시 눌러 미응답으로 되돌리면** 기록에서 사라진다.

| 상태 | 기록 |
|---|---|
| 미응답 | 아무것도 안 남음 |
| 있음 | `열감 있음` |
| 없음 | `열감 없음` |

화면에서 미응답은 **점선 테두리 + 「미응답」 표시**, 상단에 남은 개수를 띄운다.

### 4-4. 시작 게이트

**세 가지 모두 필수. 우회로 없음.**

1. **등록번호 (숫자 8자리)**
2. 환자 확인 — 손위생 · 성함 · 팔찌 (한 번에 체크)
3. 맞이 교육 안내 — 귀금속 · 환의 · 금식

**★ 이름은 받지 않는다 (2026-08-02)**

환자를 가리는 것은 **등록번호**다. 이름은 동명이인이 있고 오타가 나며,
화면에 띄워두면 어깨너머로 보인다. **손으로 적을 이유가 없다.**

이름 확인은 사라지지 않았다 — 2번의 `🗣️ "성함이 어떻게 되세요?"`가 그대로다.
**말로 묻고 팔찌로 대조하되, 타이핑은 안 한다.**

등록번호가 유일한 입력이므로 틀리지 않게 만들었다.

```
       [ 1 2 3 4 5 6 7 8 ]        큰 글씨 · 자간 넓게 · 가운데 정렬
       ▬ ▬ ▬ ▬ ▬ ▬ ▬ ▬          자릿수 표시 · 8자리 차면 초록
```

- **숫자만 남긴다** — 하이픈·문자를 붙여넣어도 걸러진다
- 8자리를 넘겨 붙여넣으면 앞 8자리만 취한다
- 8자리가 차야 「시작」이 열린다

기록 상단에는 `등록번호 12345678`만 뜬다.

> 신원 확인이 안 되는 환자는 소생실로 가므로 이 앱을 쓸 상황이 아니다.
> 예외를 만들면 바쁠 때 그 길로 새기 마련이라 예외를 두지 않는다.
> **맞이 교육은 안내만 하고 간호기록에 남기지 않는다.**

### 4-5. 동공 크기

- 급할 때는 상태 버튼 — `동공이 확대됨` `동공이 수축됨` `동공크기가 pinpoint임` `동공이 고정되어 있음`

## 5. 통증 사정 (구현 완료 · 2026-08-02)

**통증은 중요하므로 빠뜨리지 않고 전부 묻는다.** 탭이 늘어나는 것은 감수한다.
`급성통증` 진단이 있는 **21개 경로**에 자동으로 뜬다.

| # | 항목 | 내용 |
|---|---|---|
| ① | 언제부터 | 구간 선택 — 오늘·며칠 전 / 1개월 미만 / 1~3개월 / **3개월 이상** / 모름 |
| ② | 부위 | 8곳 (복수) · 가슴 4 · 배 6은 자세한 위치까지 |
| ③ | 사정도구 | NRS · FPRS · FLACC · NIPS · CNPS |
| ④ | 강도 | NRS 0~10 / 도구가 FPRS면 **얼굴 6단계로 화면이 바뀐다** |
| ⑤ | 양상 | 8종 (복수) |
| ⑥ | 빈도 | 발작적 · 지속적 · 표현 못함 · 기타 |
| ⑦ | 부위별 추가질문 | **엑셀 경로 A&E가 이미 담당** — 위젯에서 중복하지 않는다 |
| ⑧ | SMC | 감각 · 운동 · 순환 — 여는 조건은 아래 |

**기간을 자유 입력이 아니라 구간 선택으로 한 이유** — 「2주 전쯤」 같은 말을 글로 받으면
만성 판정을 글자에서 캐내야 하고 빗나간다. 구간을 누르면 판정이 어긋나지 않는다.
**만성 기준 3개월**은 IASP / ICD-11 국제 표준을 따른다.

### 5-1. 무엇이 기록되는가

값은 마스터에 없으므로 **진술문이 아니다.** 대신 **「쟀다」는 사실만** 마스터 원문 P&E로 남긴다.

| 간호사가 한 일 | 기록 |
|---|---|
| 부위를 골랐다 | P&E `통증부위를 사정함` |
| 강도를 넣었다 | P&E `통증 강도 측정함` |
| 양상을 골랐다 | P&E `통증 양상을 확인함` |
| 기간이 3개월 이상 | A&E `만성 통증 있음` + 진단이 **`만성통증`으로 바뀐다** |
| 값 전부 | 📌비고 한 줄 |

```
［급성통증］
  A&E  진통제 원함
  D    급성통증
  P&E  통증부위를 사정함 · 통증 강도 측정함 · 통증 양상을 확인함
  📌   비고: 통증 — 기간 오늘·며칠 전 / 부위 가슴(substernal site)
              / 사정도구 NRS / 통증강도 7점 / 양상 날카로운 / 빈도 지속적
```

### 5-2. 진통제 (2026-08-02 확정)

> **아파도 참는 환자가 많아 반드시 묻는다.**

마스터를 다 뒤졌지만 **「의사에게 보고함」류 진술문은 없다.** 남길 수 있는 것은 결과뿐이라,
「의사가 줄지 물어보기」가 아니라 **「투여했는지」**로 적는다.

| 시점 | 문항 | 진술문 |
|---|---|---|
| 초기 사정 | "진통제를 맞고 싶으세요?" | `진통제 원함` / `진통제를 원하지 않음` |
| **투여 후** | 💊 진통제를 투여했나요? | `처방에 의해 진통제를 투여함` |
| 〃 | "통증이 좀 나아지셨어요?" | `진통제 투여 후 통증 감소됨` / `진통제 투여하였으나 통증 지속됨` |
| 〃 | "메스껍거나 어지러우세요?" | `진통제 투여 후 부작용 있음 / 없음` |
| 〃 | 투여 후 강도 재측정 | P&E `진통제 투여 후 통증 강도 측정함` |

**투여 후 4문항은 접어둔다.** 환자 도착 직후엔 아직 하지 않은 일이라,
펼쳐두면 계속 「미응답」으로 남아 눈을 어지럽힌다. 투여한 뒤 다시 열어 기록한다.

### 5-3. SMC — 허리·팔·다리 + 골절·외상 (2026-08-02 확정)

여는 조건은 **두 가지**다.

1. 고른 **부위가 허리 · 팔 · 다리**일 때 (엑셀 `7.통증공통`의 `그룹=SMC`)
2. 경로 진단에 **`말초신경혈관기능장애위험`**이 있을 때 → 골절·외상은 부위와 무관하게 열린다

정상이면 마스터 원문 `sensory, motor, circulation intact 함` 한 번으로 끝낸다.
감각·운동·순환을 4단계(양호함·약함·없음·평가불가)로 나눈 등급은 **마스터에 없어 📌비고**로 간다.

## 5-4. 신경학적 평가 (구현 완료 · 2026-08-02)

**발동은 ㉰ 둘 다** — 자동으로 뜨는 경로가 있고, 나머지는 버튼으로 연다.

```
🧠 신경학적 평가                    ← 접힌 버튼 · 모든 경로에 있다
   동공 크기 · 빛 반사 · 감각이상 · grasp power · obey command
```

### 기존 경로를 건드리지 않은 이유

신경학 4항목이 **8개 경로에 복사되어** 있다. 이것을 공통 블록 하나로 합치려 했으나,
데이터를 열어보니 합치면 **임상 내용이 조용히 바뀐다.**

| 항목 | 경로마다 다른 것 |
|---|---|
| 질문 문구 | 감각이상 **3종** · grasp power **2종** · obey command **3종** |
| 진단연결 | 급성통증 · 저체온 · 조직관류저하:뇌 · 신체손상위험 · 낙상위험 · (없음) |

하나로 합치면 **문구를 하나 골라야 하고**, 그 순간 다른 경로의 문구가 바뀐다.
진단연결도 잃는다. 그래서 **기존 행은 그대로 두고**, 빠진 항목만 채우는 방식으로 갔다.

| 경로 | 버튼으로 추가되는 항목 |
|---|---:|
| 어지럼 · 중독 · 의식섬망 | 0 (이미 5개 다 있음) |
| 두통 · 저체온 · 뇌경색/뇌출혈 | 1 (obey command) |
| Seizure 2경로 | 3 |
| **저혈당 등 나머지 41경로** | **5 (전부)** |

기존 경로에 새 항목이 저절로 붙지 않는다. 간호사가 버튼을 눌러야만 열린다.

### 기록

신경학은 특정 진단에 매이지 않으므로 **독립 블록**으로 뺀다.
진단마다 붙이면 진단 수만큼 같은 줄이 반복된다.

```
［신경학적 평가］
  A&E  동공크기 : 3 · 감각이상 있음 · grasp power 약함
```

**저혈당 경로는 자동으로 열지 않는다.** 이미 저혈당인 줄 아는데 신경학을 펼칠 이유가 없다.
대신 방향을 뒤집어 — **신경학이 이상하면 혈당을 재게** 한다 (5-5).

## 5-5. 후속 사정 — 신경학 이상 → 혈당 (구현 완료 · 2026-08-02)

> **경고 배지가 아니다. 「질문이 하나 늘어나는 것」이다.**

작업계획 §0에 **「위험신호 배지·경고 표시는 하지 않는다」**(트리아지·KTAS 몫)고 적혀 있다.
이것은 그 원칙을 어기지 않는다. 성격이 다르기 때문이다.

| | 위험신호 배지 | 후속 사정 |
|---|---|---|
| 말하는 것 | "이 환자 위험하다" | "이거 아직 안 물었다" |
| 누구 몫 | KTAS · 트리아지 | **이 앱** |

그래서 새 장치를 만들지 않고 **이미 있는 「미응답」을 그대로 쓴다.**
문항이 하나 늘어나고, 답할 때까지 점선 테두리로 남으며, 상단 카운터에도 잡힌다.

```
🧠 신경학적 평가
   감각이상          없음  [있음]
   grasp power     [약함] 강함        ← 이상소견

● 신경학적 이상이 보입니다 — 이것부터 확인하세요
   🩺 혈당을 재세요    [증가함] [떨어짐] [정상 범위임]     ⌐미응답¬
```

### 발동 조건

`8.신경학공통`의 5항목 중 **이상소견이 하나라도** 나오면 뜬다.
어느 답이 이상인지는 `9.추천근거`가 정한다 — 3-1에서 만든 장치를 그대로 쓴다.

| 형식 | 이상 판정 |
|---|---|
| 토글 | `9.추천근거`가 지정한 쪽 (`감각이상 있음` · `grasp power 약함` 등) |
| 선택 | 〃 — **빛 반사는 `prompt`가 정상**, `sluggish`·`hippus`가 이상 |
| 값입력 | **판정하지 않음** — 동공 3mm이 정상인지 앱은 모른다 |

### 뜨지 않는 경우

**이미 혈당을 묻고 있는 경로**에서는 뜨지 않는다 (`저혈당` · `고혈당`).
`생략조건` 열에 적은 낱말이 그 경로 진술문에 있으면 빌드가 걸러낸다.

초진에서 이미 쟀는데 또 떠도 손해는 아니다. 아는 값을 눌러 기록으로 남기면 된다.

### 기록

```
［신경학적 평가］
  A&E  감각이상 있음 · grasp power 약함 · 혈당 떨어짐
  P&E  혈당 검사 시행함
```

> ⚠️ 의식이 떨어지는 원인은 혈당 말고도 많다(뇌졸중·저산소·약물·감염).
> **혈당만 띄우는 것은 「가장 싸고 빠르게 되돌릴 수 있는 것 하나」라서**이지
> 감별을 다 한다는 뜻이 아니다. 나머지는 이 앱 범위 밖이다.

### 8-6. ✅ 해결 — 📢 환자설명이 경로를 넘어 섞이던 문제

`3.환자설명` 시트가 **진단명만으로** 매핑되는데, 같은 진단명을 여러 경로가 나눠 쓴다.
`신체손상위험` 하나를 **6경로**(Seizure×3 · 어지럼 · 골절외상 · 안과)가 공유한다.
게다가 화면 코드가 explain이 있으면 그 경로의 P&E를 **덮어쓴다.**

```
경련 환자  →  골절부위 압박붕대 감아줌 · 골절부위 올려줌 · 안대 적용함
골절 환자  →  Seizure시 안전간호 시행함 · Seizure 양상을 확인함
```

**진단블록 76개 중 17개가 오염**돼 있다 (뇌경색 4 · 어지럼 6 · 안과 7 · 소아경련 7 …).
3-3(진단마다 한 묶음)과 0장(의료 안전) 정면 위배 — **잘못된 중재가 EMR에 들어간다.**

**더 나빴던 것 — 반대편 손실**

화면 코드가 `explain`이 있으면 **그것만** 보여주고 있었다. 그래서 📢 문구가 없는
경로 P&E는 **영영 안 보였다.** 간호사가 누를 방법이 없었다.

| 안 보이던 처치 | 경로 |
|---|---|
| `처방에 의해 D50W 을 투여함` | 저혈당 |
| `처방에 의해 Lorazepam 을 투여함` | 지금 Seizure 할 때 |
| `처방에 의해 해열제를 투여함` · `미온수 목욕 시행함` | 소아-발열 |
| `처방에 의해 인슐린 투여함` | 고혈당 |
| `담요를 덮어줌` | 저체온 |
| `산소 흡입 시작함` · `산소포화도 monitor 함` | 심부전 2경로 |

**총 12종 18자리.** 저혈당에 포도당, 경련에 항경련제, 발열에 해열제가 없었다.

**고친 방식** — 기준을 `explain`이 아니라 **그 경로의 `dx.pe`**로 바꿨다.
경로가 가진 P&E를 전부 보여주되, 📢 문구가 있으면 붙이고 없으면 진술문만 보여준다.

```
📢 "체온 측정해 드릴게요."        → 체온 측정함
▸  (말할 문구 없음)              → 미온수 목욕 시행함        ← 살아났다
▸  (말할 문구 없음)              → 처방에 의해 해열제를 투여함  ← 살아났다
```

**잃은 것은 없다.** 걸러진 61개 중 58개는 제 경로에서 그대로 보인다.
남은 3개(`Seizure시 안전간호 시행함` · `Seizure 양상을 확인함` · `따뜻한 환경 제공함`)는
어느 경로에도 없던 것이고, 셋 다 경로에 **표기만 다른 같은 중재가 이미 있다.**

> 남은 판단 — 표기 통일 2쌍.
> `seizure 양상 확인함`(경로·마스터○) ↔ `Seizure 양상을 확인함`(📢·마스터✕)
> `seizure 유발요인 확인함`(경로·마스터✕) ↔ `seizure의 유발요인을 확인함`(📢·마스터○)
