# 응급실 커버리지 점검 — KTAS 2021 대조 (2026-08-02)

> **1~3차 보완 반영됨** (같은 날). 아래 수치는 보완 후다.
> ✅ 64 → 70 → 78 → **87** · ❌ 92 → 86 → 77 → **68**
> 온전히 커버 37% → 40% → 45% → **50%**

> **물음** — 어떤 환자가 와도 다 물어볼 수 있나?
> **방법** — KTAS 2021 공식 주호소 **178항목**(`트리야지_주호소_전체분류_260711.md`)에
> 간호기록 V6의 **27주호소 · 50경로 · 진술문 188종**을 하나씩 대조했다.

| 판정 | 수 | 뜻 |
|---|---:|---|
| ✅ 커버 | **87** | 물어볼 문항이 있다 |
| △ 부분 | **16** | 우회로만 있거나 일부만 |
| ❌ 없음 | **68** | 물어볼 방법이 없다 |
| 제외 | 7 | 소생실·처치기록 — 이 앱 대상 아님 |

**대상 171항목 중 온전히 커버 87 (50%) · 부분 포함 103 (60%)**

> ⚠️ 이 숫자는 **항목 수** 기준이다. 환자 수 기준이 아니다.
> 흉통·호흡곤란·복통·발열·출혈처럼 **흔한 주호소는 대부분 ✅**이고,
> ❌는 롱테일에 몰려 있다. 다만 아래 「계통째 빈 곳」은 빈도와 무관하게 문제다.

## 1. 계통째 비어 있는 곳

| 계통 | 커버 | 빠진 것 |
|---|---|---|
| 산과/여성 | 1 / 10 | 임신 20주 전후 · 출산 후 문제 · 월경 · 성폭행 — **질출혈 하나만 있다** |
| 피부 | 5 / 18 | **화상 · 열상 · 물림 · 쏘임 · 봉와직염** 전무 |
| 환경손상 | 1 / 7 | **열사병 · 익수 · 전기손상 · 화학물질 노출** 전무 |
| 외상 | 1 / 12 | 부위 구분이 없다. 골절외상 **1경로**로 통합 — 두부·흉부·복부·안면 외상 구분 불가 |
| 소아 | 4 / 14 | **신생아 전무**(수유곤란·황달) · **학대 스크리닝 없음** · 소아 외상 없음 |
| 호흡기 | 3 / 7 | **아나필락시스/알레르기** — 요구사항정의서에도 미구현으로 적혀 있다 |

## 2. 흔한데 빠진 단일 항목 — 우선순위 높음

| 빠진 것 | 상태 |
|---|---|
| **인후통** | ✅ 이비인후 ← `인후 불편감`·`인후 충혈` + 급성통증 |
| **눈 통증** | ✅ 안과 ← `안구통증` + 급성통증 |
| **옆구리 통증** | ✅ 비뇨기 ← `옆구리 통증` + 급성통증 |
| **전신 쇠약** | ✅ 경로 신규 (`활동의 지속성장애`) |
| **알레르기 반응** | ✅ 아나필락시스 경로 신규 (`알레르기반응`·`기도개방유지불능`) |
| **화상** | ✅ 경로 신규 (`피부손상`·`감염위험`·`급성통증`) |
| **이통** | ❌ **보류 — 마스터에 「귀 통증」 진술문이 없다.** 지어낼 수 없다 |
| 경증 비특이 증상 | ❌ 남음 |
| 물림 · 쏘임 | ❌ 남음 |

> **이통을 못 넣은 이유** — 마스터 10,304개를 뒤졌지만 `이통`·`귀 통증`·`외이`·`중이` 어느
> 표현으로도 통증 진술문이 없다. 가장 가까운 것이 `귀가 멍멍하다고 호소함`인데 다른 뜻이다.
> 0장 절대규칙에 따라 **지어내지 않고 비워 둔다.** 칩스님이 쓸 만한 마스터 원문을
> 지정해 주시면 바로 넣겠다.

## 5. 점검 중 찾은 버그 — 고쳤다

**「이상 없음」을 고르고 사정으로 넘어가면 앱이 죽었다.**
주호소에는 있는데 경로가 빈 문자열이라, 분기 화면과 사정 화면이 서로를 무한히 부르며
`Maximum call stack size exceeded`로 화면이 하얘졌다.
이제 「사정할 항목이 없습니다」를 띄우고 마무리로 넘어간다.

## 6. 성폭행 — 일부러 만들지 않았다

마스터에 진술문(`성폭행이 보고됨` · `성폭행 의심됨` · `성폭행의 증거 있음` ·
`성폭행에 대해 표현 못함`)과 진단(`강간상해증후군`)이 모두 있다. **기술적으로는 만들 수 있다.**

만들지 않은 이유는 **증거 보존·의무 신고·연계 절차가 이 앱의 범위 밖**이기 때문이다.
