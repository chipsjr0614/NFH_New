# 통합간호기록 V8 — 5층 재설계

**파일:** `app/간호기록V8.html` (2026-08-08)
**요청(칩스 260808):** "너무 복잡하다. 기본 3질문 하고, 주호소 안에서 진단 1개, 통증은 따로, 낙상위험은 디폴트."

## 1. 왜 고쳤나 — V7의 문제 (데이터로 확인)

| 문제 | 실측 |
|------|------|
| 경로를 고르는 단계에서 이미 임상 판단을 요구 | 호흡곤란이 **5갈래**(가래 양·천명음·심부전+흉통) — 숨차다는 환자 앞에서 폐렴인지 천식인지 먼저 정해야 진행 |
| 통증 유무로 경로가 쌍으로 갈림 | **12쌍 24경로**가 거의 완전 중복. `고체온+통증없음`과 `고체온+통증있음`의 잔여 문항이 **똑같이 3개** |
| 진단이 여러 개면 사정도 배로 늘고 겹침 | 호흡곤란(심부전+흉통) 14문항 중 **5개가 두 진단에 중복** |
| 진단 과다 | 최대 4개 + 낙상위험. 앱이 `⚠️ 간호진단이 3개입니다` 경고로 때우고 있었음 |
| 버튼이 4종류 | 토글 143 · 체크 52 · 선택 8 · 값입력 4 |

### 체크형(단일 버튼)이 이상해 보였던 진짜 이유

체크형 52개의 **부정 진술문이 마스터에 있는지 전부 대조**한 결과:
- 부정형이 있음 → **9개**(`seizure 있음↔없음` 등)
- 부정형이 **없음 → 43개** (`산소 흡입 중임`·`혈당 증가함`·`혈압 저하됨`…)

43개는 전부 **재봐야 아는 값**(Hb·혈소판·CRP·INR·K·Na·혈압·맥박·SpO2·혈당·체온·소변량)이다.
마스터가 "이상할 때만 쓰는 문장"으로 만든 것이고 **정상이면 적을 문장이 없다.**
→ 설계 실수가 아니라 마스터 제약. 임의로 `산소 흡입 안함` 같은 문장을 만들 수 없다.

## 2. V8 구조 — 5층

```
0층 🔌 도관 · 튜브      25종(자주 쓰는 10종 먼저) · 없으면 넘어가기
1층 🩺 기본 3질문       어지럼 · 호흡곤란 · 오심/구토        [있음][없음]
2층 🎯 주호소 1~2개     (+부위) 물어보는 2~11개              → 진단 1개(자동)
3층 😣 통증             부위 → 강도 → 양상 → 빈도 → 기간     → 급성통증
4층 🧠 의식 · 낙상      의식(+지남력·GCS·근력) · 보호자      → 낙상위험(무조건)
```

**진단은 최대 3개** — 주호소 1 + 급성통증 + 낙상위험.

### ★ 간호진단은 자동으로 정해진다 (칩스 260808)

RN이 고르는 대신, **사정에서 양성이 나온 진단 중 우선순위 1위**가 자동 선택된다. 눌러서 바꿀 수도 있다.

```
외상 → "피가 나나요?" [없음] → 신체손상위험
                      [있음] → 출혈          (활동성 출혈이 우선)
```

**우선순위 (🔶 칩스 확정 필요 — ABC·생명위협 순으로 AI가 초안 작성)**
```
기도개방유지불능 > 알레르기반응 > 비효율적호흡양상 > 출혈 > 조직관류저하(심폐계·뇌) >
부정맥 > 고혈압 > 자살위험 > 폭력위험 > 신체손상위험 > 중독위험 >
고·저혈당 > 전해질(고칼륨·저칼륨·고나트륨) > 고·저체온 > 체액부족위험 >
감염 > 감염위험 > 출혈위험 > 피부손상 > 배뇨장애 > … > 안위변화
```

### 부위·상황 (외상·피부·중독·체온에서만)

```
외상 → 어디를 다치셨어요?  [머리][얼굴][목·척추][가슴][배][팔다리]
피부 → 뭐가 있나요?        [물림][쏘임][열상][발진][화상]…
```
부위를 고르면 **그 부위의 사정 문항이 따라오고 진단 후보에도 들어간다.**
(머리 → `조직관류저하:뇌` + 신경학적 증상 확인 / 목·척추 → `말초신경혈관기능장애위험` + SMC)
다만 근거 문항에 답하지 않으면 자동 선택되지 않는다 — **외상의 기본은 `신체손상위험`.**

### 신경 사정은 무조건 (칩스 260808)

**두통 · 뇌경색/뇌출혈 · Seizure · 어지럼 · 의식/섬망 · 중독** 6경로는 아래를 **항상** 사정한다.
V7은 이 세트가 경로마다 `neuro` 필드로 흩어져 있어(6종·2종·1종…) 경로에 따라 빠지는 항목이 있었다.

```
동공크기 · 동공 반응(펜라이트) · 감각이상 · grasp power · obey command · 의식수준
```
근력(상·하지 좌우)도 이 6경로에서 열리고, 입력하면 평가에 **`사지 근력 평가함`** 이 나간다.
신경 경로가 아니면 이 세트는 뜨지 않는다(호흡곤란·복통·피부 등 확인 완료).

### 의식이 나쁠 때만 더 묻는다

`의식 저하됨`을 눌렀을 때만 **지남력 3개 + GCS(눈뜸·언어·운동)** 가 열린다.
- GCS 합계가 **15면 `의식 명료함`으로 적는다**(점수가 곧 근거 — V7 원칙 유지).
- 신경 경로(뇌경색·어지럼·의식섬망·중독·Seizure·두통)이거나 의식 저하면 **근력**이 열린다.
  **상·하지 × 좌우 4칸**(`좌상지`·`우상지`·`좌하지`·`우하지` — 마스터 표기). 등급(MRC)은 마스터에 없어 괄호 비고.

### 저혈당 먼저 거르기 (V7 follow 유지)

신경 증상이 있거나 의식이 저하되면 `⚡ 신경 증상 — 혈당부터 확인하세요` 안내와 혈당 문항이 뜬다.
단 주호소가 이미 고혈당·저혈당이면 뜨지 않는다.

### 기본 3질문을 고른 근거
207문항 중 재사용 순위가 정확히 이 셋이었다. **1위 어지럼 36경로 · 2위 오심구토 22경로 · 3위 호흡곤란 14경로.**
(앞 둘은 V7에도 `core:true`로 표시돼 있었고 호흡곤란만 빠져 있었다)

### 통증 (3층)

| 부위 | 진술문 | 세부 |
|------|--------|------|
| 머리 | `두통 있음` | — |
| 가슴 | `흉부 통증 있음` | anterior chest · epigastric · mediastinal · substernal |
| 배 | `복부 통증 있음` | LLQ · LUQ · RLQ · RUQ · periumbilical · 전체 |
| **그 외 전부** | **`통증 있음`** | **부위 직접 기재** |

- **통증 주호소(두통·복통·심근경색 의심·그 외 통증·소아 보챔처짐)를 고르면 3층이 자동으로 켜지고 부위까지 잡힌다**(칩스 ㉠안).
- 통증 `없음`을 누르면 `통증 없음` 한 줄만 남고 급성통증 진단은 안 붙는다. 아무것도 안 누르면 통증 블록 자체가 없다.
- 기간이 `3개월 이상`이면 **만성통증**으로 자동 전환.
- NRS 점수·양상·빈도는 마스터에 없는 값이라 **괄호 비고**로 나간다(V7과 동일 원칙).

### 경련 단순화 (칩스 260808)
```
Seizure [있음][없음] → eyeball deviation [있음][없음] → 방향(시방향) [좌][우][양쪽]
```
V7의 발작 양상 4지선다·동공크기 자로 재기·펜라이트 3지선다를 **3클릭으로**. 소아-경련도 동일.
> 신설 문항 `QE1`·`QE2`의 진술문은 마스터 원문 그대로:
> `eyeball deviation 있음/없음`, `eye ball deviation 방향(시방향)`.
> **"시방향"은 오타가 아니라 마스터 등재 표기**(영문판 `time direction` = 시계 방향).

### 전해질 신설
`혈중 potassium/sodium 수치 정상 이상임/이하임` 4문항이 **V7에는 만들어져 있었지만 연결된 경로가 없어 화면에 뜨지 않았다.**
→ `🧪 전해질` 경로 신설. 진단은 답에 따라 자동으로 갈린다:
`K 높음 → 고칼륨혈증` · `K 낮음 → 저칼륨혈증` · `Na 높음 → 고나트륨혈증` · `Na 낮음 → 전해질불균형`
(V7 `sites.추가상태`에 이미 있던 진단·평가를 그대로 씀 — 처음 만든 `전해질불균형` 하나보다 정확)

### 하단 '이상 소견' 목록은 만들지 않았다
측정값 43개가 **이미 해당 주호소 안에 다 들어 있어서**다(Hb·혈소판·INR→출혈위험, CRP→감염, 혈당→고혈당, SpO2→호흡곤란, ECG→심근경색). 따로 뺄 이유가 없다.

## 3.5 화면 · 모바일 (260808)

**7단계 진행** — 상단에 진행 막대, 각 화면에 `STEP n / 7`과 제목·안내 한 줄.

```
STEP 1 도관 · 튜브    가지고 있는 관을 모두 눌러주세요
STEP 2 기본 사정      모든 환자에게 묻는 3가지
STEP 3 주호소         오늘 왜 오셨나요 · 최대 2개
STEP 4 사정           물어보고 눌러주세요
STEP 5 통증           아픈 곳이 있나요
STEP 6 의식 · 낙상    마지막 확인
STEP 7 기록 완성      복사해서 붙여넣으세요
```

- **하단 고정 네비게이션**(`←` / `다음`) — 스크롤과 무관하게 항상 손 닿는 위치.
- 상단 고정 바 : `🏠 처음으로` · 환자명(마스킹) · `📁 보관함`.
- 모바일 대응은 V7 CSS를 그대로 계승 — 다크모드, 아이폰 노치(`safe-area-inset`), 바운스 스크롤 차단, 최대폭 640px, 터치 타깃 46px 이상.
- 선택지 버튼은 누를 때 살짝 눌리는 반응(`scale .97`), 선택 시 그림자.
- 긴 문장 선택지(도관 상세·선택형 문항)는 **세로 1열**로 — 가로로 잘리지 않는다.
- 진단은 카드형으로 보여주고 **`사정 근거 있음` / `근거 없음` 배지**를 달아, 왜 그 진단이 자동으로 잡혔는지 보이게 했다.
- 알림은 화면 하단 토스트(`복사했습니다 · 보관함에 저장`).

### 📁 보관함 — 최근 10건

복사 버튼을 누르면 **자동으로 보관**된다(`localStorage['nfh_v8_hist']`, 10건 초과 시 오래된 것부터 삭제).

- 저장 항목: 시각 · **마스킹된 이름** · 등록번호 · 주호소 · 간호진단 · 기록 전문
- 목록에서 **📋 다시 복사 / 삭제** 가능. 기기에만 저장되며 서버로 나가지 않는다.
- ⚠️ 공용 기기에서는 주의 — 등록번호는 그대로 저장된다.

복사는 `navigator.clipboard` 우선, 실패하면 `execCommand` 폴백(파일로 직접 열었을 때 대비).

## 4. 검증 (JavaScriptCore로 실행)

- 43경로 무결성 — 없는 문항 참조·사정 0개·빈 진단 **0건**
- 전 문항 `stmt()` 진술문 출력 정상 (토글·체크·선택·값입력 4형식)
- 케이스 6종 기록 생성 확인: 호흡곤란 / 호흡곤란+발열(2개) / 복통(통증 자동) / Seizure / 전해질 / 통증 미응답
- 통증 부위별 진술문 매핑 5종 정상, 만성통증 전환 정상
- **버그 1건 발견·수정** — 주호소 2개에서 `고체온`을 골랐는데 호흡곤란 평가가 나오던 문제 → 고른 진단의 평가를 쓰도록 수정

- 보관함 — 13건 저장 시도 → **10건만 유지**(FIFO), 목록 요약·재복사·삭제 정상
- 복사 — 클립보드 340자 정상, `execCommand` 폴백 경로 확인

> ⚠️ **브라우저 실기 테스트는 아직.** 화면 클릭·복사·보관함은 **실제 쓰는 기기(아이폰/아이패드)에서 1회 확인 필요.**
> 특히 파일을 직접 열어 쓰는 방식이면 `localStorage`가 막히는 브라우저가 있어 보관함이 동작하는지 봐야 한다.
