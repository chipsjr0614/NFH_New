# 통합간호기록 V8 — 5층 재설계

**파일:** `app/간호기록V8.html` (2026-08-08)
**요청(칩스 260808):** "너무 복잡하다. 기본 3질문 하고, 주호소 안에서 진단 1개, 통증은 따로, 낙상위험은 디폴트."

---

## 1. 왜 고쳤나 — V7의 문제 (데이터로 확인)

| 문제 | 실측 |
|------|------|
| 경로를 고르는 단계에서 이미 임상 판단을 요구 | 호흡곤란이 **5갈래**(가래 양·천명음·심부전+흉통) — 숨차다는 환자 앞에서 폐렴인지 천식인지 먼저 정해야 진행 |
| 통증 유무로 경로가 쌍으로 갈림 | **12쌍 24경로**가 거의 완전 중복. `고체온+통증없음`과 `고체온+통증있음`의 잔여 문항이 **똑같이 3개** |
| 진단이 여러 개면 사정도 배로 늘고 겹침 | 호흡곤란(심부전+흉통) 14문항 중 **5개가 두 진단에 중복** |
| 진단 과다 | 최대 4개 + 낙상위험. 앱이 `⚠️ 간호진단이 3개입니다` 경고로 때우고 있었음 |
| 버튼이 4종류 | 토글 143 · 체크 52 · 선택 8 · 값입력 4 |

### 체크형(단일 버튼)이 이상해 보였던 진짜 이유

체크형 52개의 **부정 진술문이 마스터에 있는지 전부 대조**한 결과:
- 부정형이 있음 → **9개**(`seizure 있음↔없음` 등)
- 부정형이 **없음 → 43개** (`산소 흡입 중임`·`혈당 증가함`·`혈압 저하됨`…)

43개는 전부 **재봐야 아는 값**(Hb·혈소판·CRP·INR·K·Na·혈압·맥박·SpO2·혈당·체온·소변량)이다.
마스터가 "이상할 때만 쓰는 문장"으로 만든 것이고 **정상이면 적을 문장이 없다.**
→ 설계 실수가 아니라 마스터 제약. 임의로 `산소 흡입 안함` 같은 문장을 만들 수 없다.

## 2. V8 구조 — 5층

```
0층 🔌 도관 · 튜브      25종(자주 쓰는 10종 먼저) · 없으면 넘어가기
1층 🩺 기본 3질문       어지럼 · 호흡곤란 · 오심/구토        [있음][없음]
2층 🎯 주호소 1~2개     확정 진술문 + 물어보는 2~11개        → 진단 1개
3층 😣 통증             부위 → 강도 → 양상 → 빈도 → 기간     → 급성통증
4층 🧠 의식 · 낙상      의식 · 보호자                        → 낙상위험(무조건)
```

**진단은 최대 3개** — 주호소 1 + 급성통증 + 낙상위험.

### 기본 3질문을 고른 근거
207문항 중 재사용 순위가 정확히 이 셋이었다. **1위 어지럼 36경로 · 2위 오심구토 22경로 · 3위 호흡곤란 14경로.**
(앞 둘은 V7에도 `core:true`로 표시돼 있었고 호흡곤란만 빠져 있었다)

## 3. 바뀐 것

| | V7 | V8 |
|---|---|---|
| 경로 | 60개 | **43개** |
| 사정 문항 | 336개(중복 포함) | **207개** |
| 진단 | 1~4개 + 낙상 | **최대 3개** |
| 버튼 | 4종류 | **[있음][없음] 통일** (측정값만 예외) |
| 호흡곤란 | 5갈래 사전 선택 | **1개** — 가래·천명음은 사정 문항으로 흡수 |
| 출혈 | 12경로 | **2개** — `출혈`(토혈·객혈·혈변·흑색변·질·기타 토글) + `출혈위험` |
| 통증 | 21경로에 급성통증이 붙어 다님 | **3층으로 완전 분리** |
| 낙상위험 | 맞이교육·의식·보호자 입력 시 | **무조건** |
| 주호소 | 1개(`S.set` 단수) | **1~2개**(`S.picks` 배열) |

### 통증 (3층)

| 부위 | 진술문 | 세부 |
|------|--------|------|
| 머리 | `두통 있음` | — |
| 가슴 | `흉부 통증 있음` | anterior chest · epigastric · mediastinal · substernal |
| 배 | `복부 통증 있음` | LLQ · LUQ · RLQ · RUQ · periumbilical · 전체 |
| **그 외 전부** | **`통증 있음`** | **부위 직접 기재** |

- **통증 주호소(두통·복통·심근경색 의심·그 외 통증·소아 보챔처짐)를 고르면 3층이 자동으로 켜지고 부위까지 잡힌다**(칩스 ㉠안).
- 통증 `없음`을 누르면 `통증 없음` 한 줄만 남고 급성통증 진단은 안 붙는다. 아무것도 안 누르면 통증 블록 자체가 없다.
- 기간이 `3개월 이상`이면 **만성통증**으로 자동 전환.
- NRS 점수·양상·빈도는 마스터에 없는 값이라 **괄호 비고**로 나간다(V7과 동일 원칙).

### 경련 단순화 (칩스 260808)
```
Seizure [있음][없음] → eyeball deviation [있음][없음] → 방향(시방향) [좌][우][양쪽]
```
V7의 발작 양상 4지선다·동공크기 자로 재기·펜라이트 3지선다를 **3클릭으로**. 소아-경련도 동일.
> 신설 문항 `QE1`·`QE2`의 진술문은 마스터 원문 그대로:
> `eyeball deviation 있음/없음`, `eye ball deviation 방향(시방향)`.
> **"시방향"은 오타가 아니라 마스터 등재 표기**(영문판 `time direction` = 시계 방향).

### 전해질 신설
`혈중 potassium/sodium 수치 정상 이상임/이하임` 4문항이 **V7에는 만들어져 있었지만 연결된 경로가 없어 화면에 뜨지 않았다.**
→ `🧪 전해질` 경로 신설. 진단 `전해질불균형`, 평가 `전해질 불균형 증상이 있는지 확인함`·`혈중 전해질 검사결과 확인함` (모두 마스터 확인).

### 하단 '이상 소견' 목록은 만들지 않았다
측정값 43개가 **이미 해당 주호소 안에 다 들어 있어서**다(Hb·혈소판·INR→출혈위험, CRP→감염, 혈당→고혈당, SpO2→호흡곤란, ECG→심근경색). 따로 뺄 이유가 없다.

## 4. 검증 (JavaScriptCore로 실행)

- 43경로 무결성 — 없는 문항 참조·사정 0개·빈 진단 **0건**
- 전 문항 `stmt()` 진술문 출력 정상 (토글·체크·선택·값입력 4형식)
- 케이스 6종 기록 생성 확인: 호흡곤란 / 호흡곤란+발열(2개) / 복통(통증 자동) / Seizure / 전해질 / 통증 미응답
- 통증 부위별 진술문 매핑 5종 정상, 만성통증 전환 정상
- **버그 1건 발견·수정** — 주호소 2개에서 `고체온`을 골랐는데 호흡곤란 평가가 나오던 문제 → 고른 진단의 평가를 쓰도록 수정

> ⚠️ **브라우저 실기 테스트는 아직.** 화면 클릭·복사는 실제 쓰는 브라우저에서 확인 필요.
