## 1. 한 줄 비전

> **KTAS처럼 환자를 보면서 따라 클릭하면 → 사정이 빠짐없이 되고 → 그게 곧 정형 간호기록이 되는 도구.**

- **대상:** 간호기록·사정 개념이 약한 신규부터 빠르게 넘기고 싶은 경력까지.
- **기기:** 아이패드·갤럭시탭을 들고 **환자 곁에서** 직접 사정.
- **목적:** 사정 → 정형 간호기록 자동 생성 → 간호기록지(EMR)에 입력.

### 왜 필요한가
- 신규는 **무엇을 물어야/봐야 할지 모른다.** 베테랑도 급하면 빠뜨린다.
- 간호사마다 **중구난방** → 표준화.
- **놓침 = 위험** → "왜 안 물어봤냐"가 안 나오게.
- 묻고 또 따로 기록하는 **이중 작업** 제거 → **클릭 = 기록.**
- EMR엔 정형 문장이라야 쓸 수 있음("토했음"❌ → "오심 구토 있음"✅).

## 3. 전체 흐름

```
[STEP 0] 환자 확인 (선택) — 성함·팔찌
   ↓
[STEP 1] 도관 삽입 여부  (Foley · L-tube · PTBD · PTGBD · CVC · 흉관 · PCD …)
   ↓
[STEP 2] 주호소 선택  "어디가 불편하세요?" (KTAS식, 복수 선택)
   ↓
[STEP 3] 증상별 사정  ← 핵심
   · 일반 사정: 진술문 클릭 (있음/없음 토글)
   · 통증류: 가지치기(부위·양상·강도·발병·원인)
   · 관찰형 사정: "직접 보세요" (동공·호흡 양상·피부·의식 — 보고 클릭)
   · 놓치면 안 되는 항목은 한 번은 응답하고 지나가게(게이트)
   ↓ (자동 연결)
[STEP 4] 간호진단  (사정 결과 기반 자동 추천 → 원탭 확인)
   ↓ (자동 연결)
[STEP 5] 평가·중재  (📢 환자에게 말할 문장 = 중재, 읽으며 체크)
   ↓ 다른 사정 있으면 STEP 3~5 반복
   ↓
[STEP 6] 의식 + 보호자  (항상 🔒)
   · 의식: 있음 / 없음→GCS·지남력(시간·사람·장소)
   · 보호자: 상주 / 없음
   → 간호진단: 낙상위험 → 중재: 낙상방지 교육함·침대 난간 올려줌·보호자 …
   ↓
[완료] 정형 간호기록 자동 완성 → 복사 → 기록지(EMR) 입력
```

## 4. 화면별 요구사항

### STEP 1 — 도관 확인
- 항목: Foley(유치도뇨관) · L-tube(비위관) · PTBD · PTGBD · PCD · CVC/PICC · 흉관 · 기타 직접입력
- 없으면 빠르게 "없음"으로 통과
- 기록: 진술문 시트의 도관 진술문(한글 원문)으로 매핑 — ⚠️ 영문 약어(Foley·L-tube)는 진술문에 없으므로 **한글 진술문 대응표 필요**(검증)

### STEP 2 — 주호소 (KTAS식)
- 큰 버튼 그리드, 복수 선택. 계통/빈도순 배치
- KTAS 트리아지와 연동 시 주호소 자동 선택 가능(localStorage)

### STEP 3 — 사정 (핵심)
**3종 입력 방식:**

| 방식 | 설명 | 예 |
|------|------|----|
| 일반 토글 | 있음/없음 (양성만 빨강 강조) | 오심·구토 [없음][있음] |
| 통증 가지치기 | "통증 있음" 시 자동 펼침 | 부위·양상·강도(NRS)·발병·원인 |
| **관찰형 (보고 클릭)** | 화면이 "직접 보세요" 지시 | 동공·호흡 양상·피부·의식 |

- **놓침 방지 게이트:** 위험 항목(혈변·임신가능성·흉통·의식저하 등)은 미응답 시 "확인 필요" 빨강 유지
- **빠른 모드:** "나머지 다 정상으로" 버튼(경력용)

### STEP 4 — 간호진단 (자동)
- 사정 양성 결과 → 해당 진단 자동 추천(원탭 확인). 신규가 진단 몰라도 됨
- 예: 복부 통증 있음 → **급성통증** / 열감·chilling 있음 → **감염위험**
- 낙상위험은 항상 자동 포함 🔒

### STEP 5 — 평가·중재 (설명 = 중재)
- 진단별 중재가 **"환자에게 말할 문장"으로** 표시 → 읽으며 체크 → 그게 P&E 기록
- 예: 📢"많이 아프세요? 진통제 필요하실까요?" → "통증을 인정해줌"

### STEP 6 — 의식 + 낙상 (항상)
- 의식: 명료 / 저하(→GCS·지남력 시간·사람·장소 있음/없음)
- 보호자: 상주 / 없음
- → 낙상위험(D) → 낙상방지 교육함·침대 난간 올려줌·보호자와 같이 있게 함(P&E)

### 출력 — 정형 간호기록
- 실시간 미리보기(탭할 때마다 쌓임)
- 색 구분: A&E(파랑)·D(빨강)·P&E(노랑)·비고/NRS(회색)
- **복사** → 기록지 붙여넣기. NRS는 비고란으로만(정식 진술문 아님)

## 5. 👁️ 관찰형 사정 명세 (이 도구의 차별점)

화면이 **간호사에게 "무엇을 보라"고 지시** → 보고 탭 → 진술문 자동.
(아래 항목·표기는 **진술문 시트에서 추출·검증 후 확정** — 현재는 구조 예시)

| 영역 | 화면이 시키는 것 | 입력(보고 클릭) | 기록 진술문(예시·검증필요) |
|------|----------------|----------------|---------------------------|
| 🧠 신경/동공 | "환자 눈 보세요" | 동공크기 좌/우(mm) · 빛반사(prompt/sluggish/무반응) · 사지 힘 | "빛 반사 확인결과 prompt 함" 등 |
| 🫁 호흡 | "보고 들으세요" | 양상(정상/빠름/얕음/노력성) · 보조근 · 청색증 · 소리(천명/그렁) | "호흡곤란 있음" · "보조호흡근 사용함" 등 |
| 🩸 피부/순환 | "보세요·만지세요" | 색(정상/창백/청색증/홍조) · 발한 · 온도 | (진술문 추출) |
| 😐 의식 | "물어보세요" | 명료 / 지남력(시간·사람·장소) | "시간, 사람, 장소에 대한 지남력 있음" 등 |

> ⚠️ "GCS" 영문은 진술문 시트에 없음 → 의식은 **지남력·무의식 진술문**으로 표현. 동공/호흡 관찰값의 정확한 진술문 매핑은 **칩스 검증** 필요.

## 7. UI/UX 원칙 (KTAS식)

- **순차 흐름 + 놓침 0** — 한 덩어리씩, 안 본 항목은 시각적으로 남음(진행률·게이트)
- **양성만 강조** — "없음"은 차분, **"있음/양성"만 색**으로 튀게
- **큰 터치·한 손** — 태블릿, 버튼 ≥44px
- **관찰 지시형** — "동공 보세요"처럼 화면이 행동을 안내
- **탭 = 기록** — 자유서술 금지, 정형 진술문만 출력
- **실시간 미리보기 + 복사** — 완성이 보이고, 메인 액션은 복사/입력
- 다크테마, 태블릿 우선 + 폰 반응형
