# 통합간호기록 요구사항정의서 — 7층 구조 (2026-08-09)

**요청(칩스 260809)**
> "심플하고 디테일 있게. 모든 이에게 확실한 질문, 놓치지 않기 위한 사정.
> V4~V7 내용을 놓치지 말고."

## 0. 대원칙 — 안 바뀌는 것

1. **진술문은 마스터 원문만.** 지어내지 않는다. 없으면 비워두고 「확인 필요」로 남긴다.
2. **값은 진술문이 아니다.** NRS 점수·동공 크기·근력 등급·체온 수치는 마스터에 없으므로 **괄호 비고**로 나간다. 「쟀다」는 사실만 원문 평가로 남긴다.
3. **물어본 것은 음성이라도 기록한다.** 「없음」도 확인했다는 근거다.
4. **안 한 처치를 적지 않는다.** 간호사가 실제로 한 것만 평가로 들어간다.
5. **한 기록에 「있음」과 「없음」이 같이 남지 않는다.**
6. **내부망 · 인터넷 없음.** 자체완결 단일 HTML. 외부 호출 금지.

## 4. 층별 상세

### 0층 · 환자 확인

- 이름 · 등록번호(8자리) · **맞이 안내 탭** (귀금속 · 금식 · 도난 · 낙상)
- **이름은 가려서 표시한다** — 화면 위 · 기록 머리말 · 지난 환자 목록
  | 글자 수 | 예 |
  |---|---|
  | 2 | 홍길 → 홍O |
  | 3 | 홍길동 → 홍O동 |
  | 4 이상 | 남궁길동 → 남궁OO |

### 1층 · 도관

- **자주 쓰는 10종 먼저 + 더보기 15종** (전체 25종)
- 고르면 그 도관의 진술문이 목록으로 뜨고, 해당하는 것만 누른다
- **없으면 「도관 없음 · 넘어가기」 한 번**

### 2층 · 내원 이유

- **환자 말로 쓴다** — 「열나요」·「숨차요」·「피나요」·「다쳤어요」
- **최대 2개.** 3개째는 안 눌린다
- 🔶 **낙상 · 교통사고를 내원 이유로 넣을지 확정 필요** (지금은 「외상」 하나로 처리)
- **검색**으로도 찾는다 — 「벌」·「뱀」·「감전」·「기저귀」로 부위·상황까지 나온다

### 3층 · 기본 질문 (모든 환자)

```
어지럽거나 핑 도는 느낌이 있으세요?   dizziness 있음/없음
오심이나 구토가 있으세요?            오심, 구토 있음/없음
숨이 차거나 답답하신가요?            호흡곤란 있음/없음
```

**근거** — 207문항 중 재사용 1·2·3위가 정확히 이 셋이다(36경로·22경로·14경로).

- **소아는 아이 말로 바꾼다**
  | 어른 | 소아 |
  |---|---|
  | 어지럽거나 핑 도는 느낌 | 🩺 아이 반응 정도 (울음소리 좋음 / 자극 주면 울음 / 반응 없음) |
  | 숨이 차거나 답답 | 아이가 숨쉬기 힘들어 보이나요? |
  | 오심이나 구토 | 토했나요? |

- **숨차다고 하면 따라 나온다** — 기침 · 가래 · 산소포화도 · 산소 흡입 중 · 청색증

### 4층 · 내원 이유 질문

- 그 이유에 딸린 문항만 (평균 4~11개)
- **버튼은 [있음] [없음] 하나로 통일.** 측정값만 예외
- **체크형(반대말이 마스터에 없는 것)은 필수가 아니다**
  → 「혈압 상승됨」과 「혈압 저하됨」을 둘 다 눌러야 넘어가던 문제
  → **서로 반대인 체크는 하나만 켜진다**
- **부위·상황** — 외상 6 · 피부 9 · 온열 2 · 한랭 3 · 노출경로 3 · 추가상태 8
  고르면 그 부위 문항이 따라오고 진술문 뒤에 괄호가 붙는다 — `늑골 골절 있음(가슴)`

### 5층 · 통증 — **루틴이 아니다**

```
통증이 있으세요?   [있음] [없음]
   없음 → 「통증 없음」 한 줄만. 급성통증 진단 없음
   있음 → 부위 → 강도 → 양상 → 빈도 → 기간 → 급성통증
```

- 통증 주호소(두통·복통·그 외 통증 등)를 고르면 **자동으로 켜지고 부위까지 잡힌다**
- **기간이 3개월 이상이면 만성통증**으로 바뀐다
- 도구 — NRS(성인) · FPRS(소아·노인) · FLACC(영유아) · NIPS(신생아) · CNPS(비언어)
- 부위 8종 + 가슴·배는 세부 위치
- **NRS 점수·양상·빈도는 괄호 비고**

### 6층 · 의식 · 보호자 · 낙상

```
보호자   [있음] [없음]      ← 위
의식     [명료] [15점 미만]  ← 아래 (좌우로 나란히 두면 헷갈린다)
```

- **의식 저하일 때만** GCS(눈뜸·언어·운동) + 지남력 3개가 열린다
- **GCS 합계가 15면 「의식 명료함」으로 적는다** — 점수가 곧 근거
- **사지 근력 4칸** (좌상지·우상지·좌하지·우하지) + **평가불가**
  의식 없는 환자는 MRC 등급을 매길 수 없다. 둘 다 평가불가면 「사지 근력 평가함」을 적지 않는다
- **낙상위험은 무조건** 들어간다 + 낙상 교육 문구

## 5. 간호진단 규칙

```
내원 이유 진단   최대 2개   ← 양성인 것만. 우선순위 순
＋ 급성통증               ← 통증 있을 때만 (루틴 아님)
＋ 낙상위험               ← 항상
────────────────────────
최대 4개
```

- **간호사가 고르지 않는다.** 사정에서 양성인 진단 중 우선순위대로 자동. 눌러서 바꿀 수 있다
- **근거 없는 진단은 안 붙는다.** 다만 물어본 사정은 음성이라도 남는다
- **우선순위** — ABC · 생명위협 순 (36단계)
- 🔶 **우선순위표 임상 검토 필요** — 특히 외상에서 `출혈 > 신체손상위험`

## 6. 기록 형식

```
[홍O동 12345678]

■ 도관 · 튜브
사정) Foley catheter 유지 중임, Foley catheter 통해 소변 배출되고 있음

■ 기본 사정
사정) dizziness 없음, 호흡곤란 없음, 오심, 구토 없음

■ 비효율적호흡양상
사정) 기침 있음, 가래 있음, 열감 있음, chilling 있음, 체온 상승함
진단) 비효율적호흡양상
평가) 호흡곤란이 있는지 확인함, 산소포화도 monitor 함

■ 급성통증
사정) 통증 있음
진단) 급성통증
평가) 통증을 인정해줌, 통증 양상을 확인함

■ 낙상위험
사정) 의식 명료함, 보호자 환자 옆에 상주하고 있음
진단) 낙상위험
평가) 낙상방지 교육함, 침대 난간을 올려줌

(통증 — NRS 7점 / 욱신·쑤시는 / 지속적 / 부위 배(RLQ))
```

- **블록 순서** — 도관 → 기본 사정 → 내원 이유(우선순위 순) → 통증 → 낙상위험(항상 끝)
- 같은 진술문이 두 블록에 걸리면 **앞 블록에만**
- 평가는 블록당 2개. 중복으로 빠지면 남은 것으로 채운다

### ✅ 해결됨 — 평가 칸 문제 (2026-08-10)

**전에는** 평가(중재)가 진단당 2개까지만 나가는데, 그 2개를 `3.환자설명`이 먼저 차지했다.
환자설명은 **진단 이름으로 전 경로 공통**이라, 경로가 선언하지도 않은 평가가 기록에 나갔다 —
황달 경로에서 `체온 측정함`이 나가던 식이다. **안 한 일이 기록되는 문제였다.**

**이제** 경로가 적은 것만, 엑셀 `순서` 열대로 나간다.

```js
function peOf(dx){                       // v7_template.html
  const ex=D.explain[dx.name]||[];
  const say=p=>(ex.find(e=>e.pe===p)||{}).say||'';
  const mine=dx.pe.map(p=>({pe:p,say:say(p)}));          // 경로가 적은 것 · 적은 순서대로
  const extra=ex.filter(e=>dx.pe.indexOf(e.pe)<0)        // 경로가 안 적었을 때의 대비책
                .map(e=>({pe:e.pe,say:e.say}));
  return mine.concat(extra).slice(0,2);
}
```

**칸은 2개 그대로다.** 기록이 길어지지 않으면서 경로마다 원하는 것을 앞에 둘 수 있다.

| 저절로 좋아진 것 | 전 | 후 |
|---|---|---|
| 황달 | 감염 증상 확인 / **체온 측정함** | **간기능 검사결과 확인함** / 감염 증상 확인 |
| 부인과 | 감염 증상 확인 / **체온 측정함** | **질 분비물 양상 관찰함 / 월경력 확인함** |
| 화상 | 피부 상태 관찰 / 화상부위 세척 | **화상부위 세척함 / 화상부위 오염물 제거함** |
| 출산 후 | 출혈 증상 확인 / 출혈양상 확인 | **오로 관찰함** / 출혈 증상 확인 |
| 소아 발열 | 감염 증상 확인 / 체온 측정 | 체온 측정함 / **미온수 목욕 시행함** |
| Seizure | **`Seizure시 안전간호 시행함`**(마스터에 없는 문장) | `seizure 양상 확인함` / `안전간호를 제공함` |
| 이비인후 | 감염 증상 확인 / 체온 측정 | 감염 증상 확인 / **청력장애가 있는지 사정함** |

**엑셀 순서를 손본 곳** — 순서가 뒤집혀 나빠진 3군데를 바로잡았다(`_적용_평가순서_260810.py`).
- 통증 P&E: `통증 강도 측정함` → `통증을 인정해줌` → `통증 양상을 확인함` → `통증을 관찰하기로 함`
  (「관찰하기로 함」은 `11.평가자동`에 **「사정이 아니라 계획이다」**로 분류돼 있어 뒤로 보냈다)
- 저체온: `담요를 덮어줌`을 1번으로 (덮어주는 게 먼저다)
- 22곳에서 30칸 조정

**새로 넣은 평가 2개**
- 복부통증 · `급성통증` → `복막염 증상(국소적 통증, 미열, 오심, 구토, 장음 감소)이 있는지 확인함` (순서 1)

### ★ 정정 — 「없다」고 했다가 있었던 것

부위상세(`12.부위상세`)를 다시 보니, 앞선 편에서 「없다」고 적은 것 몇 가지가 이미 있었다.
`추가상태`·`피부상황`은 **어느 경로에서든 열 수 있다**(`EXTRA`). 다만 **간호사가 스스로 찾아 눌러야 한다.**

| 항목 | 처음 판단 | 실제 |
|---|---|---|
| 쇼크 사정 | 「하나도 없다」 | 「추가상태 → 🩸 쇼크 의심」에 체크 3 + 중재 3 + 진단 `조직관류저하`. **저절로 안 뜰 뿐** |
| 열사병 | 「없다」 | 「온열노출 → 🥵 열사병」에 있음 |
| 성인 황달 | 「경로 자체가 없다」 | 「추가상태 → 🟡 황달」에 있음. **다만 진단연결 칸이 비어 있어 간호진단이 안 나온다** |
| SMC · `말초신경혈관기능장애위험` | §9에 「V4엔 있었다」 | 「외상부위 → 목·척추 / 팔·다리」에 **이미 있음** |
| 여성 하복부 통증 | 「경로 없다」 | 「임신·산과 → 🚺 임신 아님」이 무월경·월경불순·질출혈·복통을 이미 물음 |

**→ 이 앱의 진짜 문제는 「없다」가 아니라 「있는데 안 눌린다」인 경우가 많다.**

### ✅ 복부 반영 내역 (2026-08-09)

**1차 · 복부통증 경로 재구성 — 7문 → 6문 (문항이 늘지 않았다)**

뺀 것 3문 — 전부 중복이었다.

| 뺀 문항 | 이유 |
|---|---|
| `복부 통증 있음/없음` | 「통증 → 복부」로 들어왔는데 또 물었다 |
| `오심, 구토 있음/없음` | 3층 기본 3문에 이미 있다 |
| `복부 불편감 있음/없음` | 통증과 사실상 같은 말이다 |

넣은 것 — 순서대로.

| 순서 | 질문 | 진술문 | 진단연결 |
|---|---|---|---|
| 1 | "어디가 아프세요?" 윗배 / 아랫배 / 배 전체 | `상복부 통증 있음` · `하복부 통증 있음` · `복부 통증 있음` | 급성통증 |
| 2 | 🩺 배를 눌렀다 뗀 순간 더 아파하나요? | `반동압통 있음/없음` | 급성통증 |
| 3 | 🩺 배가 불러 있는지 확인하세요 | `복부 팽만 있음/없음` | **장폐색증위험** |
| 4 | "방귀는 나오나요?" | `gas out 됨/안됨` | 급성통증 |
| 5 | "대변은 어땠나요?" | `정상 대변 봄` · `대변 못 봄` · `설사 있음` | 급성통증 |
| 6 | "대변에 피나 검은색이 보였나요?" | `혈변 없음` · `혈변 있음` · `흑색변 있음` | **출혈** |

- **1번이 통증 근거를 겸한다.** 부위를 고르면 `급성통증`의 사정 근거가 생기므로 옛 1번이 필요 없다.
- **5번은 기존 「대변」·「설사」 2문을 합친 것**이라 문항이 줄었다.
- **6번으로 「배 아파요」로 온 위장관 출혈을 잡는다.** 전에는 「출혈」 주호소로 들어와야만 물었다.
- 진단은 근거가 있을 때만 뜬다(`rec()`). 단순 복통이면 `급성통증` 하나로 끝난다.

**2차 · 성인 황달 경로 신설** — 소아에만 있고 성인에는 없었다. 담관염(열 + 황달 + 복통)은 응급이다.

`공막의 황달 있음/없음` · `열감 있음/없음` · `복부 통증 있음/없음` → `감염위험`
`가려움증 있음/없음` → `피부손상위험`

**3차 · 여성 하복부 통증 주호소 신설** — 성별을 묻는 대신 **주호소를 따로 두어** 남성 환자는 만나지 않게 했다.

`하복부 통증 있음/없음` → `급성통증` · `질 출혈 있음/없음` → `출혈` · `무월경 있음`(체크·선택사항)

### ❌ 넣지 않기로 한 것 — 장음

마스터에 `장음 잘 들림/약함/안 들림/증가함/감소함` 6종이 다 있으나 **넣지 않았다.**

- 장음을 「없음」이라고 말하려면 한 부위에서 2~5분을 들어야 한다. 응급실에서 그 시간이 안 난다.
- 「약함」과 「정상」의 구분은 숙련자끼리도 잘 맞지 않는다.
- **실제로 안 듣고 누르는 칸이 되면 없는 사실이 기록에 남는다** — 0번 대원칙 위반이다.
- 장음이 하던 역할은 **`복부 팽만 있음` + `gas out 안됨`** 이 대신한다. 둘 다 보고 물으면 되는 것이라 신규 간호사도 확실히 답한다.
