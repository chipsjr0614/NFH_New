## 0. 대원칙

- **질환을 맞히는 도구가 아니라, 증상마다 늘 똑같이 묻는 도구.**
  간호사가 원인(폐렴인지 천식인지 심부전인지)을 먼저 고르지 않아도 된다.
- 진술문은 **마스터 원문만** 쓴다. 지어내지 않는다. 없으면 비워두고 「확인 필요」로 남긴다.
- 값(NRS 점수·세부 위치·양상·SMC 등급)은 마스터에 없으므로 **진술문이 아니다** → 괄호 비고로 나간다.
  「쟀다」는 사실만 마스터 원문 평가로 남는다.

### 소아 — 성인과 합치지 않는다 (2026-08-06 결정)

소아 9경로를 성인과 대조한 결과 **합치지 않기로 했다.**

| 소아 경로 | 성인 대응 | 진술문 겹침 |
|---|---|---:|
| 소아-발열 / 구토설사 / 호흡곤란 / 경련 / 피부 | 고체온 / 소화기 / 호흡곤란 / Seizure / 피부 | **2 / 1 / 2 / 0 / 3** |
| 소아-보챔처짐 · 황달 · 수유곤란 · 무호흡 | **대응 없음** | — |

- 겹치는 진술문이 0~3개뿐이다. 소아-경련은 **0개**다.
- 소아는 **탈수**(구강건조·갈증·피부탄력·기저귀 소변량), **함몰·말단 청색증**,
  **반응 정도**(울음소리 좋음/자극 주면 울음/반응 없음)를 본다. 성인에 없는 것들이다.
- 문구가 **보호자에게 묻는 말투**다. 합치면 보호자에게 「배가 아프세요?」라고 묻게 된다.

→ 대신 **「👶 소아 환자」를 맨 위 별도 묶음**으로 올려 찾기 쉽게 했다.
   임신·산과는 별도 묶음으로 분리했다.

> **남은 것** — 소아를 몇 살까지로 볼지 기준이 없다. 정해두어야 간호사가 헷갈리지 않는다.

## 2. 기본 3문

| 문항 | 진술문 | 원래 몇 곳이 따로 묻고 있었나 |
|---|---|---|
| 어지럽거나 핑 도는 느낌이 있으세요? | dizziness 있음/없음 | 30개 세트 |
| 숨이 차거나 답답하신가요? | 호흡곤란 있음/없음 | 14개 세트 |
| 오심이나 구토가 있으세요? | 오심, 구토 있음/없음 | 15개 세트 |

**새로 얹은 것이 아니다.** 여기저기 흩어져 있던 것을 위로 올려 한 번만 묻게 한 것이다.
원인과 무관하게 나빠지는 신호라 누구에게나 물어서 손해가 없다.

> **문구는 경로 것을 그대로 쓴다.** 같은 진술문이라도 경로마다 문구가 다르다
> (`어지러우세요?` / `어지럽거나 핑 도는 느낌이 있으세요?`).
> 하나로 통합하면 임상 문구가 조용히 바뀌므로, 경로에 이미 있으면 그 문항을 쓴다.

## 3. 신경학 사정

### 기본 사정에서는 묻지 않는다

의식은 마무리 「의식 · 보호자」가 이미 묻는다(명료 / 15점 미만 → GCS → 지남력).
기본에서 또 물으면 기록에 이렇게 두 번 남는다.

```
■ 기본 사정      의식수준 : alert          ← 중복
■ 의식 · 낙상    의식 명료함
```

그래서 **신경학을 기본 사정에서 뺐다.** 의식수준(Q174)은 묶음에서도 제외했다 — 마무리가 담당한다.

### 신경학 5문

`악력` · `동공크기` · `빛반사`(prompt/sluggish/hippus) · `감각이상` · `명령수행`(obey command)

### 언제 뜨나

| 조건 | |
|---|---|
| **신경학 경로 7개** | 사정 영역에서 **항상** |
| **마무리에서 「15점 미만」을 누르면** | 그 자리에서 5문이 뜬다 |
| 그 외 | 뜨지 않는다 |

### 신경학 경로 7개
`두통(headache)` · `뇌경색뇌출혈 관련` · `지금 Seizure 할 때` ·
`이미 Seizure를 하고 멈춘뒤 내원할 때` · `어지럼` · `중독` · `의식섬망`

> **왜 경로 예외를 두나** — 뇌경색 세트는 문항이 전부 신경학이라 증상 문항이 따로 없다.
> 의식이 명료한 뇌경색 환자에게 동공을 안 보고 넘어가면 안 된다.

> **감안한 것** — 기본에서 뺀 결과, 신경학 경로가 아니면서 의식이 명료한 환자의 **악력을 안 본다.**
> 의식이 명료해도 편마비면 악력이 약할 수 있다. 중복 제거를 우선한 결정이다.

### 💪 사지 근력 (2026-08-06 추가)

신경학 사정이 뜨면 **상지 · 하지** 근력을 0~V로 누른다.

```
💪 사지 근력   0 못 움직임 · III 중력 이겨 듦 · V 정상
   상지  [0] [I] [II] [III] [IV] [V] [평가불가]
   하지  [0] [I] [II] [III] [IV] [V] [평가불가]
```

| 등급 | |
|---|---|
| 0 | 전혀 못 움직임 |
| I | 근육만 꿈틀 |
| II | 바닥에서 밀기만 |
| III | 중력 이겨 듦 |
| IV | 저항 조금 이김 |
| V | 정상 |
| 평가불가 | 의식이 없거나 협조가 안 됨 |

> **MRC 등급은 환자가 협조해야 매길 수 있다.** 의식 없는 환자에게 「손을 드세요」는 안 통한다.
> 「평가불가」가 없으면 그런 환자는 필수 항목을 채울 수 없어 **복사가 영영 안 열린다.**
> 통증 SMC가 이미 쓰는 말(`양호함 · 약함 · 없음 · 평가불가`)이라 새로 배울 것이 없다.

> **둘 다 「평가불가」면 `사지 근력 평가함`을 기록하지 않는다.**
> 경로 진단에 붙어 있던 것도 뺀다. 못 한 평가를 했다고 적으면 안 된다.

> 의식이 떨어졌을 때 근력 줄을 아예 안 띄우는 안도 검토했으나(GCS의 M이 운동 반응을
> 담고 있으므로), **자리가 나타났다 사라지면 헷갈린다.** 자리는 늘 같고 답이 하나 더
> 있는 쪽이 직관적이다.

> **마스터에 등급 진술문이 없다.** `근력 평가함` · `사지 근력 평가함` ·
> `근력 증가함/감소함/변화 없음` · `grasp power 강함/약함` 뿐이다.
> 그래서 **「사지 근력 평가함」만 마스터 원문으로 남기고 등급은 괄호 비고**로 보낸다.
> NRS 통증 점수 · 동공 크기와 같은 방식이다.

```
평가) 사지 근력 평가함
(근력 — 상지 V / 하지 III)
```

- 신경학 사정이 뜨면 **상지·하지 둘 다 필수**다.
- `사지 근력 평가함`은 **평가 2개 자리를 놓고 다투지 않는다.** 경로 진단에 이미
  있으면 거기에, 없으면 「의식 · 낙상」에 붙는다. 두 곳에 겹치면 앞 블록만 남긴다.
- **신경학 경로 7개 전부**에 `사지 근력 평가함`이 들어갔다
  (어지럼 · 중독 · 의식섬망 · 지금 Seizure 중 4개가 빠져 있어 채웠다).

### 기록 위치
진단 근거인 신경학 소견은 **그 진단 블록**에, 아니면 **「의식 · 낙상」 블록**에 넣는다
(물어본 자리와 맞춘다).

```
■ 의식 · 낙상
사정) Glasgow Coma Scale : 12, 의식수준 저하됨, grasp power 강함,
      동공크기 : Rt 3 / Lt 3, 빛 반사 확인결과 prompt 함 ★,
      감각이상 없음, obey command 가능하지 않음, 보호자 환자 옆에 상주하고 있음
진단) 낙상위험
```

## 2-1. 답에 따라 따라 나오는 문항 (2026-08-06 추가)

### 숨차니? → 기침 · 가래 · 산소 · 청색증

**저산소증을 따로 만들지 않았다.** 호흡곤란에 묶었다.

기본 3문의 **호흡곤란에 「있음」을 누르면 5문이 따라 나온다.**

| 문항 | 진술문 | 전에는 어디에만 있었나 |
|---|---|---|
| 기침이 있으세요? | `기침 있음/없음` | 호흡곤란 5경로 중 일부 |
| 가래가 나오나요? | `가래 있음/없음` | 〃 |
| 🩺 산소포화도를 확인하세요 | `산소포화도 떨어짐` | **호흡곤란 3경로만** |
| 🩺 산소를 흡입 중인지 확인하세요 | `산소 흡입 중임` | **호흡곤란 3경로만** |
| 입술이나 얼굴이 파래 보이나요? | `청색증 있음/없음` | **소아 · 아나필락시스만** |

문제가 컸다 — 호흡곤란을 묻는 경로 14개 중 **9곳이 기침·가래를 안 물었고**,
**심부전 의심으로 온 환자에게 산소포화도를 안 물었으며**, 청색증은 호흡곤란
경로에 아예 없었다.

```
산소를 물었던 3경로   호흡곤란 › 가래 없거나 적음 / 기타
                    호흡곤란 › 가래 많음 (폐렴 의심)
                    호흡곤란 › 천명음 있음 (천식·기도협착)
안 물었던 2경로       호흡곤란 › 심부전 의심 + 흉통 없음 / 있음
```

경로가 이미 그 문항을 갖고 있으면 그 문항을 쓴다(문구가 다르므로).

### 대변 못 봄 → 며칠째?

```
"대변은 보셨나요?"      [봄] [못 봄]
   못 봄이면 ↓
며칠째 못 보셨어요?      [1일] [2일] [3일] [4일] [5일 이상]
```

> **마스터에 기간 진술문이 없다.** 대변 관련 50여 개 중 일수를 담는 문장이 하나도 없다
> (`대변 못 봄` · `배변 못하고 있음` · `배변 횟수 감소함` 등 상태만 있다).
> 그래서 **일수는 괄호 비고**로 간다. NRS 점수 · 근력 등급과 같은 방식이다.

```
사정) …, 대변 못 봄, …
(배변 — 3일째 못 봄)
```

## 2-2. 병명 대신 소견으로 — 「돌려막기」 (2026-08-06)

마스터에 병명 진술문이 없어도, **있는 소견을 조합하면 그 상황이 기록된다.**
전용 경로를 새로 만들지 않는다.

| 상황 | 어디에 묶었나 | 쓰는 소견 |
|---|---|---|
| **뱀·개 물림** | 피부상황 › 물림 | `피부 손상 있음` · `redness` · `edema` · `통증` + 기본 3문 |
| **저산소증** | 호흡곤란 「있음」 | `기침` · `가래` · `산소포화도 떨어짐` · `산소 흡입 중임` · `청색증` |
| **장폐색** | **복부통증 · 소화기** | `복부 통증` · `복부 팽만` · `대변 못 봄`(+며칠) · `gas out 안됨` · `오심구토` |
| **실신** | **어지럼** | `syncope` · `dizziness` · `창백함` · `발한` + 신경학 6문 + 근력 |
| **담낭염·췌장염** | 복부통증 | 기존 문항으로 충분 (추가 없음) |
| **신부전 · 심부전** | 추가상태 › 부종·체중 증가 | `edema` · `체중 증가함` · `소변량 감소함` |

> **장폐색을 따로 만들지 않은 이유** — 장폐색도 배가 아프다. 복부통증 경로에
> `복부 팽만`만 더하면 `대변 못 봄`·`gas out 안됨`이 이미 있어 소견이 완성된다.

> **실신을 따로 만들지 않은 이유** — 어지럼 경로가 이미 `syncope`를 묻고,
> **신경학 경로라 6문과 근력이 자동으로 붙는다.** `창백함`·`발한`만 더하면 된다.

> **`창백함`은 체크형이다.** 마스터에 `창백함`·`피부가 창백함`·`손톱이 창백함`·
> `점막이 창백함`이 있는데 **전부 양성 문장이고 음성이 없다.** 토글이 될 수 없다.

## 3-1. ＋ 다른 것도 있어요 (추가 상태)

배가 아파서 온 환자가 뱀에 물렸을 수도 있고 황달이 있을 수도 있다.
경로를 바꾸지 않고 **어느 경로에서나** 열어 그것만 묻는다.

```
＋ 다른 것도 있어요                  ← 접혀 있음. 필수 아님
  🧴 피부에 뭐가 있나요?
     🐕 물림  🐝 쏘임  🔪 열상  🔴 발진  🟥 봉와직염 의심
     🟣 멍  📌 이물질  🧪 화학물질 노출  ⚡ 전기 손상
  🟡 그 밖에 확인된 것
     🟡 황달  🧪 칼륨 높음  🧪 칼륨 낮음  🧂 나트륨 높음  🧂 나트륨 낮음
```

- **고르면 그 문항만** 뜨고, 진단·평가가 따라온다.
- **안 고르면 아무것도 요구하지 않는다** — 복사 잠금과 무관하다.
- 경로가 이미 그 묶음을 쓰고 있으면(피부·외상) **두 번 보여주지 않는다.**

### 추가상태 항목

| 항목 | 사정 (마스터 원문) | 간호진단 | 평가 |
|---|---|---|---|
| 🟡 황달 | `황달 있음/없음` · `공막의 황달 있음/없음` | **없음** | `황달이 있는지 확인함` |
| 🧪 칼륨 높음 | `혈중 potassium 수치 정상 이상임` | 고칼륨혈증 | `심전도 변화를 확인함` · `불편감이 있는지 확인함` |
| 🧪 칼륨 낮음 | `혈중 potassium 수치 정상 이하임` | 저칼륨혈증 | `심전도 변화를 확인함` · `불편감이 있는지 확인함` |
| 🧂 나트륨 높음 | `혈중 sodium 수치 정상 이상임` | 고나트륨혈증 | `전해질 불균형 증상이 있는지 확인함` · `의식수준 변화가 있는지 관찰함` |
| 🧂 나트륨 낮음 | `혈중 sodium 수치 정상 이하임` | 저나트륨혈증 | `전해질 불균형 증상이 있는지 확인함` · `의식수준 변화가 있는지 관찰함` |
| 💓 부정맥 | `부정맥 있음/없음` | 부정맥 | `부정맥이 있는지 확인함` · `부정맥으로 인한 증상이 있는지 확인함` |
| 💧 부종 · 체중 증가 | `edema 있음/없음` · `체중 증가함/감소함/변화 없음` · `소변량 감소함` | 체액과다 | `수분섭취배설량 측정함` · `체중 측정함` · `말초 부종 확인함` |
| 🩸 쇼크 의심 | `혈압 저하됨` · `맥박수 증가됨` · `소변량 감소함` | **조직관류저하** | `shock 증상(…)이 있는지 확인함` · `말초 관류를 확인함` · `활력징후 측정함` |

**전해질은 이미 혈액검사로 알고 온다.** 그래서 사정을 다시 묻지 않고 **체크 한 번**으로 끝낸다.
전신 증상은 기본 3문(어지럼·호흡곤란·오심구토)이 담당한다.

- **칼륨은 심전도**를 본다 — 칼륨은 심장 전도에 직접 영향을 준다.
- **나트륨은 심전도에 안 나타난다** — 뇌 부종·신경 증상으로 나타나므로 의식수준을 본다.
- **식이 교육은 넣지 않는다** — 응급실 환자는 금식이라 식이 관련 마스터 진술문은 쓸 일이 없다.

> **「정상」 진술문이 마스터에 없다.** `정상 이상임`·`정상 이하임` 둘뿐이라
> 「정상」 선택지를 만들 수 없다. 그래서 **이상일 때만 누르는 체크 방식**이다.

> **황달은 대응하는 마스터 간호진단이 없다.** 진단 없이 사정·평가만 남긴다.

### 신부전 · 심부전 — 병명이 아니라 소견으로

둘 다 **전용 경로를 만들지 않았다.** 소견이 같기 때문이다.

```
기본 3문   어지럼 · 호흡곤란 · 오심구토      ← 이미 모두에게 묻는다
＋ 💧 부종 · 체중 증가
     edema 있음/없음
     평소보다 몸무게가 늘었나요?  [증가함][감소함][변화 없음]
     소변량이 줄었나요?           [체크]
   → 진단 체액과다
```

`체액과다`는 신부전 악화와 심부전 악화 **양쪽의 간호진단**이다.
의학적 병명(신부전이냐 심부전이냐)은 의사 기록의 몫이고, 간호기록은 소견을 남긴다.

### 저혈압 → 조직관류저하 (2026-08-06)

혈압 경로가 쓰던 **`저혈압`은 마스터 간호진단 목록에 없었다.** 빌드가 계속
「진단아님」으로 경고했다. 쇼크와 같은 **`조직관류저하`**로 바꿨다.

```
■ 조직관류저하
사정) 혈압 저하됨, 체위성 저혈압 있음
진단) 조직관류저하
평가) 혈압 측정함, 체위성 저혈압 증상이 있는지 확인함
```

> 남은 경고는 `안과`의 `감각지각장애 : 시각` 하나다.
> 마스터에는 `감각지각장애:시각,청각,촉각,미각,후각,운동감각` 한 줄로 있다.

### 쇼크 — 진단은 `조직관류저하`

**마스터 간호진단에 「쇼크」도 「저혈압」도 없다.** 쓸 수 있는 것은 넷이다.

| 진단 | |
|---|---|
| **`조직관류저하`** | 쇼크의 본질 — 조직에 피가 안 간다. **채택** |
| `심박출량감소` | 심인성 쇼크에만 맞는다 |
| `체액부족` | 저혈량성 쇼크에만 맞는다 |
| `조직관류저하:심폐계` | 이미 심근경색이 쓴다 |

원인(출혈·패혈증·심장)과 무관하게 하나로 덮고, 이미 쓰는 `조직관류저하:뇌`·
`조직관류저하:심폐계`와 계열이 같아 **`조직관류저하`**를 골랐다.

> **`피부 차가움`·`피부 축축함`은 마스터에 낱개로 없다.** 평가 문장
> `shock 증상(차고 축축한 피부, 혈압하강, 빈맥, 호흡수 증가, 혼수, 소변량 감소)이 있는지 확인함`
> 안에만 들어 있어 그 통짜 문장을 평가로 쓴다.

> **`혈압 저하됨`도 체크형이다.** 마스터에 `혈압 상승됨`·`혈압 저하됨`·`혈압 측정 안됨`만
> 있고 「정상」이 없다.

> **소변량은 체크형이다.** 마스터에 `소변량 감소함` · `증가함` · `없음`만 있고
> **「변화 없음」·「정상」이 없다**(`소변량 없음`은 무뇨라 정상이 아니다).
> 선택형으로 만들면 정상인 환자가 억지로 이상을 골라야 하므로, **줄었을 때만 누른다.**

> **체중은 선택형이다.** `체중 증가함` · `체중 감소함` · `체중 변화 없음` 셋 다 마스터에 있다.

### 부정맥 — 리듬 종류는 아직 안 넣었다

전에는 **심근경색 의심 2개 경로에서만** 물을 수 있었다. 어지럼으로 온 환자의
monitor에 Af가 보여도 기록할 데가 없었다. 추가상태로 빼서 어느 경로에서나 쓴다.

지금은 **있음/없음만** 묻는다. 리듬 종류는 마스터에 26종이 있으나
간호사가 고르기 좋은 목록을 정한 뒤에 넣는다.

<details><summary>마스터에 있는 리듬 진술문 26종</summary>

- **심방** — `atrial fibrillation`(+`with rapid ventricular response`, `with slow ventricular response`) ·
  `atrial flutter` · `atrial premature beat` · `paroxysmal supraventricular tachycardia` (각 있음/없음)
- **심실** — `ventricular tachycardia` · `ventricular fibrillation` · `ventricular flutter` ·
  `ventricular premature beat` (각 있음/없음) · `wide QRS tachycardia 있음` · `bigeminy 보임` · `trigeminy 보임`
- **전도** — `first degree AV block 보임` · `second degree AV block 보임` · `complete AV block 보임` ·
  `Left Bundle Branch Block 있음` · `Right Bundle Branch Block 있음`
- **동결절** — `normal sinus rhythm 임` · `sinus arrhythmia 있음` · `sinus arrest` · `sinus block` ·
  `sick sinus syndrome 있음` · `junctional rhythm` · `wandering pacemaker 보임`
- **속도** — `빈맥` · `서맥` (각 있음/없음) · `심박동수 증가함/감소함` · `맥박수 증가됨/감소함`
- **파형** — `QRS 넓어져 있음` · `QT 간격 연장되어 있음/짧아짐`
- **맥박** — `불규칙 맥박 촉지됨` · `결손맥박 있음/없음`
- **Pacemaker** — `pacemaker 유지 중임` · `pacing beat 보임` · `pacemaker capture/sensing failure 보임`

</details>

> **`EKG monitor 시작함`은 넣지 않았다** — 실제로 모니터를 안 걸었는데 기록될 수 있다.
> 심근경색 경로에는 그대로 남아 있다.

### 뱀 물림

**마스터에 「뱀」 진술문이 없다.** 지어내지 않고 국소 소견으로 남긴다.

| 항목 | 사정 |
|---|---|
| 🐕 물림 (동물·사람·뱀) | `피부 손상 있음` · `redness 있음/없음` · `edema 있음/없음` · `통증 있음/없음` |
| 🐝 쏘임 (벌·곤충) | `redness 있음/없음` · `edema 있음/없음` · `통증 있음/없음` |

전신 증상(`호흡곤란`·`dizziness`·`오심구토`)은 **기본 3문이 이미 담당**하므로 중복해서 넣지 않았다.
뱀인지 개인지는 **괄호 비고**에 적는다.

> 부위 괄호(`늑골 골절 있음(가슴)`)는 **부위 묶음에만** 붙인다.
> 추가상태는 항목 이름이 곧 소견이라 `황달 있음(황달)`이 되면 군더더기다.

## 4. 사정을 자르지 않는 이유

「증상당 2~3문」으로 자르는 안을 검토했으나 **자르지 않기로 했다.**

| | 자르면 | 안 자르면 |
|---|---:|---:|
| 증상 문항 | 2.6문 | 4.2문 |

차이가 **평균 1.6탭**뿐인데 반해 잃는 것이 크다.

- 피부·화상의 `감염위험`은 근거 문항이 4번째라 잘리면 진단이 사라진다
- 외상에서 「피가 나나요?」(출혈)·「다친 곳이 아프세요?」(급성통증)가 잘린다
- 어떤 질문이 잘렸는지 간호사가 알 수 없다 — **「놓치지 않게」라는 목적과 어긋난다**

→ 엑셀 문항 순서를 손댈 이유도 없어졌다.

## 5. 간호진단

### 켜지는 기준
**그 진단의 고유 사정이 양성일 때만** 켜진다. 개수로 자르지 않는다.

| 답변 방식 | 켜지는 진단 수 |
|---|---|
| 대표 증상만 양성 (실제로 흔한 답) | 1개 51경로 · 0개 9경로 · **3개 이상 없음** |
| 모든 문항 양성 (최악) | 1개 28 · 2개 22 · **3개 10경로** |

**4개 이상은 어떤 경우에도 나오지 않는다.**

### 3개 이상이면 경고만
```
⚠️ 간호진단이 3개입니다 — 낙상위험까지 4개가 됩니다.
   꼭 필요한 것만 남기고 「빼기」를 눌러주세요.
```
- **복사를 막지 않는다.** 복사 잠금은 미응답 문항만 본다.
- 「빼기」를 누르면 경고가 사라진다.

> **왜 자동으로 안 자르나** — 「급성통증 먼저, 나머지 1개」로 자르면
> 외상·임신·부인과에서 **출혈 13건**, 임신·화상에서 **감염위험 6건**,
> 심근경색에서 **부정맥 2건**이 사라진다.
> 잘리는 기준이 엑셀 행 순서라 임상 중요도와 무관하다.
> 무엇이 중요한지는 간호사가 안다.

### 통증 규칙
통증이 있으면 **무조건 `급성통증`** (HIS 관행).
기간이 **3개월 이상**이면 `만성통증`으로 넘어가고 `만성 통증 있음`이 붙는다.

## 6. 기록 형식

```
[이름 등록번호]

■ 기본 사정
사정) dizziness 없음, 호흡곤란 없음, 의식수준 : alert, grasp power 강함, 불편감 없음

■ 급성통증
사정) 복부 통증 있음, 오심, 구토 없음, 복부 불편감 없음, 대변 못 봄, 설사 없음, gas out 안됨
진단) 급성통증
평가) 통증을 인정해줌, 통증 양상을 확인함, 통증부위를 사정함

■ 의식 · 낙상
사정) 의식 명료함, 보호자 있음
진단) 낙상위험
평가) 낙상방지 교육함, 침대 난간을 올려줌, 도난방지 교육함

(통증 — 기간 오늘·며칠 전 / 부위 배(RLQ) / 사정도구 NRS / 통증강도 7점 / 양상 욱신·쑤시는 / 빈도 지속적)
```

**규칙**
- **진단 근거인 문항은 그 진단 블록에 남긴다.** 기본·신경학이라도 그 경로 진단의 사정이면
  「기본 사정」으로 올리지 않는다. 안 그러면 **진단만 있고 사정이 빈다.**
- 같은 진술문이 여러 진단에 걸리면 **앞 블록에만** 넣는다.
- **평가도 앞 블록에만** 넣되, 그래서 2개가 안 되면 **그 진단의 남은 평가로 채운다.**
  (혈압 경로에서 `혈압 측정함`이 고혈압에 먼저 쓰여 조직관류저하에 1개만 남았다)
- 근거가 없는 진단은 **진단·평가를 적지 않되 사정은 남긴다.** 음성 소견도 확인했다는 근거다.
- 「의식 · 낙상」은 **항상 맨 끝**.
- 부위·상황을 고르면 진술문 뒤에 괄호가 붙는다 — `늑골 골절 있음(가슴)`
