# 간호기록 데이터 관리 (엑셀 → 빌드 → 앱)

> 앱(`app/`)이 쓰는 데이터를 **코드가 아니라 엑셀에서** 관리한다.
> 칩스(수간호사)가 엑셀만 고치면 되고, 빌드 스크립트가 앱에 꽂는다.

## 흐름

```
data/간호기록_원본_260621.xlsx   ← 칩스가 편집 (진술문·질문·분기·필수…)
        │  python3 data/build_nfh.py
        ▼
app/nfh_data.js  (window.NFH_RAW)  ← 자동 생성 (직접 수정 금지)
        ▼
app/nfh_core.js 가 읽어 앱 동작
```

**편집 후 한 줄:** 저장소 루트에서
```
python3 3_서비스/NFH간호기록/data/build_nfh.py
```
→ `app/nfh_data.js` 갱신 + 마스터 대조 경고 출력.

## 엑셀 시트

| 시트 | 내용 | 핵심 열 |
|---|---|---|
| 1.주호소트리 | 주증상 → (분기질문/선택) → 사정세트 연결 | 질문1·선택1·질문2·선택2 / 대분류·소분류 |
| 2.사정세트 ★ | 사정세트별 A&E·D·P&E 진술문 | 진술문 / **질문문구(💬)** / **입력형식** / **필수** / 비고 |
| 3.환자설명 | 진단별 말할 문구 ↔ 연동 P&E | |
| 4.도관 / 5.낙상교육 | 체크리스트 / 교육 멘트 | |

**코드에 박혀 있던 게 이제 엑셀 열이 됨** — 칩스가 직접 관리:
- **질문문구(💬)** — 비우면 자동 생성문 사용. 채우면 그 문구로.
- **입력형식** — `토글`(있음/없음) / `값입력`(동공크기 :) / `체크`. 비우면 자동 판별.
- **필수** — `Y`면 ⚠️필수 뱃지 + 누락 강조.

## 데이터 무결성 (중요)

- **진술문 열은 마스터(`Nr.statement_*.xlsx`) 원문만.** 빌드가 마스터 전체 시트와 자동 대조.
- 마스터에 없는 표기는 **`_마스터미일치.txt`에 기록 + 콘솔 경고**. **빌드를 막지는 않음**(값을 임의로 고치지 않기 위함).
  → 이 목록은 **칩스가 마스터와 대조해 확정**할 항목. 현재 약 108건(주로 P&E 문구·`gas out`·`대변 못봄` 등 표기 변형).
- 스크립트는 값을 **지어내거나 보정하지 않는다.** 빈 칸은 빈 칸으로.

## 파일

- `간호기록_원본_260621.xlsx` — **편집 대상** (칩스)
- `build_nfh.py` — 엑셀 → `app/nfh_data.js` + 마스터 대조 ★상시 사용
- `seed_from_current.py` — (일회성) 현재 앱 데이터 → 엑셀 역생성. 이미 실행됨. 재실행 시 엑셀 덮어씀 주의
- `_마스터미일치.txt` — 빌드가 생성하는 칩스 확인 목록 (커밋 제외 가능)

## 주의

- `app/nfh_data.js`는 **자동 생성물** — 직접 고치지 말 것(다음 빌드 때 덮어씀).
- 분기 깊이는 2단(질문1→질문2)까지 지원. 실제 데이터가 그 범위.
