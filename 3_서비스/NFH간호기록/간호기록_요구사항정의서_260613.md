## 2. 전체 흐름 (5단계)

화이트보드 8단계를 5단계로 압축. ④ 낙상은 **누락 시 처벌 대상**이라 독립 유지.
v4는 ②③④를 **한 화면에 세로로 쌓고**, 하단 미리보기 시트가 ⑤를 실시간 반영한다.

```
① 맞이·확인        신원확인 + 라인/튜브 + 환의/귀금속
       ↓
② 사정 ★          주호소(복수 선택) → 주호소당 핵심 ~5문항 (스무고개)
       ↓
③ 진단·중재        진단 자동 추천(중복제거)+수동 추가 / 중재 안내멘트(양방향)
       ↓
④ 낙상교육         의식·보호자 확인 + 낙상 교육 (디폴트·항상 🔒)
       ↓
⑤ 기록 완성·복사    실시간 미리보기 → 간호기록 형식 → EMR용 복사
```

> **"스무고개"는 비유** — 끝없이 묻는 게 아니라 **주호소당 핵심 ~5문항**(데이터상 A&E 평균 4.5문항)으로 좁혀 사정한다는 뜻.

## 3. STEP ① 맞이·확인

| 입력 | 출력 | 동작 |
|------|------|------|
| 간호사 탭(확인 체크) | (선택) 도관 진술문 | 환자 곁 도착 직후 사전확인 한 번에 |

### 3-1. 신원확인 (비임상 UI 대본 — 기록 미포함)
- 대본 멘트 표시: "안녕하세요~ 성함이 어떻게 되세요?" / 팔찌 확인.
- 초진(KTAS) 기록과 주호소가 **다르면 확인 신호** 표시. (오프라인 → EMR 자동연동 없음, **간호사 수동 대조**)

### 3-2. 라인·튜브(도관) — 체크리스트, 없으면 건너뜀
선택 시 진술문 기록. **풀텀 + 약어 표시.** **[마스터(`Nr.statement_*.xlsx`) 대조 필요]**

| 표시명 | 기록 진술문 |
|--------|------------|
| Central Venous Catheter (CVC/PICC) | Central Venous Catheter (CVC/PICC) 삽입중 |
| Foley Catheter (유치도뇨관) | Foley Catheter (유치도뇨관) 삽입중 |
| Percutaneous Transhepatic Biliary Drainage (PTBD) | PTBD 삽입중 |
| Percutaneous Transhepatic Gallbladder Drainage (PTGBD) | PTGBD 삽입중 |
| Percutaneous Catheter Drainage (PCD) | PCD 삽입중 |
| 흉관 유지중 | 흉관 유지중 |
| 기타 직접 입력 | 입력값 그대로 |

### 3-3. 환의·귀금속 — 체크리스트
- 환자복 교체 / 귀금속 제거 안내(대본).
- **기록 진술문으로 남기는지 `[칩스확인필요]`.**

## 4. STEP ② 사정 ★ (핵심)

| 입력 | 출력 | 동작 |
|------|------|------|
| 주호소 선택(복수) + 문항 토글/값/체크 | 선택된 A&E 진술문 목록 | 주호소별 사정 세트 누적 |

### 4-1. 주호소 복수 선택 (대분류 15)

😣통증 / 🫁호흡곤란 / 🩸출혈(눈에 보임) / 🩹출혈(외상·코피) / ⚠️출혈위험
🦠감염 / 🚨감염위험 / 🌡️고체온 / 🥶저체온 / 🧠뇌경색·뇌출혈
❤️심근경색 의심 / 🍬고혈당 / 💉저혈당 / ⚡Seizure / ✅이상없음

- **복수 선택 가능** — 한 환자가 **통증＋출혈** 동시 선택 가능 → 각 사정 세트가 따로 돌고 결과 누적.
- 소분류로 분기(예: `혈변-복부통증 있음/없음`).
- **이상없음** 선택 → 사정 건너뛰고 STEP ④로.

### 4-2. 분기 질문 (소분류)

| 주호소 | 분기 질문 |
|--------|-----------|
| 통증 | 부위? (복부/흉부/두통/기타) |
| 호흡곤란 | 가래 많음? 심부전 의심? 흉통 동반? |
| 출혈(눈에 보임) | 종류? → 각 통증 동반 여부? |
| 출혈(외상)·출혈위험·고체온 | 통증 동반? |
| 심근경색 | 흉통 동반? |
| Seizure | 지금 발작 중? / 멈추고 내원? |
| 그 외 | 단일 세트 |

### 4-3. 문항 형식 자동 판별 (원문 텍스트 기준)

| 원문 형태 | UI | 기록 규칙 |
|-----------|----|-----------|
| 슬래시 `있음/없음`, `강함/약함` | **있음(빨강)/없음(회색) 토글** | 선택값을 **완전한 진술문**으로 기록 |
| 콜론 `동공크기 :`, `INR :` | **값 입력 칸** | 입력값 포함 문장 |
| 일반 문장 (예: "복부 통증 있음") | **체크(기록함)/해당없음** | 원문 그대로 |

- **슬래시 완전 문장 규칙**: 선택한 버튼 텍스트만이 아니라 **주어 포함 완전한 진술문**을 기록.

| 원본 텍스트 | 선택 | 기록되는 진술문 |
|------------|------|----------------|
| 혈변 있음/없음 | 없음 | **혈변 없음** |
| grasp power 강함/약함 | 약함 | **grasp power 약함** |
| 빛 반사 prompt/sluggish/hippus 함 | sluggish | **빛 반사 확인결과 sluggish 함** |

- **양성/음성 색 규칙**: 옵션의 `있음/없음` 위치는 문항마다 다를 수 있으므로 **데이터의 `pos` 플래그**로 색을 결정한다(양성=빨강, 음성=회색). UI 좌우 위치로 판단하지 않는다.
- **미평가·건너뛰기 허용**(빠른 손맛). 단 `필수` 문항(예: 혈변)은 **미평가 시 "⚠️ 놓치면 안 됨" 경고** 표시.
- **빠른 모드** — `✓ 나머지 다 정상으로` 버튼: 미평가 문항을 모두 음성(정상)으로 일괄 처리.

### 4-4. 통증 NRS (비고 전용)

통증 문항 '있음' 선택 시 **인라인 펼침**. **정형 진술문 아님 → 출력 "비고란"으로만** 표시.

| 평가 항목 | 입력 방식 | 비고란 표시 예시 |
|-----------|-----------|------------------|
| 통증강도 | NRS 0~10 칩 | 통증강도 7점 |
| 통증부위 | [상복부][하복부][우하복부][좌하복부][흉부][머리][전신][기타] | 통증부위 하복부 |
| 통증양상 | [쥐어짜듯][찌르듯][둔하게][타는듯][콕콕] | 통증양상 쥐어짜듯 |
| 발생시기 | [방금 전][몇 시간 전][어제][며칠 전] | 통증기간 몇 시간 전부터 |
| 지속여부 | [지속적으로][간헐적으로][지금은 없음] | 통증지속 지속적으로 |

> 모든 통증 증상(복부/흉부/두통/기타/출혈동반통증 등)에 동일 적용.

### 4-5. note(💡)
- 각 문항의 보조 안내(`n`, 예: "GCS 15 일때")를 작은 글씨로 표시.

## 5. STEP ③ 진단·중재

| 입력 | 출력 | 동작 |
|------|------|------|
| 선택된 주호소 블록 / 체크 / 수동입력 | 진단(D)·중재(P&E) 목록 | 자동 추천 + 수동 추가 |

### 5-1. 간호진단 (D)
- **자동 추천** — 사정에서 양성(있음) 선택 시 대응 진단을 추천 카드로 노출(예: 복부 통증 있음 → `급성 통증`, 오심·구토 있음 → `오심`).
- **채택은 간호사 선택**(토글). 양성이 해제되면 후보에서 자동 제거.
- **수동 추가** — 목록에서 선택 또는 직접 입력. 한 환자에 **여러 진단** 가능(예: `비효율적 호흡양상 ＋ 급성통증`).
- **낙상위험 진단은 STEP ④에서 항상 자동 포함** 🔒.
- 화면에는 추천/채택만, 채택된 D는 미리보기·팝업에 누적(중복 제거).

> ⚠️ **데이터 품질 플래그(임의 수정 금지 → 칩스확인필요):** `감염`·`감염위험`·`고체온` 블록의 D 목록에 "감염증상이 있는지 확인함", "체온 측정함" 등 **P&E로 보이는 항목이 D에 섞여 있음**(라벨 오류 의심). 앱은 **원본 그대로 표시**하되, 마스터 정정 시 데이터만 교체.

### 5-2. 중재 (P&E) — 환자 안내 멘트
- **말할 문장(📢) 표시 → 체크 시 대응 P&E 진술문 자동 기록**(양방향 동기화).
- 원문 그대로. 일부만 정의됨 → 나머지 **[칩스확인필요]**.

**통증(정의됨):**
- "많이 아프세요? 진통제가 필요하실 만큼 아프신가요?" → 통증을 인정해줌
- "의사 선생님께 확인받고 필요하시면 진통제 처방받아 드릴게요." → 통증 양상을 확인함
- "참으실 수 있으면 지켜보시고, 너무 아프시면 바로 말씀해 주세요." → 통증을 관찰하기로 함

**호흡곤란(정의됨):**
- "숨이 많이 차세요? 지금 산소 수치 확인해 드릴게요." → 호흡곤란이 있는지 확인함
- "산소 마스크 착용해 드릴게요. 더 힘드시면 바로 말씀해 주세요." → 산소흡입 시작함

**출혈·신경계 일부 정의됨**, 그 외 증상 멘트는 **[칩스확인필요]**.

## 6. STEP ④ 의식 / 낙상 (디폴트·항상 🔒)

| 입력 | 출력 | 동작 |
|------|------|------|
| 의식·보호자·교육 체크 | 의식 A&E / 낙상위험 D / 교육 P&E | 항상 표시, 제외 불가 🔒 |

### A. 의식 확인
💬 "성함이 어떻게 되세요? 오늘 날짜 아세요? 여기가 어딘지 아세요?"

| 선택 | 기록 |
|------|------|
| 의식 명료함 | 의식 명료함 |
| 의식 저하 | 의식수준 : [입력] / Obey command / 지남력 |

### B. 보호자 확인
| 선택 | 기록 |
|------|------|
| 보호자 상주 | 보호자 환자 옆에 상주하고 있음 |
| 보호자 없음 | 보호자 동행하지 않음 |

### C. 낙상교육 스크립트 (📢 말할 문장 → 체크 시 P&E 원문 기록)

| 📢 말할 문장 | 기록 (원문) |
|-------------|------------|
| "침대에서 내려오실 때는 반드시 간호사를 불러주세요." | 침대에서 내려오실 때 반드시 간호사 호출하도록 교육함 |
| "어지러우시면 바로 앉으시고, 보호자나 담당 간호사에게 알려주세요." | 어지러우면 바로 앉고 보호자나 담당간호사에게 알리도록 교육함 |
| "낙상 위험이 있어서 침대 난간 올려드릴게요." | 낙상 위험성에 대해 설명함 / 침대 난간을 올려줌 / 낙상방지 교육함 |
| (보호자 있을 때) "옆에서 계속 함께 있어 주세요." | 보호자와 같이 있게 함 |
| (보호자 없을 때) "보호자분 연락해 주세요." | 보호자 동반하도록 설명함 |

- 진단 **낙상위험**은 의식/낙상 미완료 시에도 자동 포함 🔒.

## 7. STEP ⑤ 기록 완성·복사

| 입력 | 출력 | 동작 |
|------|------|------|
| ①~④ 전체 선택 결과 | 간호기록 형식 + 복사 | EMR 붙여넣기 |

- **실시간 미리보기** — 하단 시트에 탭하는 즉시 정형 간호기록이 쌓이고 줄 수(카운트) 표시.
- **취합** — 도관 + (주호소별 A&E·D·P&E) + 의식/낙상 A&E·D·P&E.
- **출력 형식** — `[증상] → A&E / 비고(NRS) / D / P&E` 순. 통증 NRS는 **비고란** 별도.
- **복사** — EMR/엑셀 붙여넣기용 텍스트(TSV 고려). **자동 붙여넣기는 "고려만"** → 현 버전은 복사까지.

### 출력 예시(미리보기·복사)
```
[복통]
A&E · 오심, 구토 있음
A&E · 복부 통증 있음
📌 비고: 통증강도 7점 / 통증부위 하복부 / 통증양상 쥐어짜듯
D · 급성 통증
P&E · 통증을 인정해줌

[의식/낙상]
A&E · 의식 명료함
A&E · 보호자 환자 옆에 상주하고 있음
D · 낙상위험
P&E · 낙상방지 교육함
```

---

## 8. 출력 규칙 (요약)

- 미리보기/표의 A&E·D·P&E는 **마스터 원문만**. NRS는 비고란으로만.
- 진단: 자동 추천 → 채택 + 수동 추가, 낙상위험 항상 포함 🔒.
- 색상: **A&E 파랑 / D 빨강 / P&E 노랑 / 비고 회색**, 양성(있음) 강조 빨강.
