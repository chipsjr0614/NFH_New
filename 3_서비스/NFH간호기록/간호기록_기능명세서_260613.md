## 1. 전체 흐름 (5단계)

화이트보드 8단계를 5단계로 압축. ④ 낙상은 **누락 시 처벌 대상**이라 독립 유지.

```
① 맞이·확인        신원확인 + 라인/튜브 + 환의/귀금속
       ↓
② 사정 ★          주호소(복수 선택) → 주호소당 핵심 ~5문항
       ↓           (통증용·출혈용 등 주호소별 사정 세트)
③ 진단·중재        진단 자동 누적(중복제거)+수동 추가 / 중재 안내멘트
       ↓
④ 낙상교육         의식·보호자 확인 + 낙상 교육 (디폴트·항상)
       ↓
⑤ 기록 완성·복사    전체 취합 → 간호기록 형식 → EMR용 복사
```

**"스무고개"는 비유** — 끝없이 묻는 게 아니라 **주호소당 핵심 ~5문항**(데이터상 A&E 평균 4.5문항)으로 좁혀 사정한다는 뜻.

## 2. 단계별 기능 명세

### ① 맞이·확인

| 입력 | 출력 | 동작 |
|------|------|------|
| 간호사 탭(확인 체크) | (선택) 도관 진술문 | 환자 곁 도착 직후 사전확인 한 번에 |

- **신원확인** — 대본 멘트 표시(비임상): "안녕하세요~ 성함이 어떻게 되세요?" / 팔찌 확인.
  - 초진(KTAS) 기록과 주호소가 **다르면 확인 신호** 표시. (오프라인 → EMR 자동연동 없음, 간호사 수동 대조)
- **라인·튜브** — 체크리스트(없으면 건너뜀). 선택 시 진술문 기록:
  - CVC/PICC, Foley(유치도뇨관), PTBD, PTGBD, PCD, 흉관, 기타 직접입력 → "…삽입중/유지중". **[마스터 대조 필요]**
- **환의·귀금속** — 체크리스트. 기록 진술문 여부 **[칩스확인필요]**.

### ② 사정 ★ (핵심)

| 입력 | 출력 | 동작 |
|------|------|------|
| 주호소 선택(복수) + 문항 토글/값/체크 | 선택된 A&E 진술문 목록 | 주호소별 사정 세트 누적 |

- **주호소 복수 선택** — 대분류 15 중 선택 → 소분류로 분기(예: `혈변-복부통증 있음/없음`). 한 환자가 **통증＋출혈** 동시 선택 가능 → 각 사정 세트가 따로 돌고 결과 누적.
- **문항 형식 자동 판별**(원문 텍스트 기준):
  - 슬래시 `있음/없음`, `강함/약함` → **있음(빨강)/없음(초록) 토글**, 선택값을 **완전한 진술문**으로 기록(예: "혈변 없음").
  - 콜론 `동공크기 :`, `INR :` → **값 입력 칸**.
  - 일반 문장(예: "복부 통증 있음") → **체크(기록함)/해당없음**.
  - 모든 문항 **미평가·건너뛰기** 허용(빠른 손맛). 단 중요한 건 한 번은 묻고 지나가게.
- **통증 NRS(비고 전용)** — 통증 문항 선택 시 펼침: 강도(0~10)·부위·양상·발생시기·지속여부. **정형 진술문 아님 → 출력 "비고란"으로만** 표시.
- **note(💡)** — 각 문항의 `n`(예: "GCS 15 일때")을 보조 안내로 표시.

### ③ 진단·중재

| 입력 | 출력 | 동작 |
|------|------|------|
| 선택된 주호소 블록 / 체크 / 수동입력 | 진단(D)·중재(P&E) 목록 | 자동 누적 + 수동 추가 |

- **진단(D) 자동 누적** — 선택한 모든 주호소 블록의 D를 모아 **중복 제거 후 표시**. 한 환자에 **여러 진단** 가능(예: `비효율적 호흡양상 ＋ 급성통증`).
- **진단 수동 추가** — 간호사가 진단을 더 추가할 수 있는 UI(목록에서 선택 또는 직접 입력). 추가분도 기록에 합산.
- **낙상위험 진단은 ④에서 항상 자동 포함** 🔒.
- **중재(P&E)** — 블록별 P&E를 체크박스로 제시(기본 선택). 원문 그대로.
- **환자 안내 멘트** — 증상별 대본 표시 → 체크 시 대응 P&E 자동 연동(양방향). 일부만 정의됨 → 나머지 **[칩스확인필요]**.

### ④ 낙상교육 (디폴트·항상)

| 입력 | 출력 | 동작 |
|------|------|------|
| 의식·보호자·교육 체크 | 의식 A&E / 낙상위험 D / 교육 P&E | 항상 표시, 제외 불가 🔒 |

- **의식 확인** — 명료/저하(의식수준·Obey command·지남력 값입력). 원문.
- **보호자 확인** — 상주 / 동행없음.
- **낙상 교육 멘트** → 체크 시 P&E 원문 기록("낙상방지 교육함", "침대 난간을 올려줌" 등).
- 진단 **낙상위험**은 의식/낙상 미완료 시에도 자동 포함.

### ⑤ 기록 완성·복사

| 입력 | 출력 | 동작 |
|------|------|------|
| ①~④ 전체 선택 결과 | 간호기록 형식 표 + 복사 | EMR 붙여넣기 |

- **취합** — 도관 + (주호소별 A&E·D·P&E) + 의식/낙상 A&E·D·P&E.
- **출력 형식** — `소분류 / 세부분류 / 과정(A&E·D·P&E) / 간호 진술문` 표. 통증 NRS는 **비고란** 별도.
- **복사** — EMR/엑셀 붙여넣기용 TSV. **자동 붙여넣기(복붙)는 "고려만"** → 현 버전은 복사까지.

## 3. 출력 규칙 (요약)

- 팝업/표의 A&E·D·P&E는 **마스터 원문만**. NRS는 비고란으로만.
- 진단: 자동 누적(중복제거) + 수동 추가, 낙상위험 항상 포함 🔒.
- 색상: A&E 파랑 / D 보라·빨강 / P&E 초록·노랑 / 비고 회색 (V2 팔레트).
