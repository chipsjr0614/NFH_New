# 소아 약물 용량 — 초안 검수표

**작성:** 2026-08-10
**요청:** "확인 필요한 약물은 AHA 기준 또는 약물표 기준으로 찾아줄 것" (칩스)
**용도:** 앱 소아 탭의 `확인 필요` 항목을 채우기 위한 **초안**. 검수 후 확정

> ⚠️ **이 값들은 원내 기준이 아니다.** 타 기관 표준 자료에서 가져온 것이며,
> 국립소방병원 프로토콜·약제부 확인을 거쳐야 확정된다. 앱에는 `초안` 배지가 붙어 있다.

## 2. 채운 값 — 출처가 일치하거나 단일 출처

| 약물 | 초안 용량 | 출처 | 주의 |
|------|-----------|:----:|------|
| **Naloxone** | **0.1 mg/kg** IV (1회 max 2mg), 30초에 걸쳐, q2~3분 반복 | B·C·D **일치** | D: 5세 미만 또는 20kg 이하는 0.1mg/kg / 20kg 초과는 2mg. 알칼리 용액과 혼합 금지 |
| **Flumazenil** | **0.01 mg/kg** (1회 max 0.2mg) IV q1분<br>누적 max **0.05 mg/kg 또는 1mg** 중 낮은 쪽 | B·C **완전 일치** | ★ 만성 벤조 복용자·경련 환자 **금기**. 의도적 과량복용에는 일상적으로 쓰지 않음 |
| **활성탄** | **0.5~1 g/kg** PO/NG (**sorbitol 없는 제형**) | C | 섭취 후 가급적 1시간 이내 |
| **Mannitol** | **0.25~1 g/kg** IV over 20분 | C | 저혈량 아닌지 먼저 확인 · **5μm 미만 필터** 필요 |
| **Salbutamol 네뷸** | **0.15 mg/kg** (최소 2.5mg, 통상 2.5~5mg) q20분 ×3회 → 필요시 q1시간<br>지속 네뷸: 5~15 mg/hr | A·C **일치** | 원내 Ventolin Nebule = 2.5mg/2.5mL |
| **Insulin (속효성)** | DKA: **0.05 U/kg/hr 지속주입** (★볼루스 금지)<br>고칼륨혈증: **0.1 U/kg** IV (max 10U) + Glucose 0.5 g/kg 병용 | C | DKA에서 혈당 <300 → D5NS 추가, <200 → D10 추가 |
| **Dextrose 10% (저혈당)** | Glucose **0.5 g/kg** IV (max 25g) → **D10W 기준 5 mL/kg** | C | B는 6개월 미만 0.25~0.5 g/kg / 6개월 이상 0.5~1 g/kg |
| **Vitamin K1** | 신생아 예방 **0.5~1 mg IM 1회** (출생체중 >1500g는 1mg) | D (AAP 2022) | **체중 비례가 아닌 고정 용량** — 계산기에 kg 곱을 넣지 말 것 |

## 3. ★ 출처 간 값이 다른 항목 — 원내 결정 필요

**임의로 하나를 고르지 않았다.** 앱에는 범위를 병기하고 `출처 불일치` 표시를 달았다.

| 약물 | A (설계서/AHA) | B (UNC) | C (OHSU) | 결정 필요 |
|------|---------------|---------|---------|-----------|
| **Methylprednisolone** | 1~2 mg/kg, max **125mg** | 1~2 mg/kg/day, max **60mg/day** | **2 mg/kg** ×1 → 0.5~1 mg/kg q6h, max 60mg/day(<12세) | 초회 용량과 **최대치**가 다름 |
| **Famotidine** | 0.5~1 mg/kg, max 50mg | **0.25 mg/kg**, max 40mg/day | — | **2~4배 차이** |
| **Diazepam (경련)** | PR 0.5 mg/kg, max 20mg | IV 0.1~0.3 mg/kg, max 10mg | IV **0.1~0.2 mg/kg**, max 10mg | 투여경로·용량 모두 다름. 원내는 IV 제형(10mg/2mL) |
| **Ipratropium** | — | — | Duoneb(Albuterol+Ipratropium) **3mL** q20분 ×3 | 원내는 **Atrovent UDV 500mcg/2mL 단독** — 조합 제형이 아님. 단독 용량 확인 필요 |

## 4. 근거를 못 찾은 항목 — `확인 필요` 유지

| 약물 | 상태 |
|------|------|
| **Budesonide (Pulmicort respule)** | B·C 표에 없음. 크룹·천식 RCT에서 2mg 사용례가 있으나 **표준 투약표 근거가 아니라 채우지 않았다** |
| **Acetylcysteine (Mucomyst)** | 소아 용량 미확보. 앱 해독 탭에 성인 `150mg/kg loading` 있음 |
| **Potassium chloride** | 소아 응급 표준표에 없음(원내 희석 프로토콜 사안) |
| **Vasopressin** | 소아 심정지 일상 권고가 아님 — B·C 표에 없음 |
| **Lacosamide (Vimsk)** | B·C 표에 없음 |

## 5. ★ 덤 — 기존 앱 값과 어긋나는 것 (교차 대조 중 발견)

**요청 범위 밖이지만 발견한 이상.** 기존 앱 값이 틀렸다는 뜻은 아니고, **출처가 다르다**는 뜻이다.

| 항목 | 현재 앱 | B (UNC) | C (OHSU) | 비고 |
|------|---------|---------|---------|------|
| **Ketorolac** | 0.5mg/kg, max **30mg** | 0.5mg/kg, max **15mg**/회 | — | A는 30mg. **max가 2배 차이** |
| **Ondansetron** | **0.15** mg/kg, max 8mg | **0.1** mg/kg (<40kg) | — | A는 0.15 |
| **Midazolam 진정** | 0.05~0.1mg/kg (max 없음) | 0.05~0.1mg/kg, **max 2mg** | — | A는 max 5mg. **앱에 상한이 없다** |
| **Atropine** | max 0.5mg 표시 | 1회 max 0.5mg + **총 최대 소아 1mg / 청소년 3mg** | — | 앱에 **총 최대치가 없다** |
| **Rocuronium** | 1.2 mg/kg | **1 mg/kg**, max 100mg | — | 병원 컨펌표도 1mg/kg. 앱만 1.2 |
| **Dexamethasone** | 항구토 0.15mg/kg | **크룹 0.6mg/kg, max 16mg** | 크룹 0.6mg/kg, max 16mg | 적응증이 다름 — 크룹 용량이 앱에 없다 |
| **유지수액** | Holliday-Segar | — | **4-2-1 rule** | ✅ 동일 공식 — 일치 확인 |

## 6. ★ 소아 지속주입(CIV) 범위 — 프리믹스와 결합 가능

C에 소아 CIV 용량 범위가 있고, 응급실에 **프리믹스 백**이 있어 계산이 가능해진다.

| 약물 | 범위 (C) | 원내 농도 | 비고 |
|------|---------|-----------|------|
| Dopamine | **2~20 mcg/kg/min** | Dopamix 400mg/200mL = **2,000 mcg/mL** | 프리믹스 그대로 |
| Dobutamine | (C에 별도 표기 없음) | DoBUtamine/D5W = **2,000 mcg/mL** | ⬜ 범위 확인 필요 |
| Epinephrine | **0.01~0.1 mcg/kg/min** (쇼크), 0.01~1 (일부 표기) | 1mg/1mL 앰플 → 희석 필요 | ⬜ 원내 희석법 |
| Norepinephrine | **0.05~1 mcg/kg/min** | Norpin 4mg/4mL → V4 표준 20mcg/mL | ⬜ 소아도 20mcg/mL인지 |

> 요구사항정의서 2.4절(소아 CIV 서브탭) 구현에 그대로 쓸 수 있다. **단 검수 후.**

## 7. 그 밖에 확인된 것

- **3% 고장성 식염수** — 두개내압 상승 시 3 mL/kg (범위 2~5), 15~30분 [C]. **원내 보유 여부 확인 대기** 항목과 연결
- **Racemic epinephrine** — 크룹 stridor에 0.25mL ×2회 네뷸 [C]. **원내 미보유** → Ventolin·스테로이드로 대응
- **DKA** — 인슐린·중탄산 **볼루스 금지**, 등장액 사용, NS **10 mL/kg** 볼루스 [C]. 앱 DKA 표기(10~20mL/kg)와 대조 필요
