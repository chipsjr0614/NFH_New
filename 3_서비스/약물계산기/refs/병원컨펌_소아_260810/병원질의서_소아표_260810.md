## A. 수치 확인 요청 — 3건 (★ 최우선)

### A-1. Epinephrine IV (1:10,000) · **6-7kg 열** — 10배 의심

| 항목 | 내용 |
|------|------|
| 표 기재 | `0.65mg (0.65ml)` |
| 문제 | 같은 행 다른 10개 열은 전부 **0.010 mg/kg**인데, 이 열만 **0.100 mg/kg** |
| 근거 | 3kg→0.03 / 4kg→0.04 / 5kg→0.05 / **6-7kg→0.65** / 8-9kg→0.085 / 10-11kg→0.1 … 앞뒤 열과 자릿수가 어긋남 |
| 보조 근거 | 괄호 안 **ml 값(0.65ml)은 정상** — 0.1mg/ml 기준 0.065mg에 해당. **mg 표기만 어긋남** |
| 제안값 (미적용) | `0.065mg (0.65ml)` |
| **확인 요청** | **0.065mg가 맞습니까?** |

### A-2. Cardioversion · **19-23 / 24-29 / 30-36kg 열** — 2배 의심

| 항목 | 내용 |
|------|------|
| 표 기재 | `40J/80J` · `53J/106J` · `66J/132J` |
| 문제 | 바로 윗줄 **Defibrillation 행의 같은 열 값과 완전히 동일** |
| 근거 | 나머지 8개 열에서 Cardioversion은 Defibrillation의 **정확히 1/2**(1J/kg → 2J/kg). 이 3개 열만 동일값 |
| 대조 | 15-18kg: 제세동 33/66 ↔ 심율동전환 17/33 (1/2 유지) → 19-23kg부터 깨짐 |
| 제안값 (미적용) | `21J/42J` · `27J/53J` · `33J/66J` |
| **확인 요청** | **제세동 값이 잘못 복사된 것입니까? 심율동전환 1J/kg → 2J/kg가 맞습니까?** |

### A-3. Epinephrine ET 행 — **라벨과 부피 불일치**

| 항목 | 내용 |
|------|------|
| 표 기재 | 행 이름 `Epinephrine ET (1:10,000)` / 값 `0.3mg(0.3ml)` … `3.3mg(3.3ml)` |
| 문제 | mg÷ml 역산 시 **11개 열 전부 1.00 mg/ml** = **1:1,000**. 라벨(1:10,000 = 0.1mg/ml)과 어긋남 |
| 대조 | 같은 표의 **IV 행은 역산 0.10mg/ml** 로 라벨(1:10,000)과 일치 |
| 영향 | 라벨대로 1:10,000을 조제해 표의 ml을 투여하면 **실제 용량의 1/10** |
| 제안 (미적용) | 행 이름을 `Epinephrine ET (1:1,000)` 으로 정정 |
| **확인 요청** | **ET 투여는 1:1,000 원액 기준이 맞습니까? 라벨 오기입니까?** |

## B. 원내 재고와 불일치 — 5건

앱은 **표의 mg 값을 정본으로 쓰고, 실제 투여 부피(ml)는 원내 앰플 농도로 재계산**하도록 정했습니다(260810 결정).
그러려면 아래 농도 확인이 필요합니다.

| # | 표의 전제 | 원내 재고 | 문제 | 확인 요청 |
|---|-----------|-----------|------|-----------|
| B-1 | Atropine **0.1mg/ml** | `Atropine sulfate 0.5mg/1mL` | 재고 앰플로 표의 ml을 그대로 뽑으면 **5배 과량** | 0.1mg/ml **희석액을 별도 조제**해 쓰는 방식입니까? 아니면 원액 기준으로 ml을 다시 계산해야 합니까? |
| B-2 | Atropine ET **0.4mg/ml** | 동일(0.5mg/ml) | 1.25배 차이 | 위와 동일 |
| B-3 | Epinephrine IV **1:10,000** | `Epinephrine 1mg/1mL`(1:1,000)만 보유 | 1:10,000은 원내 조제 필요 | 현재 앱의 조제법(`Epi 1A(1mg/1mL) + N/S 9mL = 10mL`)이 원내 표준이 맞습니까? |
| B-4 | Sodium Bicarbonate **4.2%** | `NaHCO₃ 8.4% 20mEq/20mL` | mEq는 동일하나 **투여 부피가 절반** | 소아에게 4.2%로 **희석해서** 투여합니까? 8.4% 그대로 투여합니까? |
| B-5 | **Calcium Chloride** 20mg/kg | **Calcium gluconate 10% 2g(9.75mEq)/20mL** (원내 보유 · 칩스 확인) | 염 종류가 다름 | 소아 심정지 칼슘은 **gluconate 기준 몇 mg/kg**로 운영합니까? (현재 앱은 60mg/kg) |

## E. 추가 자료 요청 — 표에 없는 항목

받은 표는 **장비·소생·RSI**만 담고 있습니다. 앱 구현에 아래가 더 필요합니다.

### E-1. ★ 수액 상한 (가장 시급 — 요구사항 ②)

| 필요 항목 | 질문 |
|-----------|------|
| 1회 볼루스 | 상황별 mL/kg, 그리고 **체중이 큰 소아의 1회 절대 상한(mL)** |
| **누적 상한** | 쇼크 유형별 **총 몇 mL/kg 까지** (여기까지 주면 멈추고 승압제로 넘어가는 기준) |
| 유지수액 | 원내 최대 mL/hr, 성인 기준으로 넘어가는 체중 |
| 투여 속도 | 볼루스 1회를 몇 분에 걸쳐 주는지 |
| 수액 종류 | 상황별 N/S · Hartmann · Plasma solution A 중 무엇을 쓰는지 |

### E-2. 소아 지속주입(CIV) 표준 믹스

Epinephrine · Norepinephrine · Dopamine · Dobutamine · Midazolam · Amiodarone 등의
**원내 소아 표준 농도(mcg/ml)와 조제법, mcg/kg/min 범위**.

> 참고: 성인 Norepinephrine은 260808에 **20mcg/ml 단일 표준**으로 확정했습니다.
> **소아도 동일한 20mcg/ml를 씁니까, 별도 농도를 씁니까?**

### E-3. 기타

정상 활력징후 · 경련 · 아나필락시스 · 진통/진정/항구토 · 인공호흡기 초기 세팅 · 연령↔체중 대응표 ·
Broselow 색상명(표에는 체중 구간만 있고 색상명이 없습니다).
