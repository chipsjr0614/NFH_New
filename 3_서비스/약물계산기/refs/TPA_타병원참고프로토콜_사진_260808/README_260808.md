## 왜 보관하는가

투약앱 V4의 Actilyse 카드는 이 자료를 옮긴 것이며, 카드 최상단에
**「우리 병원 프로토콜 미제정 — 실제 투약 사용 금지」** 경고가 상시 노출된다.
