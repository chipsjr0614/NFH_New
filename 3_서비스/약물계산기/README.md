# 약물 계산기

> 체중 입력 시 약물 용량을 자동 계산하는 도구. 특히 **소아(PALS)** 는 체중별 용량이 많아 핵심.
> (원래 ER메이트의 한 도구였으나, 내용 분량이 많아 **독립 서비스**로 분리)

**상태:** 🟡 **V4 구현 완료 · 검증 대기** (260808) — 가독성 개편 + 🧮직접계산 탭 + Norepi 20mcg/ml 통일 반영. **칩스 실기기 검토 → 약제부 검증 후** `app/index.html` 승격.
> ⛔ **Actilyse(TPA)는 우리 병원 프로토콜 미제정.** 앱에 들어간 내용은 타 병원 참고자료이며 카드에 사용금지 경고가 붙어 있다. 제정 전까지 배포본 승격 불가.

## 범위
- 체중 기반 용량 계산 (소아 PALS 포함)
- 자주 쓰는 주요 약물 검색·조회 (용량·믹스법·속도·주의사항)
- 항생제 병용 투여 참고
