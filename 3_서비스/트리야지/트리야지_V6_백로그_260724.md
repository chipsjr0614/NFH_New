### 고친 버그

- [x] **🔴 호흡기 격리 오판정** — `respFlag()`가 `ansAny('cough')`(값 존재만 확인)라서 기침 **"없음"을 골라도 참** → 1구역(감염 격리)·마스크 안내가 잘못 떴다. `'없음'` 제외 판정(`ansAnyNot`)으로 수정. 존재하지 않던 `'sput'` 문항 참조도 제거
- [x] **모달 겹침** — 주호소 즉시경고와 혈당 모달이 같은 z-index로 동시에 뜨던 문제(신경학적 이상 등). 경고를 닫은 뒤 혈당 모달이 열리도록 순차화(`pendingBST`)
- [x] **나이 단위** — `"18개월"` 입력 시 기록에 `"18개월세"`로 출력되던 문제 → `ageWord()` 사용
- [x] **영아 판정** — `ageNum('18개월')`이 `18`(세)이 되어 소아 그리드 우선정렬·학대 선별이 틀리던 문제 → 개월·주·일 표기는 0세로
- [x] **텍스트 답변 유실** — 경위·장소 칸에 큰따옴표를 쓰면 옵션 클릭 시 값이 잘리던 문제 → `esc()` 확장(`"` 포함) 후 `buildQ`에 적용
- [x] **승격 해제 안 됨** — `S.forceSevere`가 한 번 켜지면 답을 취소해도 중증 트랙이 안 풀리던 문제 → `recalcForceSevere()`로 매번 전체 재계산
- [x] **학대 체크 유실** — 학대 사정 카드를 닫으면 체크 내용이 전부 삭제되던 문제 → 닫아도 유지
- [x] **온셋 미래 날짜** — 미래 날짜 입력 시 `"-1일 전(수)"`로 출력되던 문제 → 표기 생략
- [x] `buildQ`의 danger 조건 중 **참이 될 수 없던 3번째 항** 제거
- [x] 하단 버전 표기 `⚠️ V4` → `V6` (V5의 표기 오류)

## 2단계 — 기능 추가

- [x] **① 입력 자동 저장·복구** (260724)
  - `localStorage`에 자동 저장(입력 0.7초 후 디바운스 + 화면 이동 + 페이지 이탈 시)
  - **복구는 물어본다** — 시작 화면 상단에 `💾 작성 중이던 내용이 있습니다` 바 + `↩︎ 이어서 작성` / `🗑 새 환자로 시작`.
    자동 복구하지 않는 이유: **다음 환자 입력 위에 이전 환자 내용을 덮어쓰지 않기 위해**
  - 저장 범위: `S` 전체(Set 포함) + DOM에만 있던 값(바이탈·알러지 상세·여행력·생일·간호기록 수정본) + 현재 단계
  - `🏠 홈`(초기화) 시 저장본도 함께 삭제
  - ⚠️ **확인 필요:** 앱을 `file://`로 직접 열어 쓰는 방식이라 브라우저에 따라 `localStorage`가 막힐 수 있음 → **실제 쓰는 브라우저에서 새로고침 테스트 1회 필요**
- [x] **② S4(세부질문) 화면 압축** + **③ 주호소별 온셋·NRS 분리** (260724 · 함께 설계)

  **구조 변경:** S4의 전역 `발생 시점` 카드와 전역 `통증 NRS` 카드를 없애고, **주호소마다 접이식 섹션** 하나로 합쳤다.
  ```
  ▾ 복통                          🕐 · NRS 6 · 답 4/9
     🕐 발생 시점 (온셋)   [오늘][어제][2일 전][3일 전] + 날짜·시각
     📊 통증 / 불편 NRS    현재 / 과거 최고 / 통증 위치
     📝 세부 질문          …
  ▸ 외상                          🕐 · NRS 5 · 답 6/13     ← 접힘
  ```
  - **기본은 첫 주호소만 펼침** + 우상단 `모두 펼치기/접기` → 주호소 3개를 골라도 첫 화면 길이가 1개일 때와 같다
  - 헤더 배지로 **접힌 채로도** 발생시점 입력 여부(🕐)·NRS·답변 수(`답 4/9`)가 보인다
  - **발생시점·NRS·통증부위가 주호소별로 분리** — V5는 전역 1세트라 흉통+외상을 같이 고르면 발생시점을 하나만 적을 수 있었다
  - Red Flag 목록도 주호소별로 묶고 행마다 붙던 `·주호소` 꼬리표를 제거(목록이 짧아짐)
  - KTAS 자동계산의 NRS는 **주호소별 NRS 중 최댓값**(`maxNRS()`) 사용
  - NRS 슬라이더·통증부위·시각 입력은 전체 재렌더 없이 갱신 → **드래그·타이핑 중 끊김 없음**
  - 직접입력 주호소에 따옴표가 들어가도 안 깨지도록 `jsq()`로 이스케이프

  **출력 예시 (흉통 + 외상, 발생시점 각각):**
  ```
  상기 41세 여환, 2일 전(수) 19:30경 화장실(자택)에서 미끄러져 넘어짐.
  금일 08:10경부터 흉통, 두부·경추 손상으로 내원함 (식은땀 있음, 출혈 있음(코)).
  흉통 NRS 현재 8점. 허리·머리 통증 NRS 현재 5점.
  ```
  > 통증 문장은 주호소별로 따로 나가며, 부위를 안 적었고 주호소가 여러 개면 주호소명으로 구분한다.
  > `흉통 통증 NRS`처럼 겹치는 경우 `통증`을 자동 생략.

- [x] **⑤ 환자 이름 마스킹 (보안)** (260724 · 칩스 규칙 확정)

  **적용 범위:** 밖으로 나가는 **출력물만** — 간호기록·엑셀 복사.
  앱 화면 입력칸과 **신원 확인 팝업은 전체 이름 그대로** 둔다(팔찌 대조·신원 확인을 해야 하므로).
  `S.pname`(내부 상태)도 전체 이름을 유지하고, 출력 시점에만 `maskName()`을 통과시킨다.

  | 입력 | 기록·엑셀 표기 | 규칙 |
  |------|--------------|------|
  | 김철 | 김**O** | 2글자 → 앞 1 + O |
  | 김철수 | 김**O**수 | 3글자 → 가운데만 |
  | 남궁철수 | 남궁**OO** | 4글자 → 앞 2 + OO |
  | 황보철수영 | 황보**OOO** | 5글자 이상 → 앞 2 + O, **최대 5글자** |
  | 서문철수영희 | 서문**OOO** | 6글자도 5글자에서 멈춤(길이 노출 방지) |
  | Rosemary | Ros**OO** | 영문 → 앞 3 + OO |

  **문의 없이 정한 경계 케이스** (필요하면 바꿉니다):
  - **1글자 이름**(`박`) → 그대로. 가릴 글자가 없어 마스킹이 무의미
  - **3글자 이하 영문**(`Lee`) → `LOO`. 앞 3글자 규칙을 그대로 쓰면 이름 전체가 노출되므로 앞 1글자만
  - **이름 속 공백**(`김 철 수`, `Kim Soo Hyun`) → 공백을 지우고 계산 (`김O수`, `KimOO`)

  이름 입력칸 아래에 `🔒 기록·엑셀 표기: 김O수` 미리보기를 띄워, 기록에 무엇이 찍힐지 입력하면서 바로 보이게 했다.

  - [x] **복구 바 이름도 마스킹** (260724 · 칩스 요청) — `💾 작성 중이던 내용이 있습니다 · 김O○ (12345678) · 복통, 발열`.
    신원확인 전 화면에 남는 유일한 지점이라 함께 가림. **등록번호 8자리는 그대로**(어느 환자 기록인지 알아보려면 필요 — 칩스 확정)

- [ ] **🤰 임신 문항 선택지 정리** (260724 칩스 요청 · **저장만, 코드 미변경**)

  현재 V6 코드:
  ```js
  mk('pregOpts',['해당없음','없음','가능성','임신중'],'preg');
  ```
  `없음`·`가능성`이 무엇의 없음/가능성인지 문항을 안 보면 모호하다는 지적.

  | 지금 | 요청 |
  |------|------|
  | 해당없음 | 해당없음 |
  | 없음 | **임신 가능성 없음** |
  | 가능성 | **가능성 있음** |
  | 임신중 | 임신중 |

  **착수 전 확인할 것:**
  1. 문항 제목도 `🤰 임신` → `🤰 임신 가능성`으로 바꿀지 (요청 문장이 "임신 질문은 임신 가능성, 임신 : …"이라 제목 변경인지 라벨 변경인지 불명확)
  2. **기록·엑셀 출력 표기**를 선택지 그대로 쓸지 (`임신 : 임신 가능성 없음`은 다소 장황 — 출력만 `가능성 없음`으로 줄일지)
  3. 위험 표시(🔴 빨강) 대상은 지금 `가능성`·`임신중` 두 개 → 라벨이 바뀌어도 동일하게 유지
  4. 기존 저장본(localStorage) 호환 — 예전 값 `'없음'`·`'가능성'`으로 저장된 건이 있으면 복구 시 선택이 풀림. 변환 처리 필요 여부
