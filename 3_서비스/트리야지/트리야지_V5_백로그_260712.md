## 반영 완료 (260721 · 외상 현재호소 문장 정리)

칩스 요청 5건 + 실제 사용 중 나온 어색한 출력 3건 수정. 전부 `buildPresentDraft()` 계열.

- [x] **① 발생시점에 요일** — `3일 전` → `3일 전(토)`. 온셋 날짜에서 자동 계산(`onsetDayTxt()`). **금일은 요일 생략**(오늘이라 불필요)
- [x] **② yn 문진에 "있음" 명시** — `출혈` → `출혈 있음`. **전 주호소 공통 적용**(칩스 확정). 외상은 출혈 부위를 괄호로 합침 → `출혈 있음(코)`
- [x] **③ 발생장소·경위를 현재호소 본문에** — 기존엔 `type:'text'`라 통째로 버려졌음. 괄호가 아니라 문장 본문으로 들어감
- [x] **④ 발생장소 안내문구** — `예) 지하철 계단(강남역 3번출구) / 집 화장실(자택) — 정확한 지역은 괄호로`
- [x] **⑤ NRS에 "통증" 표현** — `손목 NRS 5점` → `손목 통증 NRS 현재 5점`
- [x] **⑥ 기전 중복 제거** — 경위를 직접 쓰면 기전 자동문구(`미끄러져 넘어짐`) 생략. 낙상 정보는 버리지 않고 괄호로 요약(`낙상 주저앉음·미끄러짐`). 경위를 안 쓰면 자동문구 유지
- [x] **⑦ `높이 주저앉음` 라벨 오류** — `주저앉음`은 높이가 아님. lblPre `높이` → `낙상` (외상·소아 외상 both)
- [x] **⑧ NRS를 괄호 밖 별도 문장으로** — 부위에 쉼표(`허리, 머리`)를 쓰면 괄호 항목 구분자와 섞여 "허리"가 독립 소견처럼 읽혔음. 부위 쉼표는 `·`로 자동 변환
- [x] 경위 칸 안내문구 → `장소는 위 칸에 적었으니, 여기엔 무엇을 하다 어떻게 다쳤는지만` (장소 이중 기입 방지)

### 출력 예시 (반영 후)

```
상기 41세 여환, 2일 전(일) 화장실(자택)에서 집에서 노래부르다 넘어져서 머리를 부딪힘.
두부·경추 손상으로 내원함 (낙상 주저앉음·미끄러짐, 출혈 있음(코)). 허리·머리 통증 NRS 현재 5점.
```

```
상기 34세 여환, 금일 08:10경 회사 앞 횡단보도(○○동 사거리)에서
교통사고(보행자·고속(40km/h↑)) 발생. 하지·골반 손상으로 내원함 (의식소실 있음).
좌측 하지 통증 NRS 현재 8점.
```

### 참고 (다음 작업자용)

- 현재호소를 실제로 만드는 함수는 **`buildPresentDraft()` 하나뿐.**
  `traumaPresent()`·`buildNarrative()`는 **호출되지 않는 죽은 코드** — 260721 작업 때 외상 문장 로직만 `traumaLead()`로 되살려 씀. 정리 여부는 칩스 판단 대기.
- 세부질문 답 키는 `ansKey(cc,id)` = `주호소 + U+001F + id`. **구분자가 보이지 않는 제어문자**라 `'외상mech'`처럼 직접 만들면 안 됨.
- 외상 전용 처리는 `CC[cc].narr==='trauma'` 로 분기. 본문으로 빠지는 질문은 `TR_LEAD_IDS`.
