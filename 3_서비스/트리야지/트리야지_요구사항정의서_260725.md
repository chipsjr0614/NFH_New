# 트리야지(KTAS) 앱 요구사항정의서 — V6 최종본

**버전:** v6.0 (구현 완료 2026-07-25)
**대상:** 국립소방병원 응급실 RN
**목적:** 환자 도착 즉시 → 5단계 입력 → KTAS 판정 보조 + 한국어 간호기록/인계 자동 생성 → 복사(엑셀·네이버웍스·간호인계·간호기록)
**배포본:** `app/index.html` (= `KTAS_desktop_V6.html`, 260725 승격)
**환경:** 병원 내부망(인터넷 차단) · 자체완결 단일 HTML · 태블릿 기준 + 핸드폰/PC 반응형

---

## 0. 원칙

- 인터넷/외부 API 호출 없음. 모든 데이터·질문은 빌드 시점에 인라인.
- 임상 사실(용량·금기·검사·수치 기준)은 **추측 금지** — 불확실하면 "확인 필요"·🔶칩스 검증 표시.
- 환자 이름은 **출력물에서 마스킹**(화면 입력·신원확인 팝업은 전체 이름 유지).

## 1. 전체 흐름 (5단계)

| 단계 | 화면 | 핵심 |
|------|------|------|
| S1 | 기본·위험판정 | 기본정보·환자정보·과거력/수술력·소아평가·안전배경·내원경로·첫인상/ABCD·위험배너 |
| S2 | 주호소 선택 | 검색 + 그리드 + 계통별 전체 + 직접입력 (중복 선택) |
| S3 | V/S 측정 | 혈압측정금지팔·6종 활력징후·산소(O2)·**소아 정상 V/S 참고 표시** |
| S4 | 세부질문·Red Flag·KTAS | 주호소별 발생시점(onset)·통증 NRS·세부질문·Red Flag·KTAS 자동추정·현재호소 |
| S5 | 기록 완성 | 특이사항·학대 스크리닝·**KTAS 확정**·간호기록 자동생성·복사·최종확인 |

- 상단: 🏠홈(초기화)·진행바(1/5~5/5)·☀️/🌙 테마 토글.
- **자동 저장·복구**: localStorage 자동 저장(입력 0.7s 디바운스 + 화면 이동 + 이탈 시). 복구는 시작화면 상단 바에서 "이어서 작성 / 새 환자로 시작"을 **물어봄**(다음 환자에 덮어쓰기 방지). 복구 바 이름도 마스킹.

## 2. S1 — 기본·위험판정

### 2.1 기본정보
- 내원 일시(날짜 자동), **내원시간·접수시간**(🕐지금 / 직접입력, `--:--` 자동 포맷).

### 2.2 환자 정보
- 환자번호(8자리 숫자), 이름(전체 입력, 기록엔 마스킹 미리보기 `🔒 김O수`), 성별, 나이.
- 나이: 직접 입력(예 45 / 7세 / 18개월 / 72) 또는 **생일 6자리(YYMMDD) → 만나이 자동**.
- 소아(만 15세 미만)·노인(≥65) 자동 인식. 개월·주·일 표기는 0세로 처리.

### 2.3 과거력(#)·수술력(s/p)
- 진단명 + 진단시기(선택) 태그 추가. 수술명 + 수술시기(선택).

### 2.4 소아 평가 (소아 자동 표시)
- 키(cm)·**체중(kg, ⚠️ 필수)**·체온(℃, **숫자 3자리 자동 소수점 33.3**).
  - **소아면 체중 미입력 시 S1 진행 차단**(약물용량·수액 기준이므로).
- PAT(외관·호흡노력·순환) 정상/이상, 소아 위험신호(3개월미만 발열·열성경련·탈수·처짐/수유거부).

### 2.5 안전 · 배경 정보 (**모두 선택해야 S1 통과**)
미선택 항목이 하나라도 있으면 진행 차단(alert로 미선택 항목 표시). *해당 없으면 "없음" 선택.*
- 🤰 임신(여성만 필수) · 🩸 LMP(여성) · 💉 조영제 부작용 · 💊 약물 알러지 · 🌾 각종 알러지 · 💊 복용약물 · 🚬 흡연 · ✈️ 여행력(장소·기간).
- 🦠 **감염/격리**: `없음`(배타) / 호흡기 격리 / 접촉 격리 / 역격리 (복수). 유형 선택 시 이유·균주 입력.
- 🏥 **이전 병원 입원력 (최근 1년 이내)**:
  - `[없음][있음]`. **있음** 선택 시 → 최근 입원 날짜·입원 병원 + `🫁 호흡기 격리 확진 [있음][없음]`·`🧤 접촉 격리 확진 [있음][없음]` → 확진이면 확진 시기/기간.
  - 격리 확진 **이력은 기간 무관**(특히 CRE 등 다제내성균). 🔶 기간 기준은 원내 감염관리 지침 우선.
  - 현재는 **기록만** — 이 이력 근거 격리 자동안내(isoMessages)는 미적용(🔶).

### 2.6 내원 경로
- 🚶도보·🚗자가용·♿휠체어·🏥**전원(타병원 구급차)**·🚐사설구급차(129)·🚑119 구급대·🚁헬기. (119·헬기 강조)
- 미선택 시 S1 진행 차단.

### 2.7 첫인상(Across the room) + ABCD
- 첫인상(색·발한·호흡·의식)·ABCD 각 정상/이상. "모두 정상" 버튼.
- 이상 항목 선택 시 **위험배너 자동 평가**(안정~즉시소생). 즉시소생이면 "바로 기록으로" 점프.

## 3. S2 — 주호소 선택

- 🔍 검색 · 아이콘 그리드(자주 쓰는 것 우선, 소아는 소아 주호소 상단) · `＋ 증상 목록(계통별 전체)` · 직접 입력(기타).
- 중복 선택 가능. 계통: 심혈관/전신·호흡기·신경·소화기·비뇨생식·산과/여성·정신·중독·외상·근골격·피부·안과·이비인후/구강·환경·소아·일반/처치.
- 미선택 시 S2 진행 차단.

---

## 4. S3 — V/S 측정

- 🩺 혈압 측정 금지 팔(유방절제·투석혈관 등) → 특이사항에 `$` 주의 자동.
- SBP/DBP/HR/RR/**BT(자동 소수점)**/SpO2. 🫁 산소(Room air / 산소흡입 → 장치·L/min).
- **소아 연령별 정상 V/S 참고 표시**(소아 감지 시 화면 상단): 신생아/영아/유아/학령전/학령기/청소년 6구간 HR·RR·SBP.
  - **표시 전용** — 자동 비정상 판정·KTAS 자동 승격 미적용(판단은 RN). 출처 PALS/APLS(재설계 §7.4 채택). 🔶 원자료 최종 대조 권장.

## 5. S4 — 세부질문·Red Flag·KTAS·현재호소

- **주호소별 접이식 섹션**: 각 주호소마다 🕐발생시점(onset: 날짜+시간, "지금" 버튼)·📊통증 NRS(현재/과거최고/부위)·세부질문. 첫 주호소만 펼침 + 모두 펼치기/접기.
- 발생시점·NRS·통증부위가 **주호소별로 분리**(여러 주호소 각각 입력).
- Red Flag(주호소별 + 공통), KTAS 자동추정(모디파이어 배지). NRS는 주호소별 최댓값 사용.
- 📝 현재호소: 클릭 내용 기반 자동 문장 초안 + 직접 수정. 주호소별 온셋이 문장에 반영.

## 6. S5 — 기록 완성

- 특이사항(문제사항은 문장 앞 `$`). 학대 선별 — **V7부터 FIND 하나로 통합**(§11.4). *V6까지는 체크리스트형 '학대 의심 사정' 카드(소아·노인·외상 자동 권고).*
- **KTAS 확정(RN)**: 내원시 / 변경시(접수 후 재평가).
  - 같은 KTAS 버튼 **재클릭 시 선택 해제**(토글). 내원시·변경시 독립.
  - **내원시 KTAS 미입력 시** "기록 생성 → 최종확인"에서 **알람 + 진행 차단**(변경시는 선택).
- 간호기록 자동생성(수정·추가 가능) + 🔄 재생성. 복사 버튼(간호기록/최종확인).

## 7. 최종확인 모달 + 복사 4종

- 모달: 이름·등록번호(8자리)·나이·내원/접수시간·담당교수 + **신원확인·환자교육 체크** 완료 시 복사 버튼 활성.
  1구역(감염 격리) 안내 배너. **모달이 화면보다 길면 내부 스크롤**(버튼까지 도달).
- 값은 **공통 조립(`recordParts`)** — 4종 내용 일치. 위험항목 🔴, 이름 마스킹.
- **불릿은 `•`로 통일**(엑셀에서 `-` 시작 셀이 수식 오인되는 문제 회피). 내원동기·특이사항·배경정보 각 줄 앞 `•`(항목은 ` / `로 묶음).

### 7.1 ✅ 엑셀 복사 (파랑)
- 13칸 TSV: 접수일·내원시간·접수시간·환자번호·이름·성별/나이·내원경로·내원시 KTAS·변경시 KTAS·V/S·내원동기·특이사항·담당교수.
- 내원동기 = 배경(과거력·수술력·격리·입원력·알러지 등) + 내원이유(주호소 + **정확한 onset 날짜·시간**) + 현재호소. 셀 내 여러 줄 유지.

### 7.2 📋 네이버웍스용 복사 (초록)
- 리치(text/html) + 평문 동시 복사. 표 2개(간격 없이 세로로 붙음, 총폭 동일):
  - 표A(11칸): 기본정보 + 담당교수. **V/S 넓게(310px)·내원/변경 KTAS 좁게(40px)**.
  - 표B(2칸): 내원동기(넓게)·특이사항.

### 7.3 📝 간호인계용 Reminder2 복사 (보라)
- 리치 복사. 환자 헤더 자동채움 + 인계 템플릿:
  - `[ER M/D 접수시간]` / `# 이름(성별/나이, 환자번호)` / `# initial V/S` / `# 내원동기`(아래 `•` 항목 **2칸 들여쓰기**) / `# 특이사항`.
  - 인계 템플릿 7항목(파란 큰 글씨): [V/S target]·[full drip]·[Dressing]·[각종 tube·중심 동맥 정맥관]·[잉여 검체 보관]·[미시행 검사]·[기타공유인계사항]. `(Ex:)` 예시·`-` 빈칸·구분선 유지.

### 7.4 📋 간호기록 복사
- `[환자]/[배경정보](•)/[내원동기]/[현재호소]/[V/S]/[특이사항]/[KTAS]` 라벨형 텍스트.

## 7.5 완료 기록 보관 + 자동저장·복구

- **📁 완료 기록 보관함** (상단 `📁`, **PIN 8020**): 엑셀/네이버웍스/Reminder2 **복사(완료) 시 자동 보관**. 초기화해도 유지.
  - `localStorage['NFH_TRIAGE_HISTORY']` · **최대 1,000건**(초과 시 오래된 것부터 순차 삭제 FIFO, 용량 초과 시에도 무음 실패 없이 오래된 것부터 방출).
  - **전체 스냅샷 저장**(불러오기 복원·엑셀 재복사 가능) + 요약(시간·이름·번호·주호소·KTAS). **이름은 마스킹본만** 저장.
  - 같은 환자 세션 재복사는 `S._histId`로 **갱신**(중복 방지). 목록에서 불러오기/엑셀재복사/삭제/전체 내보내기. ⚠️ 공용기기 주의.
- **자동 저장·복구(작성 중 초안)**: 입력 0.7초 디바운스 + 화면 이동/이탈 시 `localStorage['NFH_TRIAGE_V6']`에 1건 저장. 새로고침/재접속 시 상단 바에서 **"이어서 작성 / 새 환자로 시작"** 선택(자동 복구 안 함 — 다음 환자 위 덮어쓰기 방지).
  - ★ **복구 바가 뜬 동안은 자동저장 정지**(`restorePending`) — 빈 화면 자동저장이 초안을 덮어쓰던 버그 수정(260725).

- **임상 수치·문구 전반이 초안 상태로 배포됨**(오너=칩스 요청 승격). 검증 후 문구 확정 필요.

## 11. V7 변경분 (260808 · 구현 완료, 실기 확인 후 승격 예정)

배포본에는 아직 반영되지 않았다. 파일은 `app/KTAS_desktop_V7.html`.

### 11.1 발열 — 내원 전 해열제 (S4 세부질문)

`발열`·`소아 발열` 주호소를 고른 경우에만 표시. `💊 내원 전 해열제 [복용]`을 선택해야 하위 문항이 열린다.

- **💊 내원 전 해열제** `[없음][복용]`
- **약 이름**(아세트아미노펜·이부프로펜·덱시부프로펜·기타·모름, 소아는 소아 제품명 예시) · `기타`면 직접 기재
- **마지막 복용**(30분 이내 / 1시간 / 2~3시간 / 4~6시간 / 6시간 이상 / 모름)
- **용량은 받지 않는다**(260808 칩스) — 보호자가 정확히 모르는 경우가 많아 입력 부담 대비 실익이 낮음. mg/kg 환산·과용량 판정도 해당 없음.

### 11.2 출혈량 정량화 (S4 세부질문)

생활 단위 환산 선택지: `묻어나는 정도 / 숟가락 1~2술(약 15~30mL) / 소주잔 1잔(약 50mL) / 종이컵 반 컵(약 100mL) / 종이컵 1컵(약 200mL) / 종이컵 1컵 이상(200mL 초과, 🔴) / 모름`.
세트 구성 = **양 환산 + 양 직접 기재 + 횟수 + 현재 지혈 상태**.

| 주호소 | 적용 |
|--------|------|
| 출혈 | 기존 `소량·중등도·대량` 교체 |
| 코피 | 신설 + 출혈 지속시간 |
| 구토/오심 | 토혈=있음일 때만 열림 |
| 객혈 | 신설 모듈에 포함 |

- **KTAS 자동판정에는 미반영**(`calcKTAS()` 무변경) — 기록·인계 전달용 정량화까지. 🔶 임상 컷오프는 칩스 확정 필요.

### 11.3 `객혈` 주호소 모듈 신설

169 목록에는 있었으나 세부질문이 없어 서술 문진으로 빠지던 주호소. 객혈량 4종 + 양상·기간·기침·호흡곤란·**결핵 과거력/접촉력**·항응고제. 기침 선택 시 기존 로직에 따라 **1구역(감염 격리)·마스크 안내 자동 표시**.
🔶 track(severe)·Red Flag는 출혈 모듈 준용 초안 — 칩스 확정 필요.

### 11.4 학대 선별 (S5) — FIND 하나로 통합

의료기관 평가용 도구. **관찰 7 + 확인질문 3**, 문항은 칩스가 전달한 원문 그대로.
**V6까지 있던 체크리스트형 '학대 의심 사정' 카드는 삭제**했다(도구가 둘이면 헷갈림 — 260808 칩스).

- **관찰 7**(묻지 않고 확인): 멍·상처·화상 / 여러 부위 손상 / 비정상적인 부위의 멍(등·엉덩이·귀·목·안쪽 허벅지) / 특이한 손상 형태(손가락·물체·벨트 모양) / 손상 단계가 서로 다름 / 아동(환자)의 행동 / 보호자의 행동 → 각 `[없음][있음]`
- **확인질문 3**(직접 물음): 어떻게 다쳤나요? / 언제, 어디서 다쳤나요? / 그때 누가 함께 있었나요? → 서술 입력 + `해당없음` 버튼

| 나이 | 제목 | 표시 | 필수 |
|------|------|------|------|
| 만 12세 이하 | 🔍 아동학대 선별 (FIND) | 자동 | **O** — 10문항 미응답 시 최종확인 차단 |
| 13~69세 | 🔍 학대 의심 선별 (FIND) | 자동 | X (권고) |
| 만 70세 이상 | 🔍 학대 의심 선별 (FIND) | 자동 | **O** |
| 나이 미입력 | — | 수동 버튼 | X |

- 기존 소아(<15)·노인(≥65) 기준과 별개 판정. 관찰 6번 라벨은 13세 이상이면 `환자의 행동`으로 전환.
- **음성(해당 없음)도 특이사항에 기록** — 시행 증거. 양성이면 `$`·🔴 + S5 주의 박스. 권고 대상이 하다 만 것은 기록 안 함.
- S1 첫 화면 배지는 **필수 대상만** 노출.
- 🔶 **양성 판정 기준(몇 개 이상)·신고 조치 절차·시행자 기록 여부는 칩스 확정 필요.** 앱은 개수·항목명 표기만 하고 자동 판정·KTAS 승격을 하지 않는다.

### 11.5 문진 엔진 속성 3개 추가

- `inNote` — 자유 입력(text) 문항을 **기록 문장에 포함**시킨다. V6까지 text는 전부 문장에서 빠졌다(해열제 용량이 기록에 안 남던 원인). 이 플래그를 단 문항만 포함되므로 **기존 문항 동작은 그대로**.
- `mutedBy` — 더 구체적인 답이 있으면 덜 구체적인 문항을 문장에서 생략.
- `cols:1` — 선택지 세로 1열 렌더. V6까지 데이터에 선언만 되고 미구현이던 속성(라벨 긴 출혈량 칩에 필요). 부수 효과로 `출혈-부위`·`정신과-주요 문제`도 세로 배치.
