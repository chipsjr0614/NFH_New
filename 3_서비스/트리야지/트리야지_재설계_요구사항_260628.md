## 1. 왜 갈아엎는가 (재설계 배경)

V3(현행)의 구조적 문제 4가지. 모두 코드에서 확인됨.

| # | 문제 | V3 코드 근거 | 영향 |
|---|------|-------------|------|
| 1 | **모든 환자가 10단계 전수 통과** | `showScreen` 1→10 고정 | 경증도 중증도 같은 길이 → 느림 |
| 2 | **소아 외상 경보 없음** | 주호소에 `소아 발열`만 존재, `CC_ALERTS` 4종뿐 | 소아 외상 미감지 |
| 3 | **소아 입력값이 KTAS에 미반영** | `calcMod()`에 PAT·소아 위험신호 가중치 0 | 소아 중증도 자동판정 X |
| 4 | **학대 스크리닝 전무** | 코드에 아동·노인 학대 항목 없음 | 학대 의심 누락 |
| 5 | **간호기록 문장 9개 주호소만 완성** | `buildNote()` if-분기 9개 | 나머지 20개 주호소 빈약 |

### 재설계 목표 (우선순위順)
1. **속도** — 위험도에 따라 화면 수가 달라지는 **분기형**. 경증은 4화면(공격적 단축).
2. **놓침 방지** — 위급/소아 외상/학대를 **자동 경보**.
3. **클릭→간호기록** — 전 주호소에서 클릭만으로 정형 내원동기 문장 생성.

## 4. 분기 로직 (자동 중증/경증 판정)

**① 위험판정**과 **② 주호소 선택** 결과로 트랙을 자동 결정한다. RN은 언제든 수동으로 트랙 전환 가능.

| 판정 | 조건(하나라도 해당) | 트랙 | 동선 |
|------|--------------------|------|------|
| 🔴 위급 | ABCD 이상 1개+ / 첫인상 bad / 초응급 주호소(흉통·호흡곤란·신경학적·중독 등) | 위급 | ①→⑥ 즉시 점프, KTAS 1·2 경보 |
| 🟠 중증 | Red Flag 가능 주호소 / 첫인상 warn / V/S 이상 | 중증 | ③Red Flag→④세부→⑤Modifier→⑥ |
| 🟢 경증 | 위 어디에도 안 걸림 | 경증 | ③V/S+핵심질문→⑥ |

트랙은 **2단계**로 결정한다: ⑴ 하드 트리거(주호소 무관, 무조건 위급) 검사 → ⑵ 통과 시 주호소 기본 트랙 적용. 경증이라도 Red Flag 하나라도 체크되면 중증 승격.

### 4.A 하드 트리거 (주호소 무관 → 자동 🔴위급) — 🔶칩스검증(수치)

| 트리거 | 기준(초안) |
|---|---|
| ABCD 이상 | A·B·C·D 중 1개라도 이상 |
| 첫인상 bad | 청색증·식은땀·반응저하·움직임없음·들것 |
| SpO2 | < 90% |
| SBP | < 90 mmHg (쇼크) 또는 ≥ 180 + 증상 동반 (고혈압 위기) |
| HR | < 50 (서맥) 또는 ≥ 130 (심한 빈맥) |
| RR | < 10 (서호흡) 또는 ≥ 30 (심한 빈호흡) |
| BT | < 35°C (저체온) ※ 고열은 4.C 승격 |
| 의식 | 혈당저하 동반 의식저하 |

> ※ 위 수치는 성인 기준. **소아는 연령별 정상치가 달라 적용 불가** → 별도(§7.3, 🔶칩스검증).

### 4.B 주호소별 기본 트랙 — ✅확정 (2026-06-28, 칩스)

> 어지럼증은 뇌졸중 감별 위해 🟠중증으로 확정 이동.

| 🔴 위급 (즉시경고+깊게) | 🟠 중증 (Red Flag 화면 필수) | 🟢 경증 (fast-track 허용) |
|---|---|---|
| 흉통 | 복통 | 구토/오심 |
| 호흡곤란 | 두통 | 설사 |
| 실신/의식변화 | 발열 | 코피 |
| 신경학적 이상 | 출혈 | 인후통 |
| 약물/중독 | 알레르기 | 귀 증상 |
| 정신과 응급(자살/자해) | 외상 | 근골격(비외상) |
| 소아 외상(중증 기전) | **어지럼증** | 눈 통증/시력 |
|  | 소아 외상(경증 기전) | 소아 발열(3개월↑·상태양호) |
|  | 산과 | 비뇨기(단순 배뇨통) |
|  | 눈 화학물질/이물 |  |
|  | 비뇨기(고환통·요폐) |  |
|  | 소아 발열(3개월 미만) |  |

### 4.C 경증→중증 자동 승격 조건 — 🔶칩스검증(수치)

🟢경증 트랙에서도 아래 잡히면 자동으로 중증 배너 + Red Flag 화면 복귀:

| 조건 | 기준(초안) |
|---|---|
| 발열 | BT ≥ 39.5°C (38~39.5는 MID) |
| 빈맥 | HR ≥ 120 |
| 빈호흡 | RR ≥ 25 |
| 통증 | NRS ≥ 7 |
| 경계 혈압 | SBP 90~100 또는 ≥ 180 (증상 없음) |
| 고령 | ≥ 65세 + 비특이 증상 → **고령 주의 배너만 표시**(부드럽게 반영, KTAS 강제 안 함) |

> 🔶 **고령 가중**은 우선 "배너만 표시(부드럽게)"로 반영함. 적극 반영(≥65세 자동 중증 승격)을 원하면 변경. 칩스 확정 필요.

## 5. 화면별 상세 요구사항

### ① 빠른 위험판정 (V3의 S1+S2+S3 압축)

| 영역 | 항목 | 비고 |
|------|------|------|
| 기본 | 나이(입력 시 소아 자동감지), 내원경로 7종 | 이름·환자번호는 ⑥ 최종확인 팝업에서(속도) |
| 첫인상(GI) | 얼굴색·발한·호흡·의식·자세·입원방식 6항목 | **"모두정상 ✓" 한방 버튼** 추가 |
| ABCD | A/B/C/D 정상·이상 | **"ABCD 모두정상 ✓" 한방 버튼** 추가, D 이상 시 BST 팝업 유지 |
| 판정 배너 | 🔴/🟠/🟢 실시간 | 🔴이면 "즉시 소생 — 바로 기록" 점프 버튼 노출 |

- 소아(만 15세 미만) 감지 시 소아 카드(체중·체온·키·PAT·보호자) 표시 — V3 유지하되 **PAT를 KTAS에 반영**(§6).

#### 배경·안전 정보 카드 (초기, 선택 입력) — ✅확정 (2026-06-28, 칩스)

V3의 안전정보(임신·조영제·약물알러지·복용약물)에 **흡연·여행력 추가**. 미입력 시 "없음" 출력(V3 규칙 유지).

| 항목 | 입력 | 기록 출력 예 |
|------|------|-------------|
| 임신 | 해당없음/없음/가능성/임신중 + LMP | `임신 가능성 (LMP 2026-05-20)` |
| 조영제 알러지 | 없음/있음⚠️ | `조영제알러지 있음` |
| 약물 알러지 | 텍스트 | `약물알러지 페니실린` |
| 복용약물 | 텍스트 | `복용약물 와파린` |
| **흡연** | 비흡연 / 현재 흡연 / 과거 흡연(금연) [+ 양: 갑년 선택] | `흡연 현재(1갑/일)` |
| **여행력** | 없음 / 있음 → 장소·기간(날짜)·일수 | `여행력 2026-06-10~06-20 동남아(10일)` |

- **스크리닝 연동:** 여행력 "있음" + 발열 → 감염 스크리닝 단서 / 흡연 → 흉통·호흡곤란 위험인자 표시(🔶 KTAS 가중 여부는 칩스검증).
- 출력 위치: 간호기록 **배경정보 줄**(V3 `safetyLines()` 확장) + 엑셀 내원동기 칸.

### ② 주호소 선택

- 주호소 그리드(V3의 29개 계승). **소아 환자면 소아 전용 주호소를 최상단 정렬.**
- 신규 주호소: **`소아 외상`** 추가(§7). 기존 `외상`은 성인/공통.
- 탭 즉시: 초응급 주호소면 경고 팝업(`CC_ALERTS` 확장 — §7).
- 탭과 동시에 §4 분기 판정 실행.

### ③-경증 V/S + 핵심질문 (한 화면)

- V/S 입력(V3 S4 유지).
- 그 주호소의 **핵심 질문 2~3개만** 노출(대개 NRS + 동반증상 1~2). 전체 세부질문 세트(③④⑤)는 생략.
- 핵심 질문 셋(주호소별 무엇이 "핵심"인지)은 🔶칩스검증.

### ③④⑤-중증 (V3 S6·S7·S8 계승)

- ③ Red Flag — 주호소별 동적 목록(V3 `RF` 계승).
- ④ 세부질문 — 주호소별(V3 `QD` 계승, 신규 주호소 보강).
- ⑤ Modifier 자동 → 예상 KTAS(V3 `calcMod` 계승 + 소아/학대 가중치 추가 §6).

### ⑥ 기록 완성 (공통)

| 영역 | 내용 |
|------|------|
| 과거력 | `#진단명` 태그 + `s/p 수술명` 태그 (V3 유지) |
| ⚠️ 학대 스크리닝 | **소아 또는 노인(≥65세) + 외상/화상 계열일 때 자동 노출**(§7) |
| 특이사항 | `$` 마커 (V3 유지). 학대 체크 시 자동으로 `$` 문장 삽입 |
| KTAS 확정 | 내원시 / 변경시 1~5 (RN 최종 결정) |
| 내원동기 | **클릭 누적 → 자동 문장 생성**(§6) — 수정 가능 |
| 출력 | 간호기록 복사 / 항목별 복사 / 전체 1줄 엑셀 복사 / 최종확인 팝업 (V3 유지) |

## 6. ⭐ 클릭 → 내원동기 자동 생성 (핵심 기능)

**"클릭클릭하면 내원동기를 만들어준다"** = 모든 선택이 문장 슬롯을 채우고, 정형 문장으로 조립된다.

### 6.1 문장 구조 (공통 골격)

```
{과거력} 과거력 있는 환자로, {내원사유}을(를) 주소로 {경로} 내원함.
{주호소별 자동 문장}
{기타 동반 증상}
[BST / Red Flag / Modifier / 추가메모]
```

- 과거력 없으면 → "특이 과거력 없는 환자로".
- 슬롯: onset(언제) · location(어디) · quality(양상) · NRS(강도) · 동반증상 · 발생양상.

### 6.2 클릭 → 출력 예시

| 주호소 | 클릭한 것 | 자동 생성 문장 |
|--------|----------|---------------|
| 복통 | 6시간전·RLQ·찌르는·NRS8·발열✓·구토✓·#당뇨·도보 | `#당뇨 과거력 있는 환자로, 복통을 주소로 도보 내원함. 6시간 전부터 RLQ 부위 찌르는 양상의 복통(NRS 8/10) 발생, 발열·구토 동반.` |
| 흉통 | 30분이내·중앙·쥐어짜는·NRS7·왼팔방사·식은땀✓·119 | `특이 과거력 없는 환자로, 흉통을 주소로 119 구급대 내원함. 30분 이내 전부터 중앙 부위 쥐어짜는 양상의 흉통(NRS 7/10) 발생, 방사통(왼팔)·식은땀 동반.` |
| 소아 외상 | 낙상·본인키이상·두부·의식소실✓ | `(소아) 낙상(본인 키 이상 높이)으로 인한 외상. 손상 부위: 두부. 의식 소실 있음.` 🔶칩스검증(소아 외상 문구) |

### 6.3 적용 범위

- **V3에서 문장이 나오는 주호소: 9개** (흉통·복통·두통·발열·신경학적·외상·중독·출혈·산과).
- **v4 요구: 전 주호소(24개+신규 소아외상)에 문장 템플릿 부여.** 초안은 §6.4.
- 출력 문구는 진술문 마스터를 벗어나지 않게 `statement-lint`로 검증.

### 6.4 전 주호소 문장 틀 초안 — 🔶칩스검증(정형 문구)

> **표기:** `{슬롯}` = 클릭값이 채워지는 빈칸 · `[…]` = 해당 입력 있을 때만 출력(선택).
> 슬롯은 각 주호소 세부질문(클릭형)과 1:1 대응. **아래 문구는 초안이며, 정형 진술문 마스터(예: "토했음"❌→"오심 구토 있음"✅) 대조 후 칩스 확정.**

#### 초응급
**1. 흉통**
틀: `{onset} 전부터 {loc} 부위 {qual} 양상의 흉통(NRS {nrs}/10) 발생[, {rad} 방사통]·[식은땀]·[호흡곤란]·[심계항진] 동반.[ 심장 과거력 {pmhx_c}.]`
예: `30분 이내 전부터 중앙(substernal) 부위 쥐어짜는 양상의 흉통(NRS 7/10) 발생, 왼팔 방사통·식은땀 동반.`

**2. 호흡곤란**
틀: `{onset} 발생한 호흡곤란[, {pos}][, {cough}/{sput} 가래][, 발열 동반].[ 심장질환/천식·COPD 과거력 있음.]`
예: `안정 시 갑자기 발생한 호흡곤란, 누우면 악화, 습성 기침(노란 가래) 동반.`

**3. 실신/의식변화**
틀: `[{pro} 전구증상 후 ]의식 소실({dur}) 발생[, 경련][, 외상][, 실금] 동반[, 목격자 {wit}].`
예: `두근거림 전구증상 후 의식 소실(수분) 발생, 외상 동반, 목격자 있음.`

#### 신경
**4. 두통**
틀: `{onset_t} 발생한 {loc} 두통({onset} 전부터, NRS {nrs}/10)[, 구역·구토][, 광과민][, 음과민] 동반.[ 두통 과거력 {pmhx_h}.]`
예: `갑자기(벼락두통) 발생한 후두부 두통(1시간 이내 전부터, NRS 9/10), 구역·구토 동반.`

**5. 어지럼증**
틀: `{trig} 발생하는 {type} 어지럼[, 이명][, 난청][, 오심·구토] 동반.`
예: `자세 변화 시 발생하는 빙글빙글(vertigo) 어지럼, 이명·오심 동반.`

**6. 신경학적 이상**
틀: `신경학적 이상 증상으로 내원. Last Known Well {lkw}, 증상발견 {disc}. {onset} 발생한 {side} 증상[, FAST: {안면마비·편측위약감·언어장애}][, 시야장애][, 보행장애](두통 NRS {nrs}/10).`
예: `신경학적 이상 증상으로 내원. Last Known Well 14:30, 증상발견 16:00. 갑자기 발생한 우측 증상, FAST: 안면마비·편측위약감·언어장애.`

#### 소화기
**7. 복통**
틀: `{onset} 전부터 {loc} 부위 {qual} 양상의 복통(NRS {nrs}/10)[, 발열][, 구토][, 설사] 동반.[ 임신 가능성 {preg}.]`
예: `6시간 전부터 RLQ 부위 찌르는 양상의 복통(NRS 8/10), 발열·구토 동반.`

**8. 구토/오심**
틀: `{onset} 전부터 오심 구토({cnt})[, 토혈][, 복통][, 발열] 동반.`
예: `오늘부터 오심 구토(3~5회), 복통 동반.`

**9. 설사**
틀: `{onset}부터 설사({cnt})[, 혈변][, 발열][, 복통] 동반.`
예: `2~3일부터 설사(4~6회), 발열 동반.`

#### 출혈·감염·전신
**10. 출혈**
틀: `{site} 확인, 출혈량 {amt} 추정({dur})[, 항응고제 복용 중].`
예: `위장관(토혈/혈변) 확인, 출혈량 중등도 추정(현재 진행 중), 항응고제 복용 중.`

**11. 발열**
틀: `체온 {bt_v}℃ 확인, {dur} 발열 지속[, 오한][, 발진][, 호흡기 증상][, 요로 증상] 동반[, {travel} 여행력].`
예: `체온 38.5℃ 확인, 1~3일 발열 지속, 오한·호흡기 증상 동반.`

**12. 알레르기**
틀: `{cause} 추정 알레르기 반응, {sym}[, 알레르기 과거력 있음].`
예: `음식 추정 알레르기 반응, 두드러기·호흡곤란 동반.`

#### 외상·정신·중독
**13. 외상(성인/공통)**
틀: `{mech}으로 인한 외상[, 낙상 높이 {height}], 손상 부위 {area}[, 의식 소실 동반].`
예: `낙상으로 인한 외상, 낙상 높이 본인 키 이상, 손상 부위 두부·상지, 의식 소실 동반.`

**14. 정신과 응급**
틀: `{type}(으)로 내원[, 자해 도구 소지][, 정신과 과거력][, 정신과 약물 복용 중][, 주변 안전 확인 완료].`
예: `자살시도로 내원, 자해 도구 소지, 정신과 약물 복용 중.`

**15. 약물/중독**
틀: `{subst} {amt} {intent} 노출({time})[, 구토 유발함].`
예: `처방약 과다복용 대량/불명 자살시도 노출(13:00).`

#### 소아
**16. 소아 발열**
틀: `(소아, {age}) 체온 {bt_v}℃[, 해열제 {anti}][, 경련 동반], 활동 {act}, 수유/섭취 {feed}[, 발진 동반].`
예: `(소아, 6개월~5세) 체온 39.2℃, 해열제 복용-효과 없음, 활동 처짐 심함, 수유/섭취 감소.`

**17. 소아 외상(신규)**
틀: `(소아) {mech}으로 인한 외상[, 낙상 높이 {height}], 손상 부위 {area}[, 의식 소실 {loc_yn}][, 구토 {vomit}][, 외상 후 경련][, 행동 {behavior}].`
예: `(소아) 고에너지 낙상으로 인한 외상, 손상 부위 두부, 의식 소실 있음, 구토 반복(2회 이상).`

#### 산과·안과
**18. 산과**
틀: `임신 관련 증상으로 내원. [LMP {lmp}, ][임신 {ga}, ][산과력 {gp}][, 질출혈 {bleed}][, 진통 간격 {ctx}][, 태동 {fm}].`
예: `임신 관련 증상으로 내원. 임신 32주, 산과력 G3P2, 질출혈 중등도, 진통 간격 5분.`

**19. 눈 통증/시력**
틀: `{side} 눈 {pain} 증상({onset} 발생)[, 콘택트렌즈 착용].`
예: `우측 눈 심한 통증+구토 동반 증상(14:00 발생), 콘택트렌즈 착용.`

**20. 눈 화학물질/이물**
틀: `{subst} 눈 노출({time}), 세척 {irr}.`
예: `알칼리 눈 노출(13:30), 세척 시행함.`

#### 이비인후
**21. 코피**
틀: `{side} 코피({dur} 지속)[, 외상 동반][, 항응고제 복용 중].`
예: `양측 코피(30분째 지속), 항응고제 복용 중.`

**22. 인후통**
틀: `인후통[, 발열 동반], 삼킴 {swallow}[, 음성 변화][, 이물감] 동반.`
예: `인후통, 발열 동반, 삼킴 침도 못 삼킴, 음성 변화 동반.`

**23. 귀 증상**
틀: `{side} 귀 증상, 청력 {hear}[, 이루(분비물)][, 외상·이물] 동반.`
예: `좌측 귀 증상, 청력 갑작스런 난청, 이루 동반.`

#### 비뇨기·근골격
**24. 비뇨기**
틀: `{loc} 통증, 배뇨 {void}[, 발열 동반][, 결석 과거력 있음].`
예: `옆구리 통증, 배뇨 혈뇨, 발열 동반, 결석 과거력 있음.`

**25. 근골격**
틀: `{onset} {dur} 요통/관절통[, 하지 방사통 동반], 배뇨 {void}.`
예: `외상 있음 3일째 요통/관절통, 하지 방사통 동반, 배뇨 정상.`

#### 공통 머리말 (모든 주호소 앞에 자동 부착)
틀: `{과거력 있으면 "#OO 과거력 있는 환자로" / 없으면 "특이 과거력 없는 환자로"}, {내원사유}을(를) 주소로 {경로} 내원함.`
→ 그 뒤에 위 주호소별 문장이 이어진다.

## 7. 🆕 신규 기능 (V3에 없던 것) — 🔶칩스검증 집중 구역

> 아래 임상 내용은 **AI 1차 초안**이다. 항목·기준·KTAS 급수 전부 칩스 확정 필요. 빈칸은 지어내지 않음.

### 7.1 소아 외상 주호소 (신규) — ✅구조 확정 (2026-06-28, 칩스)

> 근거: 소아 평가 삼각형(PAT) + 소아 두부외상 PECARN. 정확한 수치·급수는 🔶칩스검증.

#### 세부질문 (클릭형)

| 질문 | 선택지 |
|------|--------|
| 손상 기전 | 낙상 / 교통사고 / 끼임·눌림 / 타박 / 자상·관통 / 기타 |
| 낙상 높이 | 해당없음 / 낮음 / **고에너지** (아래 기준) |
| 손상 부위(복수) | 두부·안면·경부·흉부·복부·골반·척추·상지·하지 |
| 의식 소실 | 있음 / 없음 / 모름 |
| 구토 | 없음 / 1회 / 반복(2회 이상) |
| 외상 후 경련 | 있음 / 없음 |
| 행동 변화 | 평소와 같음 / 보챔 심함 / 처짐·반응저하 |

**낙상 높이 — 연령 구분(PECARN) ✅확정:** 🔶수치 확인 권장
- 영아(만 2세 미만): **0.9 m 이상** → 고에너지
- 소아(만 2세 이상): **1.5 m 이상** → 고에너지

#### 위험징후 (Red Flag) — 간소화 ✅확정

쉬운 말로만 표시(탭 도움말 없음).
- 의식 변화 / 반응 저하
- 반복 구토 (2회 이상)
- 외상 후 경련
- 고에너지 손상 (차에 치임·높은 곳 낙상)
- 비정상 행동 (보호자가 "평소와 다르다")
- 두피 혈종 (특히 영아)
- 두개골 골절 의심 (함몰·영아 천문 팽대)
- 다발성 외상

#### 즉시경고 팝업

- 소아 두부외상 의심 → "신경학적 관찰·CT 고려, 보호자 곁에"
- 학대 의심 동반 시 → §7.2 학대 카드 자동 노출

#### KTAS 반영 — 🔶칩스검증(급수·가중치)

| 조건 | 가중(초안) |
|------|-----------|
| PAT 이상 (외관·호흡·순환 중 1개+) | _(수치 미정)_ |
| 위험징후 1개+ | 중증 이상 _(급수 미정)_ |

### 7.2 학대 의심 스크리닝 (신규) — ✅확정 (2026-06-28, 칩스)

**노출 조건:** 환자가 소아(만 15세 미만) 또는 노인(≥65세) **이면서** 외상·화상·반복내원 계열일 때 ⑥ 화면에 자동 카드.

**표시 방식:** 각 항목은 **간단한 항목명**으로 보이고, **탭하면 전문기준 도움말**(근거)이 펼쳐진다.

#### 공통 (소아·노인 모두)

| # | 항목명 | 도움말(탭 시) |
|---|--------|--------------|
| 1 | 손상-기전 불일치 | 다친 경위와 실제 부상이 안 맞음 |
| 2 | 지연 내원 | 다친 뒤 한참 지나 데려옴 |
| 3 | 진술 번복·불일치 | 말이 바뀌거나 보호자·환자 진술이 다름 |
| 4 | 반복 내원 | 같은/유사 손상으로 반복 내원 이력 |
| 5 | 보호자 통제적 | 환자와 단둘이 못 있게 하거나 통제적 |

#### 아동 추가 (만 15세 미만) — 근거: TEN-4-FACES

| # | 항목명 | 도움말(탭 시) |
|---|--------|--------------|
| 1 | 발달단계 불일치 | 발달상 불가능한 손상 (예: 못 걷는 영아의 골절) |
| 2 | 의심 부위 멍 | 몸통·귀·목 멍, 또는 4개월 미만 영아의 멍 (TEN-4) |
| 3 | 얼굴 손상 | 볼·눈꺼풀·결막·귓바퀴·설소대 손상 (FACES) |
| 4 | 양상 있는 손상 | 담배·담금·물림·도구 자국 등 패턴 화상/멍 |
| 5 | 시기 다른 손상 | 회복단계가 서로 다른 손상이 섞임 |

#### 노인 추가 (≥65세)

### 7.4 소아 연령별 정상 V/S & 발열 기준 — ✅채택 (2026-06-28, 칩스)

> **출처: PALS/APLS 표준 소아 정상 활력징후.** 이번 버전은 **표만 화면에 참고 표시**(입력칸 옆), **자동 비정상 판정·자동 승격은 추후 버전으로 보류**(칩스 결정). 실제 KTAS 소아 보정은 자동화 시점에 §7.3과 함께 확정.
> ⚠️ 수치는 PALS/APLS 원자료와 최종 1회 대조 권장(자료마다 구간 미세차).

#### 연령별 정상 V/S (참고용)

| 연령 | HR (회/분) | RR (회/분) | 수축기혈압 SBP (mmHg) |
|------|-----------|-----------|----------------------|
| 신생아 (0~1개월) | 100~205 | 30~60 | 60 이상 |
| 영아 (1~12개월) | 100~180 | 30~53 | 70 이상 |
| 유아 (1~2세) | 98~140 | 22~37 | 72 이상 |
| 학령전 (3~5세) | 80~120 | 20~28 | 74 이상 |
| 학령기 (6~11세) | 75~118 | 18~25 | 80 이상 |
| 청소년 (12~15세) | 60~100 | 12~20 | 90 이상 |

#### 소아 발열 기준 (초안)

| 항목 | 기준 | 검증 |
|------|------|------|
| 발열 | ≥ 38.0°C | 🔶칩스검증 |
| 고열 | ≥ 39.0°C | 🔶칩스검증 |
| 3개월 미만 발열 | ≥ 38.0°C → 무조건 위급/중증 (소아 위험신호) | 🔶칩스검증 |

#### 적용 방식 (이번 버전)
- 소아(만 15세 미만) 감지 시 V/S 입력칸 옆에 **해당 연령 정상범위 참고 표시**.
- **자동 비정상 판정·자동 승격은 미적용**(추후 확장). 판단은 RN 몫.
