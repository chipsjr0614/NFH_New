# 트리야지(KTAS) 앱 재설계 요구사항

**버전:** v4.0 (재설계 설계안)
**작성일:** 2026-06-28
**대상:** 국립소방병원 응급실 RN
**현행 구현:** `app/KTAS_desktop_V3.html` (10단계 전수 통과형) — 본 문서로 갈아엎는다
**관련 문서:** [`트리야지_요구사항정의서.md`](트리야지_요구사항정의서.md)(V3 현행), [`README.md`](README.md)

> ⚠️ **임상 사실 미확정 표시 규칙**
> 이 문서에서 **`🔶칩스검증`** 으로 표시된 항목은 임상 판단이 필요한 부분으로, AI가 임의로 채우지 않았다(또는 1차 초안일 뿐이다). 현장 적용 전 칩스(수간호사) 확정 필수. — CLAUDE.md 0번 절대규칙.

## 1. 왜 갈아엎는가 (재설계 배경)

V3(현행)의 구조적 문제 4가지. 모두 코드에서 확인됨.

| # | 문제 | V3 코드 근거 | 영향 |
|---|------|-------------|------|
| 1 | **모든 환자가 10단계 전수 통과** | `showScreen` 1→10 고정 | 경증도 중증도 같은 길이 → 느림 |
| 2 | **소아 외상 경보 없음** | 주호소에 `소아 발열`만 존재, `CC_ALERTS` 4종뿐 | 소아 외상 미감지 |
| 3 | **소아 입력값이 KTAS에 미반영** | `calcMod()`에 PAT·소아 위험신호 가중치 0 | 소아 중증도 자동판정 X |
| 4 | **학대 스크리닝 전무** | 코드에 아동·노인 학대 항목 없음 | 학대 의심 누락 |
| 5 | **간호기록 문장 9개 주호소만 완성** | `buildNote()` if-분기 9개 | 나머지 20개 주호소 빈약 |

### 재설계 목표 (우선순위順)
1. **속도** — 위험도에 따라 화면 수가 달라지는 **분기형**. 경증은 4화면(공격적 단축).
2. **놓침 방지** — 위급/소아 외상/학대를 **자동 경보**.
3. **클릭→간호기록** — 전 주호소에서 클릭만으로 정형 내원동기 문장 생성.

## 2. 핵심 설계 원칙

|------|------|

## 4. 분기 로직 (자동 중증/경증 판정)

**① 위험판정**과 **② 주호소 선택** 결과로 트랙을 자동 결정한다. RN은 언제든 수동으로 트랙 전환 가능.

| 판정 | 조건(하나라도 해당) | 트랙 | 동선 |
|------|--------------------|------|------|
| 🔴 위급 | ABCD 이상 1개+ / 첫인상 bad / 초응급 주호소(흉통·호흡곤란·신경학적·중독 등) | 위급 | ①→⑥ 즉시 점프, KTAS 1·2 경보 |
| 🟠 중증 | Red Flag 가능 주호소 / 첫인상 warn / V/S 이상 | 중증 | ③Red Flag→④세부→⑤Modifier→⑥ |
| 🟢 경증 | 위 어디에도 안 걸림 | 경증 | ③V/S+핵심질문→⑥ |

트랙은 **2단계**로 결정한다: ⑴ 하드 트리거(주호소 무관, 무조건 위급) 검사 → ⑵ 통과 시 주호소 기본 트랙 적용. 경증이라도 Red Flag 하나라도 체크되면 중증 승격.

### 4.A 하드 트리거 (주호소 무관 → 자동 🔴위급) — 🔶칩스검증(수치)

| 트리거 | 기준(초안) |
|---|---|
| ABCD 이상 | A·B·C·D 중 1개라도 이상 |
| 첫인상 bad | 청색증·식은땀·반응저하·움직임없음·들것 |
| SpO2 | < 90% |
| SBP | < 90 mmHg |
| 의식 | 혈당저하 동반 의식저하 |

### 4.B 주호소별 기본 트랙 — ✅확정 (2026-06-28, 칩스)

> 어지럼증은 뇌졸중 감별 위해 🟠중증으로 확정 이동.

| 🔴 위급 (즉시경고+깊게) | 🟠 중증 (Red Flag 화면 필수) | 🟢 경증 (fast-track 허용) |
|---|---|---|
| 흉통 | 복통 | 구토/오심 |
| 호흡곤란 | 두통 | 설사 |
| 실신/의식변화 | 발열 | 코피 |
| 신경학적 이상 | 출혈 | 인후통 |
| 약물/중독 | 알레르기 | 귀 증상 |
| 정신과 응급(자살/자해) | 외상 | 근골격(비외상) |
| 소아 외상(중증 기전) | **어지럼증** | 눈 통증/시력 |
|  | 소아 외상(경증 기전) | 소아 발열(3개월↑·상태양호) |
|  | 산과 | 비뇨기(단순 배뇨통) |
|  | 눈 화학물질/이물 |  |
|  | 비뇨기(고환통·요폐) |  |
|  | 소아 발열(3개월 미만) |  |

### 4.C 경증→중증 자동 승격 조건 — 🔶칩스검증(수치)

🟢경증 트랙에서도 아래 잡히면 자동으로 중증 배너 + Red Flag 화면 복귀:

| 조건 | 기준(초안) |
|---|---|

## 5. 화면별 상세 요구사항

### ① 빠른 위험판정 (V3의 S1+S2+S3 압축)

| 영역 | 항목 | 비고 |
|------|------|------|
| 기본 | 나이(입력 시 소아 자동감지), 내원경로 7종 | 이름·환자번호는 ⑥ 최종확인 팝업에서(속도) |
| 첫인상(GI) | 얼굴색·발한·호흡·의식·자세·입원방식 6항목 | **"모두정상 ✓" 한방 버튼** 추가 |
| ABCD | A/B/C/D 정상·이상 | **"ABCD 모두정상 ✓" 한방 버튼** 추가, D 이상 시 BST 팝업 유지 |
| 판정 배너 | 🔴/🟠/🟢 실시간 | 🔴이면 "즉시 소생 — 바로 기록" 점프 버튼 노출 |

- 소아(만 15세 미만) 감지 시 소아 카드(체중·체온·키·PAT·보호자) 표시 — V3 유지하되 **PAT를 KTAS에 반영**(§6).

### ② 주호소 선택

- 주호소 그리드(V3의 29개 계승). **소아 환자면 소아 전용 주호소를 최상단 정렬.**
- 신규 주호소: **`소아 외상`** 추가(§7). 기존 `외상`은 성인/공통.
- 탭 즉시: 초응급 주호소면 경고 팝업(`CC_ALERTS` 확장 — §7).
- 탭과 동시에 §4 분기 판정 실행.

### ③-경증 V/S + 핵심질문 (한 화면)

- V/S 입력(V3 S4 유지).
- 그 주호소의 **핵심 질문 2~3개만** 노출(대개 NRS + 동반증상 1~2). 전체 세부질문 세트(③④⑤)는 생략.
- 핵심 질문 셋(주호소별 무엇이 "핵심"인지)은 🔶칩스검증.

### ③④⑤-중증 (V3 S6·S7·S8 계승)

- ③ Red Flag — 주호소별 동적 목록(V3 `RF` 계승).
- ④ 세부질문 — 주호소별(V3 `QD` 계승, 신규 주호소 보강).
- ⑤ Modifier 자동 → 예상 KTAS(V3 `calcMod` 계승 + 소아/학대 가중치 추가 §6).

### ⑥ 기록 완성 (공통)

| 영역 | 내용 |
|------|------|
| 과거력 | `#진단명` 태그 + `s/p 수술명` 태그 (V3 유지) |
| ⚠️ 학대 스크리닝 | **소아 또는 노인(≥65세) + 외상/화상 계열일 때 자동 노출**(§7) |
| 특이사항 | `$` 마커 (V3 유지). 학대 체크 시 자동으로 `$` 문장 삽입 |
| KTAS 확정 | 내원시 / 변경시 1~5 (RN 최종 결정) |
| 내원동기 | **클릭 누적 → 자동 문장 생성**(§6) — 수정 가능 |
| 출력 | 간호기록 복사 / 항목별 복사 / 전체 1줄 엑셀 복사 / 최종확인 팝업 (V3 유지) |

## 6. ⭐ 클릭 → 내원동기 자동 생성 (핵심 기능)

**"클릭클릭하면 내원동기를 만들어준다"** = 모든 선택이 문장 슬롯을 채우고, 정형 문장으로 조립된다.

### 6.1 문장 구조 (공통 골격)

```
{과거력} 과거력 있는 환자로, {내원사유}을(를) 주소로 {경로} 내원함.
{주호소별 자동 문장}
{기타 동반 증상}
[BST / Red Flag / Modifier / 추가메모]
```

- 과거력 없으면 → "특이 과거력 없는 환자로".
- 슬롯: onset(언제) · location(어디) · quality(양상) · NRS(강도) · 동반증상 · 발생양상.

### 6.2 클릭 → 출력 예시

| 주호소 | 클릭한 것 | 자동 생성 문장 |
|--------|----------|---------------|
| 복통 | 6시간전·RLQ·찌르는·NRS8·발열✓·구토✓·#당뇨·도보 | `#당뇨 과거력 있는 환자로, 복통을 주소로 도보 내원함. 6시간 전부터 RLQ 부위 찌르는 양상의 복통(NRS 8/10) 발생, 발열·구토 동반.` |
| 흉통 | 30분이내·중앙·쥐어짜는·NRS7·왼팔방사·식은땀✓·119 | `특이 과거력 없는 환자로, 흉통을 주소로 119 구급대 내원함. 30분 이내 전부터 중앙 부위 쥐어짜는 양상의 흉통(NRS 7/10) 발생, 방사통(왼팔)·식은땀 동반.` |
| 소아 외상 | 낙상·본인키이상·두부·의식소실✓ | `(소아) 낙상(본인 키 이상 높이)으로 인한 외상. 손상 부위: 두부. 의식 소실 있음.` 🔶칩스검증(소아 외상 문구) |

### 6.3 적용 범위

- **V3에서 문장이 나오는 주호소: 9개** (흉통·복통·두통·발열·신경학적·외상·중독·출혈·산과).
- **v4 요구: 전 주호소(29개+신규)에 문장 템플릿 부여.** 나머지 20개 템플릿 작성은 🔶칩스검증(정형 문구 확정).
- 출력 문구는 진술문 마스터를 벗어나지 않게 `statement-lint`로 검증.

## 7. 🆕 신규 기능 (V3에 없던 것) — 🔶칩스검증 집중 구역

> 아래 임상 내용은 **AI 1차 초안**이다. 항목·기준·KTAS 급수 전부 칩스 확정 필요. 빈칸은 지어내지 않음.

### 7.1 소아 외상 주호소 (신규)

| 요소 | 1차 초안 | 검증 |
|------|---------|------|
| 세부질문 | 손상기전(낙상/교통/타박/끼임/기타)·낙상높이·손상부위·의식소실·구토·보챔 | 🔶칩스검증 |
| 위험징후(Red Flag) | _(미정 — 소아 외상 적색기 목록 필요)_ | 🔶칩스검증 |
| 즉시경고 팝업 | _(미정)_ | 🔶칩스검증 |
| KTAS 반영 | PAT 이상 + 위험징후 → 가중치 | 🔶칩스검증 |
